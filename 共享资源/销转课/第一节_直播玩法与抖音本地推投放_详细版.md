## 二、抖音本地推投放实操（05:53-38:56）

### 2.1 投放数据展示（05:53-07:32）
- 上个月投放数据：累计消耗金额114万，真实占用金额120-128万
- 成交占比：100个人来买，89个人下单（89%成交率）
- 安心老师说"做短视频带货的、帮你们起账号的徒弟们，流量都非常不错"

### 2.2 投放工具介绍
今天会用到的投放工具：
1. **抖加** — 自媒体必须用，效果非常好
2. **本地推** — 抖音本地推（本次重点）
3. **巨量千川** — 带货
4. **微信豆** — 视频号

投流分类：
- **留资**：留客户的
- **团购**：卖产品的
- **带货**：快递包邮

### 2.3 本地推操作步骤（08:22-09:19）

**第一步：** 打开抖音 → 右上角三条杠 → **创作者服务中心**
**第二步：** 点开 **巨量本地推**
**第三步：** 点 **内容加热** → **团购成交**
**第四步：** 选择要加热的视频

> 巨量本地推个人小白也可以投，不是只能实体商家。哪怕没店儿，也能帮做流量到账号里来。

### 2.4 投放时长选择（09:19-10:16）

**推荐：12小时**

理由：
- 选太短（2小时/4小时）→ 流量跑飞，平台不知道该推啥人群，随便推
- 选24小时 → 微付费撬动自然流，投几块钱放24小时跑不动
- 所以微付费策略下，12小时最优

### 2.5 行业分类与投放半径（10:16-17:05）— 核心干货

安心老师先问大家做什么行业，让同学打出来。然后讲投放半径的选择逻辑。

#### 2.5.1 强刚需 — 6公里以内

**定义：** 每天都要消费的、每周都要消费的

**逻辑：** 用户下楼骑电瓶车5-10分钟能到，超过6公里客户意愿大幅下降

**行业清单：**
- 餐饮类：奶茶、早餐、面馆、快餐、炸串、小吃、社区简餐
- 便民生活：理发店、美甲美睫、干洗店
- 社区零售：生鲜便利店、水果超市
- 小型宠物店、家政保洁、社区托管、小药店、社区理疗店

#### 2.5.2 半刚需 — 8-12公里

**定义：** 有固定需求，但不追求极致就近，愿意开车出去走一走转一转

**8公里档（中档位）：**
- 正餐、中餐、家常菜、火锅、烤肉
- 足浴推拿、普通健身房
- 中小型牙科门诊
- 母婴店、儿童兴趣班
- 洗车、汽车美容、小型维修店
- 逻辑：店装修好、有卖点，客户愿意开车去

**10-12公里档（低频半刚需）：**
- 烧烤、宵夜、大排档
- 轻医美、皮肤管理中心（顾客愿意开10公里来）
- 亲子乐园、室内游乐场
- 城市快捷酒店
- 小型剧本杀密室店
- 逻辑：顾客1-4周消费一次，周末/夜间出行

#### 2.5.3 非刚需 — 20公里+

**定义：** 打卡型消费，可能数月/一年消费一次，客单价高

**行业清单：**
- 大型门店、酒楼
- 整形门诊（规避医美机构）、艺考培训、学科类培训
- 4S店、二手车行
- 医美医院
- 大型主题公园
- 高端私房菜、私房会所

**逻辑：** 用户决策周期长（比如买车不确定买宝马还是奥迪），可以投20公里以外

#### 2.5.4 全国生意
自定义 → 直接选「全国」

### 2.6 达人相似投放（17:05-22:44）

#### 2.6.1 操作流程

1. 右上角放大镜 → 搜行业关键词
2. 点小漏斗 → 点「用户」
3. 找到同行业头部账号（平台按变现/流量/粉丝由高到低排列）
4. 记下账号名
5. 在达人相似 → 更多 → 输入同行账号名

**案例1：葡萄酒行业**
- 搜"葡萄酒" → 点用户 → 找到"万利庄园葡萄酒"（58万粉丝）
- 记下名字 → 在达人相似→更多输入名字

**案例2：金融行业**
- 搜"金融" → 点用户 → 找到"婷姐聊金融"（50万粉丝，平均七八十万播放量）
- 把名字输入到达人相似

**原理：** 同行的粉丝刷视频时也会刷到你的账号。把你的同行流量搬过来。

#### 2.6.2 本地推优势
- 平台补贴大额流量券：投100抵40
- 比抖加便宜：1块钱买1万播放量
- 人群更精准
- 市场竞争小（很多人只会投抖加，不会投本地推）

### 2.7 探店投流法（22:44-30:13）

**适用场景：** 同城同行流量都不怎么样的时候

#### 方案一：探店账号
- 搜本地探店账号（如"湛江探店"）
- 探店达人流量天然大，且都是本地顾客
- 投流时把探店账号勾上

#### 方案二：方言投流
- 搜"郑州方言" → 找到本地网红
- 搜"湛江方言" → 找到湛江本地网红
- 精准到本地客户
- 投流时把方言网红名字投一遍

**案例：** 郑州方言搜到的"郑州地产波哥"——虽然不是同行业，但粉丝是郑州本地人，投他的粉丝就能精准获客。

### 2.8 视频号投流（22:44-27:35）

#### 视频号适合人群
个人带货、源头直销、品牌增收、知识服务（教英语课等）、本地团购、橱窗带货

#### 手机端投流流程
1. 发完作品 → 点「分享」 → 「上热门」 → 「专业加热工具」
2. 投流界面跟抖音一模一样（视频号基建抄抖音的）
3. 加热时长：12小时
4. 人群推荐：选「作者粉丝」
5. 搜索同行：搜行业关键词 → 点用户 → 记同行名字 → 搜索 → 勾选
6. 一般带10-15个同行

**找同行的方法：**
- 不知道同行叫啥名？打开放大镜搜行业关键词（如"电器批发"）
- 点用户 → 排名前几个的就是同行里做得不错的
- 记下名字 → 在搜索里搜 → 勾选

### 2.9 ROI案例数据（35:28-38:56）

安心老师展示去年投流费5000万，用案例证明投流效果：

| 行业 | 投入 | 产出 | ROI |
|------|------|------|-----|
| 面包店 | 1000元 | 17000 | 17 |
| 足浴店 | 800元 | 核销3万（成交100多单） | 33 |
| 服装店 | 400元 | 49000 | 117 |
| 餐饮 | 2500元 | 成交16万 | 64 |
| 蛋炒饭店（改后） | 投流（金额未详） | - | 16.38 |

> **核心观点：** 你的钱包捂得越紧就越没有办法钱生钱。现在平台早已经商业化，不投流几乎等于没流量。微付费撬动自然流——花100块有1000块的效果，花1万有10万的效果。

## 三、卖点视频制作（38:56-49:21）

### 3.1 核心逻辑
- **卖点视频的本质就是重复有效的模型**
- 拍流量视频 → 拍卖点视频 → 投流（三步走）
- 视频拍得不好，投流没有效果

### 3.2 AIP工具制作卖点视频（不用买样品）

**步骤：**
1. 搜想卖的产品 → 截图（如猫罐头、清洁剂）
2. 回到AIP工具 → 选模板
3. 点「剪同款」 → 把截图放进去 → 点「生成」

**案例1：猫罐头 → 短剧风格**
- 用短剧模板带猫罐头："这婚我退订了，你根本配不上我们家" → "猫罐头有吞太鱼和蟹肉罐罐"
- 效果：豪门闹离婚因为一罐猫罐头

**案例2：清洁剂 → 对比风格**
- "老管家重油污清洁剂，易瓦解油垢，净味又清新"
- 左边拿清洁球擦，右边喷上去直接一擦
- 老太太表情

**案例3：矿泉水 → 剧情风格**
- "姐来了，姐你先听车" → "早上赶上班就爱喝这个水"
- 天然矿泉水，解渴又方便

### 3.3 简易操作
1. 找到想卖产品的模板
2. 网上截一张图（不用买样品）
3. 点「剪同款」 → 生成
4. 保存上传

> 不需要自己出镜做视频，直接去生成就可以了。

### 3.4 核心原则
做短视频的本质是**留住用户的注意力**。你吸引住用户的目光，你咋拍都会有流量。

## 四、内容急诊室（49:21-01:03:31）

### 4.1 功能定位
很多人流量低不是内容不行，而是分不清：
1. **没有人点**（标题/封面问题）
2. **点进来没看完**（内容问题）

内容急诊室专门解决两种问题：
1. **还没发的视频** → 不知道流量怎么样
2. **已经发了但数据差** → 点赞低、播放量低、没评论、没转化、违规限流

### 4.2 操作流程
1. 点分享 → 复制链接
2. 丢到文案急诊室里 → 粘贴 → 发送
3. AI自动分析：账号整体数据、人群画像、给出建议

### 4.3 诊断报告示例（房产行业）

**六维评分：**
- 标题吸引力6分（不够吸睛）
- 互动引导4分

**核心病因：**
- 文案专业突出但流量获取能力不足
- 开头没抓住用户注意力
- 市场分析太专业
- 互动性引导弱

**修改建议：**
- 开头强化钩子（资产贬值、买房踩坑等用户痛点代替直白的市场告知）
- 加入互动设计（"你在温州有房吗？现在觉得买房是好时机吗？"）
- 标题重写：温州楼市彻底变迁，豪宅贬值，刚需买房必看这几个点
- 0-3秒加温州地标性建筑（借景点）
- 借势讲法

### 4.4 改前改后对比（蛋炒饭店）

**改前：** 视频拍得不好看，没人愿意看

**改后：** 用卖点视频打法
> "价1999，1份货铺1699，商铺200，店铺91，现在只要八块钱，烟免费送，辣椒免费送，葱免费"

**结果：** 净成交ROI 16.38（投1块回来16块）

### 4.5 关键观点
> 平台还是以内容为王的。不知道自己错在哪里，其实就是一种错误。

## 六、直播干货（01:20:42-01:37:58）

### 6.1 直播间人数分层话术

| 在线人数 | 策略 | 具体操作 |
|---------|------|---------|
| **几个人** | 点对点 | 谁进来欢迎谁，建立互动，做5秒停留 |
| **10-30人** | 整场互动 | 问普遍存在的问题（"有没有掉发的？"），拉所有用户痛点 |
| **30-100人** | 卖点展示+改价 | 展示价值→改价→上链接→促成交 |
| **100-260人** | 统一话术 | 放弃一对一，全程带动氛围，差异化展示（"这是我原来地中海的头发"） |

### 6.2 直播三要素：人货场

**人：**
三种直播方式：
1. **不出镜**：怼产品拍
2. **视频素材**：素材放上去，真人在左下角露小头
3. **戴口罩播**：加美颜，不露脸也能播

> 不是颜值主播，加个美颜戴个口罩甚至不用出镜都能播。普通话不标准也能播（山东学员、广东学员案例）。

**万能直播框架：价值 → 稀缺 → 比价 → 保障**
- **价值**：产品有什么价值（榴莲口感像冰淇淋）
- **比价**：跟别人比好在哪里
- **保障**：打消用户顾虑（退款服务）
- **稀缺**：限量/限时（"321上链接"）

**货：**
引流品 → 主推品 → 利润品
教练根据商品帮忙组货盘

**场：**
- 画面要吸睛（绿色背景护眼+竹子风坚韧不拔）
- 卖点可视化：在直播间展示产品
- 不同行业不同视觉方向：
  - 餐饮 → 诱人
  - 酒旅 → 美
  - 家政 → 专业感
  - 按摩 → 性价比/舒适感

### 6.3 直播变现方式

| 方式 | 适用 | 说明 |
|------|------|------|
| **团购** | 实体店（线下核销） | 低价引流到店券 → 到店升级消费 |
| **小风车** | 高客单（装修、房产） | 收集客户电话 → 单独邀约洽谈 |
| **小黄车** | 全国邮寄（服装带货等） | 商品快递到用户手中 |

### 6.4 直播案例
- 卖鲈蟹钳的：2小时卖1万单
- 河南小县城串串火锅：4小时卖4万
- 华莱士首场直播：安心公司做的
- 卖寿司的：40分钟卖3000单，第三场直接卖1万
- 美发学员卖染发剂：7天消耗1500，成交22万，核销13万

## 九、书单号与风口赛道（01:55:44-02:59:00）

### 9.1 书单号红利
- 实体书店倒闭原因：压货囤货（为卖一两本书整一两千本）

- 佣金50%左右，比洗洁精/抹布高得多

### 9.2 AB链玩法（核心技巧）
- 小黄车标0.98元/1元 → 点进去是书签（不是书）
- 类比：拼多多上标20块的洗衣机，点进去是洗衣机地漏
- **增加商品点击率 → 推流变高**

> 20块钱买的不是洗衣机，是洗衣机的地漏。

### 9.3 三频共振多平台开播
- 成本：三台备用机
- 一台播抖音，一台播视频号，一台播小红书
- 画面场景一模一样，不会违规
- 每个平台推流不同，不会判定重复开播

**案例展示：**
- 抖音卖了585单

- 视频号也有订单

- 7天涨粉13万
