# 结营调查问卷与发送话术

> 使用时机：学员陪跑结束（第28天结营）后，由交付老师（陪跑老师）给自己的学员逐一发送。
> 目的：调研学员对陪跑老师、训练营的真实满意度，收集改进意见。

## 问卷字段（固定 6 项）

1. 真实名字
2. 行业（赛道）
3. 陪跑过程中遇见了什么问题
4. 陪跑老师
5. 对待陪跑老师有什么意见
6. 对待训练营有什么建议

## 发送纪律（重要）

1. **发送者 = 陪跑老师本人**（交付老师），署名「你的陪跑老师 + 真实名字」——问卷里有一栏「陪跑老师」，学员看到署名才知道那栏填谁，填得才准
2. 若教务老师代发，话术里必须点出陪跑老师真实名字（例：「我是陪跑老师 {名字} 的教务老师」），否则学员不知道评价对象是谁
3. 发送时机：结营当天或次日，趁学员还有仪式感；不要拖过 3 天，拖越久回收率越低
4. 24-48 小时未填的，用跟进话术再发一次；最多跟进 2 次，不连环催
5. 问卷回收结果：交付老师汇总后交陈涛（东坡先生），作为陪跑老师考核与训练营迭代依据

## 发送话术（随问卷链接一起发）

```
{学员称呼}，咱们的陪跑训练营到今天就正式结营了 🎉

这 30 天能陪你走下来，我特别想听听你的真实感受——不管是对我，还是对整个训练营，好的坏的都想听，你写的每一条我都会认真看。

这是一份结营小问卷，就 6 个问题，2 分钟能填完：
👉 {问卷链接}

你的真实想法对我们特别重要，能帮后面的学员少踩坑。谢谢你这 30 天的信任和配合！

——你的陪跑老师 {老师真实名字}
```

## 未填跟进话术（24-48 小时没填，再发一次）

```
{学员称呼}，怕你太忙活忘了，结营问卷再发你一次哈 👉 {问卷链接}，2 分钟就好。
特别是「陪跑过程中遇见了什么问题」那一栏，你多写一句，都是帮下一期学员避坑～
```

## 话术设计逻辑（调 10_教练沟通要素）

- **先仪式感再请求**：先宣布结营、回顾 30 天，再给问卷——直接甩链接像催收，仪式感让填写变成「结营的最后一步」
- **降低成本**：「就 6 个问题，2 分钟」——明确填写成本，减少拖延
- **给意义不给压力**：「帮后面的学员少踩坑」——利他人视角比「请配合我们工作」有效
- **署名点身份**：学员对「陪跑老师」的角色认知来自 30 天的相处，不一定知道你叫什么——署名是对号入座的锚点
