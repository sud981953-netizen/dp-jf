# 28天陪跑SOP

> 基于方法论体系设计。交付老师每天教1个知识点 + 布置任务，学员在每日沟通中完成。
> 前期（1-2周）账号搭建 + 起号测试，后期（3-4周）内容深化 + 变现落地。
> 通用框架，交付老师按学员行业填充具体文案/场景。
> 【优先级说明】本SOP是陪跑节奏的详细参考。每日执行以 SKILL.md Phase 2 周次知识点表为准，
> 每日详细话术文案以外部《实操执行手册》+ 知识卡片为准。三者有出入时：SKILL.md > 实操执行手册 > 本SOP。
> 【数据原则】全程不看后台数据，不用完播率/互动率做诊断。视频好坏用眼睛看（场景/表现力/包装/内容），
> 复盘归因从方案/执行/赛道三个角度找原因。

## 第一周：账号搭建 + 起号测试

### 第1天：账号价值定位

- **知识点**：账号价值分实用价值（干货/信息差/避坑/揭秘）和情绪价值（共鸣/故事/搞笑）。避免只实用变工具人账号（白嫖多难变现）、只情绪太虚无。主次分明，主+辅。
- **任务**：跟交付老师深度访谈，梳理基础信息（行业/资源/目标/出镜意愿等20条）
- **产出**：完成基础信息采集表

### 第2天：IP人设定位

- **知识点**：人设=标签组合（身份+专业+性格+经历+差异化）。三种找标签思路：从客户痛点出发（如「不让顾客疼痛的牙医」）/从个人特征出发（如「四胞胎宝妈」）/按行业特性出发。铁律：不弄虚假人设。
- **任务**：确定你的人设标签组合 + 搭建账号主页（昵称/头像/简介/背景图）
- **产出**：账号主页搭建完成（昵称=职业+标签，简介含身份荣誉/行业/年限/案例/座右铭）

### 第3天：用户五层漏斗 + 对标账号

- **知识点**：用户分5层（L1所有人-L5已付费），你的目标用户在哪层？找对标要看评论区长评能力——只有拥有「长评」能力的博主才是真对标。
- **任务**：找3-5个对标账号（翻评论区找长评）+ 搭建素材库（8类：选题/开篇钩子/脚本结构/呈现形式/故事/观点/同行/BGM）
- **产出**：对标账号清单 + 素材库框架

### 第4天：选赛道三标准 + 选题引擎

- **知识点**：赛道三标准（选题容量3年1000+/自己搞明白/能说清楚给用户听）。五级星图（行业大类→细分→品类→属性→选题）×六个角度（避坑/对比/教程/案例/观点/趋势）=1800选题。
- **任务**：用五级星图梳理你的行业选题
- **产出**：本周选题清单（10-15条）

### 第5天：开头钩子 + 拍首条

- **知识点**：前3秒决定生死。开头四维评分（预测打断/奖励植入/损失厌恶/命名），≥3项达8分合格，第一句≤20字。7大开头类型（预告看点/价值包装/共鸣引发/互动激发/直击痛点/事件开场/现象前置）。
- **任务**：拍首条测试视频（按四维评分设计开头）
- **产出**：1条测试视频 + 交付老师点评优化

### 第6天：视频评价认知 + 多发测试

- **知识点**：评价视频用眼睛看（场景/表现力/画面包装/内容质量），不看后台数据。冷启动期多发测方向（每天3-5条），测什么视频形式容易火。
- **任务**：发3-5条测试视频（不同形式/不同变法）
- **产出**：3-5条视频发布

### 第7天：观看复盘 + 定方向

- **知识点**：观看复盘方法——开头没吸引力=看前3秒自己都想划走；没共鸣=看完内心毫无波动；没人关注=结尾没有给人关注的理由。归因：方案问题/执行问题/赛道问题。测出方向。
- **任务**：逐条回看本周视频，定下周内容方向
- **产出**：方向复盘报告（哪类视频看着最舒服、最有感觉，下周重点做哪类）

## 第二周：内容创作 + 流量型主力

### 第8天：选题四条件 + 素材库扩充

- **知识点**：选题四条件必须全满足——和人设强相关/目标用户关心/有真实经历或独特见解/有具体数字或反常识结论。任一不满足不做。
- **任务**：扩充爆款素材库（每天刷1小时进货，归类收藏）
- **产出**：素材库扩充（新增10+条素材）

### 第9天：72变创意手法

- **知识点**：72变第1-34变（内容创作技巧类）——每条视频匹配一个变法做创意手法（如反常识/吐槽/损失厌恶/冲突/好奇等）。变法决定钩子方向（反常识变法→反常识钩子，吐槽变法→共鸣钩子）。
- **任务**：写3个开头钩子（每个匹配一个变法）
- **产出**：3个开头钩子（标注用的哪个变法）

### 第10天：AI辅助创作（不抄对标）

- **知识点**：AI辅助创作——AI搭骨架，人工定灵魂。**不要抄对标/洗稿**（平台判抄袭降权，2026算法内容评审过滤搬运）。两种流程：已想透逻辑链→AI润色→人工砍一刀；只有想法→AI搭骨架→人工调整→AI润色。
- **任务**：用AI辅助写3条文案（人工定灵魂）
- **产出**：3条文案

### 第11天：文案五模块 + 论证五层

- **知识点**：文案五模块（开头/定义/拆解/案例/收束）。论证五层——目标达层4以上（观点+底层逻辑+反面后果+案例），层3以下就是说教。写作风格DNA：短句/数字精确/口语化/自我暴露/金句结构。
- **任务**：写1条完整文案（五模块+论证层4+写作DNA）
- **产出**：1条完整文案

### 第12天：无脚本拍摄 + 实拍

- **知识点**：无脚本拍摄10技巧——眼神盯两眼中间/拍摄前聊私密话题/小动作默契开拍/高情绪提问/身体稳定/积极回应/距离2米/反常识刺激性提问/着装平等匹配。
- **任务**：实拍流量型视频（每天3-5条测方向）
- **产出**：3-5条流量型视频

### 第13天：视频包装

- **知识点**：BGM搭配（情绪加持，内容与音乐相反可反转效果）+ 封面制作（醒目突出）+ 标题撰写（信息缺口/情绪强刺激，3-5个竞争对手封面旁能胜出）。
- **任务**：包装本周视频
- **产出**：包装完成（BGM+封面+标题）

### 第14天：本周复盘

- **知识点**：观看复盘——哪条自己都不想看第二遍=开头或选题有问题；哪条看完没感觉=无共鸣；哪条看完但不想关注=结尾无引导。归因：方案问题/执行问题/赛道问题。
- **任务**：复盘本周视频 + 归因
- **产出**：周复盘报告 + 下周调整方向

## 第三周：价值型深化 + 数据迭代

### 第15天：价值型四种呈现

- **知识点**：价值型四种呈现——人设向（出镜）/干货向（不出镜配音）/场景化向（不出镜第一人称记录）/图文向（不出镜）。不出镜也能做价值型。
- **任务**：拍价值型视频（按你的出镜意愿选形式）
- **产出**：价值型视频

### 第16天：故事设计六板块

- **知识点**：故事六板块——人物塑造（反应/性格冲突/戏剧化）/人物关系（社会/地位/情感）/情感印象（即时→共鸣→认同）/开头呈现/主体构思（三幕式）/结尾动作（升华/金句/互动）。
- **任务**：写故事脚本（六板块完整）
- **产出**：故事脚本

### 第17天：情绪价值四象 + 7种通用情感

- **知识点**：情绪四象——故事情节/特殊角色/相似情境/配音加持。7种通用情感（喜怒哀乐惊恐思），先找让自己产生强大情绪的场景，确定情绪+人物关联。
- **任务**：拍情绪型视频
- **产出**：情绪型视频

### 第18天：观看诊断 + 归因

- **知识点**：观看诊断if/else——自己都想划走→标题开头有问题；看完无感觉→无共鸣无价值；看完不关注→结尾无引导；有播放没评论→无情绪共鸣点。归因：方案执行到位但视频看着就是不行=重做方案；未按方案拍=执行问题；换了几轮都不行=考虑换赛道。
- **任务**：诊断本周视频 + 归因
- **产出**：诊断报告 + 归因结论

### 第19天：爆款复盘四步

- **知识点**：爆款复盘四步——拆解结构（为什么爆）/提取规律（哪些可复制）/更新素材库（有效元素存入）/复制结构（相同变法+新选题再做一条）。爆款定义：播放>平时10倍，涨粉>平时5倍，评论有大量长评。
- **任务**：复盘爆款（如有）+ 复制结构
- **产出**：爆款复盘报告 + 1条复制视频

### 第20天：72变运营手法

- **知识点**：72变第35-72变（账号运营类）——选1-2个作为账号运营主线。差异化定位（反向操作/跨域复用/特殊视角）/系列化运营（章回体/打卡挑战/用户共创）/人设化运营/起号策略。
- **任务**：选你的账号运营主线变法
- **产出**：运营主线确定

### 第21天：迭代校准

- **知识点**：迭代机制——配比校准（数据好的类型加比例）/选题方向校准（数据反馈调整星图重点）/变法校准（淘汰无效变法，加大有效变法）。
- **任务**：调整下周方向
- **产出**：迭代方案

## 第四周：转化型 + 引流变现

### 第22天：转化型吸引式

- **知识点**：转化型吸引式优先——价值展示型/资源展示型/案例转化型/实力背书型。核心逻辑：先展示价值→再亮明资源→用户产生信任主动消费。**不硬推销**（推销式营销感强，算法判营销号降权）。
- **任务**：拍转化型视频（吸引式）
- **产出**：转化型视频

### 第23天：线索转化型做法

- **知识点**：线索转化型视频做法——挖掘你的产品/服务/理念/生产流程/销售成交过程/售后服务，每个钩子搭配一个有趣的故事。
- **任务**：做线索转化视频（挖你的产品/案例+故事）
- **产出**：线索转化视频

### 第24天：漏斗承接

- **知识点**：漏斗承接——流量型爆款后T+1接价值型，T+3接人设向价值型，T+7接转化型。月规划按「第1-2周泛流量为主→第3周精准内容加重→第4周转化收口」递进（与要素定义库/11_内容漏斗与流量分层要素.md 步骤3一致）。
- **任务**：规划你的漏斗承接节奏
- **产出**：承接方案

### 第25天：爆款复制

- **知识点**：爆款复制——拆解爆款用的哪个变法→提取变法规律→用相同变法+新选题再做一条。72变贯穿：起号用运营变法，爆款复制用相同变法。
- **任务**：复制爆款（相同变法+新选题）
- **产出**：复制视频

### 第26天：月度复盘 + 迭代

- **知识点**：月度观看复盘——回看本月所有视频，哪类内容看着最好/最差，72变哪个变法最有效，哪条是播放明显起量的小爆款。
- **任务**：月度复盘
- **产出**：月度复盘报告

### 第27天：下月规划

- **知识点**：基于复盘结论规划下月——配比校准（看着效果好的类型加比例）/选题方向（星图重点调整）/变法（淘汰无效，加大有效）。
- **任务**：写下月规划
- **产出**：下月规划方案

### 第28天：引流变现 + 总复盘

- **知识点**：引流到你的产品——把流量引到你的现有产品/实体店（skill不定义变现路径，引流到学员自有产品）。爆款决定速度，结构决定上限。
- **任务**：引流落地 + 月度总复盘
- **产出**：变现落地情况 + 月度总复盘报告

## 陪跑核心原则

1. **每天一个知识点 + 一个任务**——学到的东西和布置的任务同时有
2. **前期重搭建起号**（1-2周）——定位深耕，多发测试方向
3. **后期重变现落地**（4周）——转化型吸引式，引流到学员产品
4. **拒绝洗稿/抄对标**——AI辅助创作（搭骨架人工定灵魂）
5. **72变贯穿**——1-34变做创意手法，35-72变做运营主线
6. **要素自检**——每条视频过开头四维/论证五层/选题四条件
7. **观看驱动迭代**——每周用眼睛复盘，归因找问题（不看后台数据）
8. **结果导向**——第28天变现落地，月度有结果

## 假设标注

本SOP的配比、变法标签均为「假设（待实战校准）」。跑完3个学员后才能去掉「假设」前缀。
