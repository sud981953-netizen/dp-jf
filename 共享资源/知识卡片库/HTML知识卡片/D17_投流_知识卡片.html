01

为什么要投流？先搞懂这个

投流不是「花钱买流量」，是「花钱买精准的人」。

你把视频发出去，抖音先给你推 300-500 个人看。数据好，继续推；数据不好，停。这个叫「自然流量」——但自然流量有天花板。你拍得再好，算法不给你推到对的人面前，你也白拍。

投流就是跳过算法慢慢试的过程，直接花钱让平台把你的视频推到你想找的那群人面前。你做装修的，想找要装修的人；你做美业的，想找要做脸的人。投流帮你找到他们。

但投流不能救烂内容。如果视频本身没人看（完播低、没互动），投再多钱也白搭。投流是放大器——内容好，放大爆；内容差，放大自己的错误。

先测后放大：100元测方向 → 数据好加投 → ROI>1再追加

四大平台投流工具速查

🎵 抖音
💰 DOU+（抖加）
适合：新号测方向/涨粉/加热视频
目标：涨粉/点赞评论/主页点击
预算：100-300元测试
出价：自动出价
配比：70%自然+30%DOU+
🎯 巨量千川
适合：带货/直播间引流/商品转化
目标：直播间成交/商品转化
定向：地域+兴趣标签
ROI：>2.5（美业）
开户：抖店后台→千川
📢 抖音 AD（巨量广告/巨量引擎）
比千川更专业的品牌广告投放，适合品牌曝光、线索收集。门槛高，预算大，新手不建议碰——先用DOU+和千川跑通再说。
📍 巨量本地推 — 实体店专属
专门给实体店用的。你开火锅店、美发店、口腔诊所、装修公司——想让周边3-5公里的人到你店里来，用本地推比用DOU+更精准。因为它的逻辑是「按地理位置推送」，不是按兴趣推送。

跟DOU+的区别：DOU+推的是喜欢看你这类内容的人（可能是全国各地的），本地推推的是住在你店附近的人。开店的优先用本地推，别用DOU+拿全国的流量——外地人不可能来你店里。

怎么用：抖音搜索「巨量本地推」→认领你的门店→设置投放范围（3-5公里）→选投放目标（团购/留资/到店）→日预算100元起测。
适合谁：餐饮、美业、口腔、教培、家政、装修等一切有实体门店的行业。

🛒 视频号挂车投流避坑指南（一线实战经验）
视频号短视频挂车投放 ≠ 直播间投放。很多培训用直播间的逻辑教短视频投流，完全是两码事——直播间是实时数据+人货场搭着跑的，短视频是素材驱动。以下是实战总结的四条避坑铁律：

避坑1：新号出价怎么设
新号权重低，挂车投成交计划出价会略高。一般是佣金的1.2倍左右，个别品需出到客单价的0.7倍。启动后ROI不会很正——只要有消耗就行。如果消耗太快→停止计划→重建→出价往下压10个豆→找到消耗速度和ROI的平衡点。

避坑2：ROI计划别上来就建
很多教直播的人直接让建ROI计划去测素材——跑不动的。ROI计划需要更精准的人群，必须等成交计划先跑出一定单量、有了人群数据积累，再建ROI计划才有意义。顺序：先成交→积累数据→再ROI。

避坑3：多素材必须同一链接
不同链接=不同产品=佣金率不同=人群定向不同。把不同链接的素材加到一个计划里→数据乱七八糟。只把同一个产品链接下的多个素材放一个计划。

避坑4：短视频挂车不需要圈人群
直播间需要圈人群，短视频挂车不需要。因为短视频内容本身就是定向——前三秒已经决定了谁留下、谁划走。圈了人群反而窄→不消耗→即使消耗了ROI也不正。视频号投放人群和出价每天都是浮动的（有人竞争就高，人群就那么多），不用纠结。

总结：视频号挂车投放不难——先跑成交计划积累数据→再建ROI计划→同链接多素材→不圈人群。别被割韭菜的交几千块学这些。
💡 一句话选平台：做抖音用DOU+测、千川转；做小红书用薯条测、聚光转；做视频号用微信豆测、ADQ转。不管哪个平台，都是先测后放大。

微付费打标签法（花几块钱撬动上万流量）

前3条作品打标签，第4条起用隐藏法省钱投。
不是投得越多越好——是投得越准越好。

2 第4条起 — 几块钱撬大流量
💰 投100元 → ⏱️ 跑1小时 → 🙈 隐藏 → 👀 放出来 → 💸 花3-5块

3 别忘了：每条评论都要回

你回一条 → 评论数变2条 → 用户回来看 → 视频还在放 → 播放量+完播率一起涨。回评论 = 免费二次加热。

⚠️ 每条作品消耗金额不同（1-5块），因为内容不同。花3块就补3块，花5块就补5块——别多充，只补消耗掉的。
04

投流翻车实录（避坑指南）

翻车1：「投了好几百，一个咨询都没有」
原因：你投的是「涨粉」或「点赞」，不是「主页访问」或「获取客户」。涨粉来的都是看热闹的，不是想买东西的。如果你要的是客户咨询→投的时候选「主页访问」或「获取客户」，不选涨粉。前提是你的账号主页简介和作品能让人看完想咨询。
翻车2：「投了100块，半个小时就用完了，什么都没得到」
原因：投放时长选太短。2小时、6小时平台来不及找精准用户，只能给你灌水充数。改：时长选12小时。让平台有足够时间找到对的人。
翻车3：「投流来的全是老头老太太，根本不是我的客户」
原因：你选了「智能推荐」或「粉丝经营」。平台为了完成任务，推给最容易停留的人——老年人和机器号。改：用「自定义人群」→「达人相似」→填10个同行账号。把人群主动权拿回来。
翻车4：「我选达人相似，结果选的头部大号，根本洗不动」
原因：你找了粉丝几百万的头部大号。他们的粉丝粘性极强，看到你的视频也不会关注你——你不是那个大V。改：找2万-20万粉的中腰部账号，粉丝活跃、粘性没那么强、更容易转化。
翻车5：「投了本地推，结果全是外地人打电话问能不能发货」
原因：投放范围没设好，选了全市甚至全省。改：范围设3-5公里。开店的客户就在你周边，远了人家也不可能来。做同城的尤其是餐饮美业，别贪大——圈越小越精准。
翻车6：「投了5条视频，4条亏了，心态崩了不投了」
原因：你把投流当成赌博——期望每条都爆。实际上投流是数据测试，10条里有1-2条好的就不错了。改心态：投流的目的是用100块测出那条好方向，不是每条都赚钱。测出来之后，把坏的停了，好的放大。亏小钱找方向，赚大钱靠放大。

💬 投流说到底是个什么事？

把投流想象成请人帮你发传单。DOU+/薯条/微信豆 = 请街上的人帮你发（简单、便宜、谁都能干）。千川/聚光/ADQ = 请专业派单公司帮你发（精准，但贵，门槛高）。

小白最常犯的错：把投流当救命稻草。视频播放不高 → 投100块 → 还是不爆 → 再投200块 → 还是不行。钱越投越多，心态越来越崩。其实问题根本不在投流，在内容本身——你内容不行，就像给一个不好吃的菜打广告，广告打得越多，知道不好吃的人越多。

正确姿势：先跑通自然流量，再用投流放大。你哪天有一条视频自然播放破了1万，完播和互动都达标——这时候投100块推一把，看能不能冲到10万。这叫「放大爆款」，不叫「拿钱买命」。

多平台怎么做？不需要每个平台都投。你主做哪个平台，就先在那个平台用最便宜的工具（DOU+/薯条/微信豆）测。测通了再考虑跨平台。记住：投流是放大镜，不是魔法棒。好内容放大10倍，烂内容放大自己的错误。
