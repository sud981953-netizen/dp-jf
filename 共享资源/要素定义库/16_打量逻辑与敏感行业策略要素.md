# 打量逻辑与敏感行业策略要素

**不是所有学员都适合做 IP。能出镜、有网感、能讲话的走 IP 逻辑。不能出镜、没网感、没时间拍的走打量逻辑，从目标客户出发打流量。**

---

## 一、核心区分：IP逻辑 vs 打量逻辑

### IP逻辑（人驱动）

适用条件：
- 能出镜（愿意面对镜头）
- 有网感（知道怎么说话、怎么表现）
- 有时间（能持续拍内容、打磨内容）
- 有表达力（能把一个事讲清楚）

核心逻辑：
- 从"人"出发：先定人设，再定内容
- 靠人设标签让用户记住你
- 靠内容深度建立信任
- 变现靠用户对"人"的信任和连接

内容形式：口播、VLOG、人设向图文
需要调用：要素定义库 01-08 所有 IP 相关要素

### 打量逻辑（流量驱动）

适用条件：
- 不能出镜（不愿意面对镜头）
- 没网感（不知道怎么表现）
- 没时间（没精力打磨内容）
- 但有产品/店在卖

核心逻辑：
- 从"目标客户"出发：目标客户喜欢什么，就用什么去打（吸引）他们
- 去人设化：不靠人设，靠流量模板
- 什么样的视频有流量能变现，就用什么样的视频模板去做
- 批量生产为主（AI 生成/模板化）

内容形式：AI 生成图文/混剪、美女引流、反差内容、搞笑段子、场景记录
不需要：人设包装、深度选题、口播文案

## 二、打量逻辑操作流程

### 步骤1：先分析目标客户群体

不是分析"我要拍什么"，是分析**我的目标客户喜欢看到什么**。

```
IF 学员产品/服务的客户是:
  男生 -> 喜欢美女/搞笑/反差/游戏/车/赚钱
  女生 -> 喜欢美/情感/生活/省钱/八卦/成长
  中年人 -> 喜欢家庭/健康/赚钱/回忆/情感共鸣
  年轻人 -> 喜欢潮流/娱乐/游戏/新奇/反差

每一类人群都有共性喜好。
卖槟榔的客户是抽烟喝酒的男生 -> 他们喜欢美女
卖五金工具的客户是中年男性 -> 他们喜欢实拍场景/干货
卖女装的客户是女性 -> 她们喜欢穿搭展示
```

### 步骤2：选流量载体

找到目标客户喜欢看的、且不违规的"流量载体"。

```
目标客户 -> 他们爱看什么？ -> 这个载体能不能自然地融入产品元素？

卖槟榔 -> 爱看美女 -> 用 AI 生成美女展示槟榔（背景是门店/手里拿着）
卖白酒 -> 爱看豪爽场景 -> 拍豪爽喝酒场景/哥儿们聚会
五金店 -> 爱看实用技巧 -> 拍维修/装修场景，产品自然出镜
成人用品 -> 爱看搞笑/反差 -> 拍搞笑送货过程/无厘头开箱
```

### 步骤3：批量生产

打量逻辑不走深度创作，走模板化、批量生产。

```
- 用 AI 工具生成图片/视频（AI 美女/AI 场景/AI 口播）
- 固定脚本模板，只换变量（产品/场景/文案词句）
- 每天批量产出多条，多号矩阵发布
- 不追求单条爆款，追求稳定出量
```

### 步骤4：元素自然融入，不强展示产品

打量逻辑的核心技巧：**不用力表现产品，让观众自己感受到。**

```
错误做法：对着镜头介绍槟榔多好吃、多便宜
  -> 算法识别为"槟榔广告"，限流违规

正确做法：美女跳舞/搞笑视频，背景是槟榔门店，身边放着槟榔
  -> 算法锚点落在"美女""跳舞"上，弱化槟榔
  -> 但观众能看到门店和槟榔，自己就会感受到"这家店在卖槟榔"
  -> 想买的自然会找上门
```

### 步骤5：同城定位强化

打量逻辑通常用于同城实体店引流，位置标签是核心。

```
- 发布时必须带门店定位
- 视频背景/环境突出门店特征（门头/环境/产品陈设）
- 内容不需要强调"我在哪"，位置标签+门店环境已经表明
```

## 三、敏感/违规行业的流量载体承接逻辑

这个逻辑适用于：槟榔、成人用品、白酒、医美、金融、法律（部分敏感领域）等容易被限流违规的行业。

### 核心原则：用流量载体遮蔽产品，让观众自己解码

```
IF 产品本身容易违规:
    -> 不要直接在视频里展示/介绍产品
    -> 选一个不违规的"流量载体"来承接
    -> 在视频里只表现"元素"，不表现"产品"
    -> 观众看到元素，自己就会解码"哦，这是卖XX的"
    -> 算法按载体标签推流，不会按产品标签限流
```

### 具体操作

```
载体选择：
  找目标客户喜欢的、不违规的、能自然融入产品元素的内容形式

元素融入（点到为止，不刻意）：
  - 门店背景露出（门头/招牌/货架）
  - 产品在角落自然出现（不是特写，是环境的一部分）
  - 穿工作服/制服暗示行业
  - 对话中顺带提到（不解释，带过即可）

观众解码：
  - 不会解码的观众 -> 不是目标客户，流失就流失了
  - 能解码的观众 -> 精准目标客户，会主动找上门
  - 自然筛选，不会引来非目标人群
```

### 敏感行业 x 流量载体速查

| 敏感行业 | 目标人群 | 可用流量载体 | 元素融入方式 |
|---------|---------|------------|------------|
| 槟榔 | 抽烟喝酒的男生 | 美女跳舞/搞笑 | 门店背景+手持槟榔（不讲解） |
| 成人用品 | 年轻人/情侣 | 搞笑开箱/反差剧情 | 普通快递盒+暗示性文案 |
| 白酒 | 中年男性/社交人群 | 豪爽聚会/兄弟日常 | 聚餐场景+酒杯自然出镜 |
| 医美 | 爱美女性 | 变美分享/日常VLOG | 不知不觉提到项目+展示效果 |
| 金融贷款 | 缺钱人群 | 赚钱干货/避坑指南 | 讲知识时代入具体服务 |
| 法律咨询 | 有法律需求的人 | 案例普法/剧情复现 | 讲故事时自然带出服务优势 |

## 四、IP逻辑 vs 打量逻辑判定路由

```
IF 学员不能出镜 OR 没网感 OR 没时间 OR 明确说"不想出镜":
    -> 走打量逻辑（调用 16_打量逻辑与敏感行业策略要素.md）
    -> 核心任务：
        1. 分析目标客户群体画像（性别/年龄/喜好）
        2. 选流量载体（他们喜欢什么内容）
        3. 设计元素融入方式（怎么自然带出产品）
        4. 批量生产模板设计
        5. 敏感行业检查（如果有，走流量载体承接逻辑）
ELIF 学员能出镜 AND 有网感 AND 有表达力:
    -> 走IP逻辑
    -> 核心任务：
        1. 账号定位+人设包装（调用 01_账号定位要素.md）
        2. 内容漏斗设计（调用 11_内容漏斗与流量分层要素.md）
        3. 选题+文案+呈现（调用 02-05要素）
        4. 72变匹配（调用 06_72变要素.md）
        5. 日常教练循环（进入 Phase 2）
ELSE（条件模糊）:
    -> 先判断最多见学员的真实能力和意愿
    -> 如果介于两者之间，可以IP逻辑为主+打量逻辑元素为辅
```

## 五、打量逻辑中的变通原则（融入 10_教练沟通要素）

打量逻辑不是放弃变通，而是换一种变通方式：

```
IP逻辑的变通：调选题方向、调人设表达、调呈现形式
打量逻辑的变通：换流量载体、换元素融入方式、换批量工具

打量逻辑中，如果当前载体不跑量：
  -> 换一种流量载体（美女不行换搞笑，搞笑不行换剧情）
  -> 换元素融入方式（背景融入不行换场景融入）
  -> 换批量工具/渠道（AI图不行换混剪，一门号不行再多开几门）

绝对不变通的底线（打量逻辑）：
  - 去人设化：不做IP，不发人设内容
  - 不从产品出发：从目标客户出发
  - 不强展示产品：让观众自己感受
```

## 六、内联案例库

### 案例1：卖槟榔不能出镜（打量逻辑）

**学员背景**：卖槟榔的实体店老板，不能出镜，没网感，之前按IP逻辑发内容，引流来的人年龄偏大，不是目标客户。

**策略转向**：
1. 确定打量逻辑：不能出镜没网感 -> 不做IP
2. 目标客户分析：卖槟榔 -> 客户是男生 -> 抽烟喝酒吃槟榔 -> 喜欢美女
3. 选流量载体：AI生成美女跳舞/搞笑视频
4. 元素融入：在门店前面或里面拍，美女手里拿着槟榔，背景是槟榔门店
5. 敏感规避：不介绍槟榔、不展示价格、不强引导。视频锚点放在"美女""跳舞"上，槟榔只是背景元素，算法不会归到槟榔限流，但观众自然能解码

**效果**：引流来的人精准（目标客户自己找上门），不引来非目标人群。

### 案例2：五金店不出镜（打量逻辑）

**学员背景**：五金店老板，不出镜，之前硬着头皮对口播没流量。

**策略**：
1. 目标客户分析：五金店客户是干活的手艺人/装修工/DIY爱好者 -> 喜欢实用技巧
2. 选流量载体：第一人称视角拍维修/装修场景
3. 元素融入：产品在操作过程中自然出镜（拿扳手修东西、拿电钻打孔），不刻意介绍
4. 卖点展示：顺手好用/价格实惠/工具齐全，通过操作过程展示，不靠嘴说
5. 同城定位：拍的时候带门店定位，背景露出门店环境
