# 内容漏斗与流量分层要素

**不要一上来就卖产品。先让目标人群跟你产生共鸣，信任建立后你说什么她信什么。**

这个文件解决一个核心问题：拿到学员的信息后，怎么规划内容策略，让内容从泛流量一步步收口到精准客户。

---

## 核心方法论（非谈判项）

### 原则1：先共鸣，再卖货

很多潜在客户没有产品意识、没有需求。你直接讲产品，她划走。但如果你的内容先跟她产生了情感共鸣，她会觉得"这个人懂我"，然后你说的什么她都会信。

> 真实案例（女性养生赛道）：
> 学员做女性养生产品。不直接讲产品，先讲"养生先养心""养心最好的方式是保持好的心态""三四十岁女性在婚姻里怎么让自己越活越好""跟老公吵架之后怎么恢复自己的气血"。
> 这些都是大流量的女性情感+养生话题。目的是跟女性群体产生共鸣。共鸣建立后，再慢慢把产品引出来，"我们说我们的产品能帮助女性怎么怎么样，她会信的"。

### 原则2：泛相关，不跑偏

大流量内容不是什么热度和你无关的话题都做。必须跟你的赛道"泛相关" -- 话题本身是大众关心的，但受众群体和你的目标客户重合。

判断标准：
```
IF 这个话题的受众 = 你的目标客户群体
AND 这个话题的流量 >> 精准话题的流量
AND 这个话题能自然过渡到你的产品/服务
-> 这就是好的泛流量选题
```

> 示例：做女性养生的，"跟老公吵架后怎么恢复气血" = 泛相关（受众是三四十岁女性，能过渡到养生产品）
> 反例：做女性养生的，去追"某明星出轨"的热点 = 不相关（受众对不上，过渡不了）

### 原则3：一层一层往下筛

流量不是一步到位的。内容策略要像漏斗，从宽到窄一层层筛：

```
第1层（最宽）：泛流量共鸣内容
  -> 受众：你的目标人群 + 更大范围的同类型人
  -> 内容：大流量情感/生活/痛点话题，跟赛道泛相关
  -> 目的：拉新、建立共鸣、让算法识别你的受众标签

第2层（中）：精准流量内容
  -> 受众：已经对你产生兴趣的人
  -> 内容：围绕你的赛道做深度内容，展示专业性
  -> 目的：把共鸣转化为信任，筛出真正有需求的人

第3层（最窄）：转化型内容
  -> 受众：已经有信任基础、有需求的人
  -> 内容：产品介绍、案例展示、效果见证
  -> 目的：促转化，引导私信/到店/下单
```

### 原则4：精准流量少时往上扩

如果学员在精准流量层面跑不动（话题太窄、搜索量太小、没人看），不要死磕精准话题。往上扩一层，做大流量的泛相关内容，先把人群圈进来，再一层层往下筛。

```
IF 精准选题跑不出流量:
  -> 不要换赛道，往上扩一层
  -> 找到目标人群也关心的、但流量更大的话题
  -> 先做泛流量内容把人圈进来
  -> 再用精准内容筛，最后用转化内容收口
```

> 真实案例（高端管家赛道）：
> 学员做中式管家服务，招学员和接雇主。管家这个话题本身很窄，精准流量很小。
> 教练的策略不是死磕"管家"话题，而是往上扩：先做"中年失业想转行"的情感共鸣内容，再过渡到"管家比传统家政好在哪里"，最后引出管家培训。人群是一样的，但流量池大了10倍。

## 流量分层模型

对任何赛道，都要做三层流量分析：

### 第1层：泛流量池（共鸣层）

找到你的目标人群"还关心什么" -- 不是你的产品相关，是这个人相关。

方法：从人群画像出发，向上推导

```
你的目标客户是谁？
  -> 她是什么年龄段？
  -> 她在生活中面临什么问题？
  -> 她会刷到什么内容停下来？
  -> 这些内容跟你的产品能不能搭上？
```

行业举例：

| 赛道 | 目标人群 | 泛流量选题举例 | 过渡路径 |
|------|---------|-------------|---------|
| 女性养生 | 三四十岁女性 | 跟老公吵架后怎么恢复气血 / 婚姻中怎么越活越好 / 养生先养心 | 情感共鸣 -> 女性养生意识 -> 产品 |
| 高端管家培训 | 28-45岁想转行的中年人 | 中年失业怎么办 / 转行选什么行业好 / 什么工作包吃住还体面 | 转行焦虑 -> 管家行业介绍 -> 培训招生 |
| 二手车 | 想买车但预算有限的人 | 买新车还是二手车 / 怎么避免被坑 / 什么车性价比高 | 买车焦虑 -> 二手车优势 -> 到店看车 |
| 财税会计 | 小企业老板 | 创业踩过的坑 / 公司注册怎么省钱 / 被查税怎么办 | 经营痛点 -> 财税专业 -> 代账服务 |
| 疗愈 | 压力大的都市女性 | 为什么你总是很累 / 职场内耗怎么破 / 三十岁还迷茫怎么办 | 情绪共鸣 -> 疗愈需求 -> 疗愈服务 |
| 知识付费 | 想赚钱但没方向的人 | 普通人怎么月入过万 / 副业做什么好 / 为什么越努力越穷 | 焦虑共鸣 -> 方法论 -> 课程 |

### 第2层：精准流量池（信任层）

泛流量把人圈进来后，用精准内容建立专业信任。

方法：从你的产品/服务出发，向下拆解

```
你的产品解决什么问题？
  -> 这个问题的原因是什么？
  -> 你的方法跟别人的有什么不同？
  -> 你能输出什么专业内容让客户觉得你懂？
```

行业举例：

| 赛道 | 精准选题举例 | 信任建立点 |
|------|-------------|---------|
| 女性养生 | 气血不足的5个表现 / 为什么你越补越虚 / 正确的养生顺序 | 让她觉得"原来我一直做错了，这个人懂" |
| 高端管家培训 | 管家和保姆的区别 / 管家一个月能挣多少 / 怎么从零开始做管家 | 让她觉得"管家这个行业好，这个机构靠谱" |
| 二手车 | 买二手车怎么验车 / 哪些二手车不能买 / 二手车砍价技巧 | 让他觉得"这个老板不坑人，懂行" |
| 财税会计 | 小公司怎么合理避税 / 发票开的少怎么办 / 注册个体还是公司 | 让他觉得"这个会计专业，能帮我省钱" |

### 第3层：转化流量池（收口层）

信任建立后，用转化内容引导行动。

方法：给出明确的下一步

```
你的产品是什么？
  -> 客户为什么要选你？
  -> 怎么引导她来咨询/到店/下单？
  -> 信任基础够不够支撑她直接行动？
```

行业举例：

| 赛道 | 转化选题举例 | 引导动作 |
|------|-------------|---------|
| 女性养生 | 学员案例 / 产品使用前后对比 / 限时体验课 | 私信咨询 / 体验课报名 |
| 高端管家培训 | 学员就业案例 / 管家薪资展示 / 免费试听课 | 报名咨询 / 试听 |
| 二手车 | 到店实拍 / 车源展示 / 限时优惠 | 到店看车 / 加微信 |
| 财税会计 | 客户省钱案例 / 免费财税诊断 / 代账套餐价格 | 免费诊断 / 签约 |

## 内容漏斗规划流程

做账号策划时，按以下步骤为学员规划内容漏斗：

### 步骤1：拆目标人群

```
1. 你的客户是谁？（年龄/性别/职业/收入/地域）
2. 她现在的生活状态是什么？（在做什么/面临什么问题）
3. 她有没有你的产品意识？（有需求/无需求但可教育/完全 unaware）
4. 她平时会刷什么内容？（什么内容能让她停下来）
```

### 步骤2：搭三层流量池

```
第1层 泛流量：找到目标人群关心的、流量大的、能过渡到你赛道的话题
  -> 列10-20个泛流量选题方向
  -> 每个方向标注：受众是谁、怎么过渡到第2层

第2层 精准流量：围绕你的赛道做深度内容，展示专业
  -> 列10-15个精准选题方向
  -> 每个方向标注：展示什么专业度、怎么建立信任

第3层 转化流量：引导客户行动
  -> 列5-8个转化选题方向
  -> 每个方向标注：引导什么动作、信任基础够不够
```

### 步骤3：排内容节奏

```
第1-2周：以泛流量内容为主（配比参考 SKILL.md 三类内容配比表）
  -> 目标：快速跑流量，让算法识别受众标签
  -> 重点选题：共鸣型、痛点型

第3周：增加精准流量内容比重
  -> 目标：把泛流量筛成精准流量
  -> 重点选题：专业型、对比型、干货型

第4周：转化内容收口
  -> 目标：引导有信任基础的客户行动
  -> 重点选题：案例型、见证型、促销型
```

### 步骤4：校准漏斗

跑一周后看效果：
- 泛流量内容跑不出流量 -> 泛的方向不对，换更宽的话题
- 泛流量有量但不涨粉 -> 内容没建立共鸣，选题或表达要调
- 涨粉但不进精准内容 -> 过渡不自然，第1层到第2层的桥梁要搭好
- 精准内容没人看 -> 信任基础不够，回退到第1层继续做共鸣

## 教练指导要点

教练老师在给学员做账号策划时，必须把这个漏斗逻辑讲清楚：

1. **先问学员：你的客户是谁？她平时关心什么？** -- 不是问"你想拍什么"，是问"你的客户会刷到什么停下来"
2. **帮学员找到泛流量选题** -- 学员通常只想到精准话题（直接讲产品），教练要引导往上扩一层
3. **搭好过渡桥梁** -- 每个泛流量选题都要想好"怎么自然过渡到产品"，过渡不了的不做
4. **排好节奏** -- 不是一开始就做转化内容，先做共鸣，再做专业，最后做转化
5. **每周校准** -- 看泛流量有没有跑起来、精准内容有没有建立信任、转化内容有没有人咨询

**学员常见误区（教练要提前纠正）：**
- "我要直接讲产品" -> 不行，没有信任基础，讲了也没人信
- "泛流量话题跟我的产品没关系" -> 要的是跟人有关，不是跟产品有关
- "我做了一周泛流量还没转化" -> 漏斗需要时间，先建共鸣再筛精准
- "我的赛道太窄了跑不出流量" -> 往上扩一层，找目标人群也关心的大流量话题

## 内联案例库

### 案例1：女性养生赛道的漏斗设计

**学员背景**：做女性养生产品（如养生茶/养生课程），目标客户是三四十岁女性。

**漏斗设计**：
```
第1层 泛流量（共鸣）：
  - "养生先养心，养心最好的方式是保持好的心态"
  - "三四十岁女性在婚姻里怎么让自己越活越好"
  - "跟老公吵架之后怎么恢复自己的气血"
  -> 受众：三四十岁女性（远大于养生产品受众）
  -> 过渡路径：情感共鸣 -> 女性养生意识 -> 产品

第2层 精准流量（信任）：
  - "气血不足的5个表现，你中了几个"
  - "为什么你越补越虚"
  - "正确的养生顺序，90%的人都搞反了"
  -> 信任建立：让受众觉得"这个人懂养生，我以前做错了"

第3层 转化流量（收口）：
  - 学员使用产品后的真实变化
  - 养生课程内容展示
  -> 引导：私信咨询 / 体验课报名
```

**核心逻辑**：很多女性没有养生意识、没有产品需求。直接讲产品她划走。先用大流量情感话题跟她共鸣，"她说什么就是什么了"，再引出产品，她才会信。

### 案例2：高端管家赛道的漏斗设计

**学员背景**：做中式管家服务，招培训学员。管家话题窄，精准流量小。

**漏斗设计**：
```
第1层 泛流量（共鸣）：
  - "中年失业怎么办，什么工作包吃住还体面"
  - "转行选什么行业，35岁还不晚"
  - "月入过万还包吃住的工作真的存在吗"
  -> 受众：28-45岁想转行的中年人（远大于管家受众）
  -> 过渡路径：转行焦虑 -> 管家行业介绍 -> 培训招生

第2层 精准流量（信任）：
  - "管家和保姆的区别，收入差多少"
  - "管家一个月到底能挣多少"
  - "怎么从零开始做管家"
  -> 信任建立：让受众觉得"管家这个行业好，值得转"

第3层 转化流量（收口）：
  - 学员就业案例展示
  - 管家薪资真实见证
  -> 引导：报名咨询 / 免费试听课
```

**核心逻辑**：管家话题太窄，精准流量跑不动。往上扩一层做"中年转行"的大流量话题，人群一样，流量池大10倍。共鸣建立后再筛到管家。

## 说话风格

1. **先问客户是谁，再定内容方向。** 不问"你想拍什么"，问"你的客户平时刷到什么会停下来"。
2. **泛流量选题要讲为什么选。** 不是随便给一个大流量话题，要说清楚"这个话题的受众就是你的客户，能过渡到你的产品"。
3. **过渡路径要搭好。** 每个泛流量选题都要说清楚"从这个话题怎么过渡到你的产品"。
4. **节奏不能急。** "先做共鸣再做转化"不是建议，是漏斗逻辑，跳过共鸣直接转化没效果。

**绝对不要做的事：**
- 不要让学员一上来就做产品介绍内容（没有信任基础）
- 不要给泛流量选题不搭过渡路径（做了共鸣但接不上产品）
- 不要让学员死磕精准话题跑不出流量（往上扩一层）
- 不要跳过第1层直接做第2层（没有共鸣基础，精准内容没人看）
- 不要把三层内容混着发没有节奏（先泛后精再转化）
