# 每日巡检要素

## 输出契约（今日工作台的格式硬约束，发出前逐字段打勾）

| 字段 | 必填 | 格式 | 示例 |
|------|------|------|------|
| 工作台标题+统计 | 是 | 日期 + 🔴/🟡/🟢 三色人数统计 | 🔴今日必做2人 |
| 🔴 今日必做 | 是 | 姓名 + 原因 + 建议动作 + 可直接复制的话术 | 张三，有待评价视频 |
| 🟡 今日跟进 | 是 | 姓名 + 原因 + 建议动作 | 李四，今日作业未布置 |
| 🟢 观察 | 是 | 姓名 + 一句话状态 | 王五，一切正常 |
| 优先级排序 | 是 | 🔴→🟡→🟢 顺序列出，不混排 | |

优先级判定标准以本文件第三节为准；老师侧的巡检报告（钉钉巡检 md）不走本契约，按 24 号输出纪律走。

---

**核心目标：** 每天老师上班第一件事，把学员交付文件夹地址发给AI，AI自动扫描所有学员文件夹，按优先级排序输出今日工作台：今天谁需要对接、发什么信息、聊什么话题。

---

## 一、触发条件定义

当老师发送的消息满足**以下任一条件**，判定为"每日巡检请求"，进入 Phase 00。

`
IF 消息内容满足以下任一条件：
  ① 以盘符或绝对路径开头（如 E:\\、C:\\）
  ② 包含"所有学员"或"全部学员"
  ③ 包含"今天" 且同时包含（"需要"/"要做"/"安排"/"工作"/"汇总"/"看一下"）中的任一
  ④ 包含"巡检"/"晨检"/"上班第一件事"/"先看看" 等关键词
  ⑤ 首次使用且发送了文件夹路径（如 "E:\\学员交付"）
  
  → 进入 Phase 00：每日晨间巡检
ELSE：
  → 继续走原本的消息来源判定（Phase 路由）
`

**注意：**
- 如果老师发送了地址同时说了"帮我看看张三"——先做巡检扫全部学员，再单独处理张三
- 如果老师只发地址没说明意图——默认进每日巡检
- 如果老师只发"今天需要做什么"但没提供地址——从记忆中读取已有地址，如果没有就问老师要

---


**日期与记忆说明（重要）：**
- 这个skill是在同一条对话里持续使用的，不是每天新建任务
- 第一次使用时需提供文件夹地址，AI记住该地址
- 之后每天只需要说"今天需要做什么"，不用再发地址
- AI自动识别当前日期，判断是新的一天还是同一天
- 同一天内再次请求 -> 复用上次结果
- 新的一天（日期变了）-> 自动重新扫描
- 最后巡检日期由AI自动记忆

## 二、学员状态扫描清单

每次巡检时，对每个学员文件夹执行以下扫描：

### 2.1 必须读取的文件和字段

| 文件路径 | 读取字段 | 用于判断 |
|---------|---------|---------|
| /学员名/学员档案.md | 行业类型、变现路径、出镜意愿 | 基础信息 |
| /学员名/学员档案.md | 规划状态、当前周次、已完成作业数、最新评价 | 当前进度 |
| /学员名/学员档案.md | 待办事项列表 | 今日待办 |
| /学员名/03_作业与排期/ | 最新的作业卡（按时间排序） | 今日作业是否已布置、作业状态 |
| /学员名/04_视频评价/ | 最新的评价记录（按时间排序） | 是否有待评价视频 |
| /学员名/00_对话存档/ | 最近1次对话的内容 | 学员最近情绪状态、是否有未处理消息 |
| /学员名/00_对话存档/ | 最近对话的日期 | 是否长时间未互动 |

### 2.2 文件夹状态特殊标记

| 状态 | 判定条件 | 处理方式 |
|------|---------|---------|
| 待初始化 | 只有学员档案.md未填写 | 不归入优先级，提醒老师"该学员还未开始" |
| 正常跟进 | 有档案+有作业记录+近期有互动 | 按正常优先级判断 |
| 已毕业 | 学员档案.md中标记为"已完成" | 不归入优先级，备注"已毕业" |
| 休眠 | 超过2周无互动记录 | 归入🟢观察 |
| 新学员 | 刚建文件夹，只有基础信息 | 提醒老师需要做账号规划 |

## 三、优先级判定表

### 🔴 今日必做（高优先级）

满足以下任一条件即判定为🔴：

| 条件编号 | 判定依据 | 检查方式 |
|---------|---------|---------|
| R1 | 有学员提交了视频但还没评价 | 最新评价记录中有"待评价"标记，或04_视频评价/中有未评价的日期 |
| R2 | 有学员发了消息但老师还未回复 | 00_对话存档/最新记录的结尾是学员问题，没有AI的回复 |
| R3 | 今天已经过了半天(12:00后)但今天的作业还没布置 | 03_作业与排期/中今日无作业记录 |
| R4 | 学员处于冷启动期(第1-2周)且超过2天没有新作业 | 学员档案.md 当前周次<=2 且 最新作业日期距今>2天 |
| R5 | 最近一次对话记录显示学员有情绪问题 | 最新对话存档中包含"没信心/不想拍了/是不是不适合/为什么别人可以"等情绪词 |
| R6 | 学员在第1-3周，未完成作业数超过3条 | 03_作业与排期中标记"未提交"的作业>3条 |

### 🟡 今日跟进（中优先级）

满足以下任一条件即判定为🟡：

| 条件编号 | 判定依据 | 检查方式 |
|---------|---------|---------|
| Y1 | 今天的作业还没布置（正常情况，非R3场景） | 03_作业与排期中今日无作业记录（且非下午） |
| Y2 | 昨天布置的作业学员还没提交，需要提醒 | 最新作业状态为"已布置未提交" |
| Y3 | 正在做方案确认阶段（老师发方案后等学员确认） | 学员档案.md 待办中有"等待学员确认" |
| Y4 | 学员刚完成冷启动期(第3周结束)，需要调整内容配比 | 当前周次=3或4，且未做配比调整 |
| Y5 | 到了周复盘节点（周五/周六） | 日期是周五或周六 |

### 🟢 观察（低优先级）

满足以下全部条件：

| 条件编号 | 判定依据 |
|---------|---------|
| G1 | 学员进度正常，无待办事项 |
| G2 | 今天的作业已布置或今天不需要布置 |
| G3 | 无待评价视频 |
| G4 | 学员情绪稳定，无异常表现 |
| G5 | 最后一次互动在3天以内 |

### 同优先级内排序规则

按以下顺序排序（从上到下越靠前越紧急）：

`
1. 🔴 R2（有未回复学员消息） > R1（有待评价视频） > R5（有情绪问题） > R3/R4/R6
2. 🟡 Y2（需要提醒交作业） > Y3（等确认） > Y1（未布置作业） > Y4/Y5
3. 🟢 按最后一次互动时间排序，越久越靠前
`

---

### 每日消息回复三步法（防埋雷，强制）

巡检不止扫文件夹，还要提醒老师把当天的学员消息回复节奏走完。每天必须走完三步，防止埋雷：

```
Step 1 · 浏览所有消息，优先处理紧急
  包括前一天晚上群里销售对接的重点学员——先抓重点，再处理常规
Step 2 · 回到第一个学员，按顺序逐一回复
  逐个浏览，确保无遗漏
Step 3 · 按日期标签全量复查
  点击日期标签（如「7月30日」），把每个学员全部再看一遍
  检查漏回复、长时间没「动弹」的人
```

核心原则：**千万不要出现「好长时间没有联系的学员」。**
输出今日工作台时，把超过3天没互动的学员标出来，提醒老师今天必须主动回复一句——学员长时间没「动弹」就是退费前兆。

## 五、话术生成规则

不同状态下需要不同的话术风格和内容。

### 5.1 状态R1：有待评价视频

`
话术结构：
  开头："看到您昨天的新视频了，我仔细看了几遍..."
  先问感受："您自己觉得拍得怎么样？"
  再给评价（按09_视频评价要素）：
    - 先说好的1个点（建立信心）
    - 再说最需要改进的1-2个点（不要一次性甩完）
    - 给具体改进建议
  最后："下一条咱们这样拍：{一句话方向}"

注意事项：
  - 不要一次说太多问题，学员记不住
  - 先说好的，再说不好的（三明治法则）
  - 具体的改进建议比"下次注意"有用100倍
`

### 5.2 状态R2/R3/R6：需要布置作业

`
话术结构：
  开头看情况：
    - 正常情况："今天咱们继续推进，第X天作业来了！"
    - 需要提醒提交时："昨天布置的作业做得怎么样了？有什么困难吗？我来帮您调整一下"
    - 进度滞后时："这两天感觉怎么样？咱们调整一下节奏，今天先做个小作业找回感觉"
  作业卡内容（按72变法给框架）：
    - 变法名称
    - 作业要求
    - 示例
    - 拍摄建议
  结尾："拍完发群里，我帮您看"

注意事项：
  - 作业卡只发正文，不发拍摄指导
  - 每个作业对应一个72变变法
  - 作业要具体到学员能直接拍，不需要自己想创意
`

### 5.3 状态R5：学员情绪问题

`
话术结构（调用 要素定义库/12_消息识别与问题分类要素.md 情绪急救流程）：
  第一步：接住情绪
    "最近是不是遇到什么问题了？没事，说说看"
    "您说的这个情况我理解，刚开始做视频确实容易这样"
  第二步：给新视角
    "其实您刚才说的这个问题，在抖音上有一个很简单的解法..."
    "您看这个账号，一开始也是..."
  第三步：给具体下一步
    "咱们今天先做一个最简单的：{具体到可执行的1个动作}"
  第四步：建立信心
    "做视频就是这样的，前面10条最难，后面的就顺了"

注意事项：
  - 绝不说"这很正常""别急慢慢来""坚持就是胜利"
  - 用"咱们"不用"你应该"
  - 先共情再给方法
  - 给的动作必须是今天就能做的
`

### 5.4 状态Y2：需要提醒交作业

`
话术结构：
  "昨天给您布置的作业做了吗？"
  "有什么不顺畅的地方吗？我来帮您调整"
  "不用都做到完美，先拍一条出来发给我看看就行"

注意事项：
  - 不要说"你还没交作业"（让人反感）
  - 问"有什么困难"比催交效果好
  - 降低门槛："先拍一条看看，不要求完美"
`

### 5.5 状态Y3：等待确认

`
话术结构：
  "上次我们聊的方向，您觉得怎么样？"
  "有什么不太对的地方吗？我们可以再调整"
  "如果没有问题的话，咱们就按这个方向推进了"

注意事项：
  - 给学员一个"可以说不"的空间
  - 不要替学员做决定
`

### 5.6 状态🟢：一切正常

`
话术（如需跟进）：
  "今天怎么样？"
  "进度没问题的话继续保持"
  "明天需要开始第X天的作业了，准备一下"

注意事项：
  - 正常状态不需要太多话术
  - 简单确认即可
`

## 六、边界情况处理

| 情况 | 处理方式 |
|------|---------|
| 学员文件夹为空（刚创建未填信息） | 标记为"待初始化"，不归入优先级，提醒老师"该学员还未开始" |
| 学员已完成全部课程 | 标记为"已毕业"，不归入优先级 |
| 学员超过2周未互动 | 标记为"休眠"，归入🟢观察 |
| 某学员文件夹没有学员档案.md | 标记为"档案缺失"，提醒老师补全 |
| 所有学员都是🟢观察，无待办 | 输出"今天没有紧急需要处理的事项"，建议老师准备下周内容 |
| 只有一个学员 | 正常按巡检流程输出 |
| 学员数量超过20个 | 每个优先级分类中最多显示前10个，其余标注"还有N个..." |
| 同一天内再次请求巡检 | 先输出上次结果，问"需要重新扫描所有学员吗？"（老师每天说"今天需要做什么"时自动判断是新的一天还是同一天） |
| 老师提供的地址无效或不存在 | 提示地址无效，让老师重新提供 |

## 八、周抽检：输出质量回归（双轨质检，每周五做）

日常输出靠生成时自检（25号〇节定轨+SKILL.md说话检查），周抽检是第二道防线：从本周产出里抽一小批，用机器+人工复核双轨标准有没有持续守住。老师不用动手，巡检时顺带做。

**抽什么：** 每周五的巡检顺带抽本周产出——3份作业卡/评价表（老师轨契约）+3段已发学员的话术（从 00_对话存档/ 里抽最近三天发给学员的成品话术）。

**怎么检：**

1. **老师轨产出**（作业卡/评价表）：`python scripts/check_prose.py --contract 作业卡 文件.md`（或 评价表），缺字段清零。另外人工扫一眼：判断是否先行、一屏能否扫完。
2. **学员轨话术**：把话术单独存 md 后 `python scripts/check_prose.py --track 学员 话术.md`——黑话/硬停词/天数编号零容忍（失败级必须清零），称呼/语气词/电报腔提醒项人工判断。
3. **混轨检查**（人工，30秒）：抽到的话术里出现表格、术语、「风险等级」这类老师轨特征，或老师轨输出里出现「哈」「同学」，记一笔混轨——这是25号〇节「两轨隔离规则」的违例。

**结果处理：** 抽检全过，巡检报告末尾加一行「本周输出抽检：通过」。有违例，把违例原话和轨别记到当周周复盘（Phase 3 第6步文件维护），累计两周同类违例→按 tests/路由测试题库.md H组对应题型跑回归定位根因，是规则问题改25号，是遵循问题用「重新读取25号〇节双轨输出总则，再回答一遍」拉回。

**为什么要周检：** 生成时自检会被长对话稀释（第10轮后字段遵循率下降），机器契约查不出语义完整性，电报腔检测只有提醒级。三层各有盲区，叠起来才兜得住。
`
