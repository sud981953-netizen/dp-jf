# 借东风与投流放大要素（流量放大双打法）

> 本文件是创亿独创的两个流量放大方法：借东风（零成本，从同行爆款评论区借精准流量）+ 微付费投流法（花几块钱撬动上万流量）。
> 使用时机：1. 学员冷启动停滞、发了几条没流量；2. 学员问"怎么让更多人看到我"；3. 学员想投钱推广（DOU+/薯条/微信豆）；4. 实体店想做同城投放。
> 核心边界：这两个方法是放大器，不是救命稻草。内容没跑通，什么放大手段都白搭。

---

## 一、总纲：什么时候用哪个（if/else）

自然内容跑流量是基本盘，这两个是放大器，顺序不能乱：
先把内容跑通 -> 借东风借精准流量（零成本）-> 内容验证OK -> 微付费投流放大

```
IF 冷启动没流量/不想花钱 -> 借东风（第二章）
IF 有视频自然播放破过万 AND 想再放大 -> 微付费投流（第三章）
IF 内容还没跑通就想投钱 -> 拦住：投流救不了烂内容，先回 Phase 2 磨内容
IF 实体店想投流 -> 本地推优先（3-5公里），别用DOU+拿全国流量
IF 敏感行业 -> 投流前先查16号敏感行业速查表，有些行业投了也不过审
```

## 二、借东风（零成本引流）

### 2.1 一句话讲清楚什么是借东风

三国时周瑜限诸葛亮三天造出10万支箭，诸葛亮没有硬造，而是草船借箭——借来的箭一样能打仗。
做账号同理：靠自己短时间做出10万流量的作品很难，但流量可以借——同行的爆款作品已经聚集了大量精准客户，直接从那里借。

核心认知：同行的粉丝 = 你的客户。同行账号做得好，是因为他人群标签精准，他的粉丝、他的客户，本来就是你的精准人群。
万物均不为我们所有，万物皆可为我们所用——流量也能借。借船出海、借网打鱼、借鸡生蛋。

### 2.2 借的是什么：小蓝条引流原理

同行一条爆款（比如点赞7.6万、播放少说500万）-> 刷短视频的用户大多会看评论区，几百万人点进评论区 -> 评论区上方「大家都在搜」的小蓝条显示的是你的账号名 -> 哪怕只有几十万人点击，也直接跳转进入你的账号。

关键：小蓝条是平台生成的，任何人都删不掉。同行可以删你的评论，但删不掉小蓝条。

### 2.3 实操五步法（布置给学员的作业流程）

1. **搜行业**：打开抖音 -> 右上角放大镜 -> 输入行业关键词（水果搜水果、幼儿园搜幼儿园、茶叶搜茶叶，你是什么行业就搜什么）
2. **筛爆款**：点右上角小漏斗 -> 选「一周内」-> 找到同行刚发一两天、数据就很炸的作品（几万点赞的那种）
3. **小号评论区埋钩子**：点开这条爆款的评论区，用小号评论，话术默念两个字——「感觉」（模板见2.4）
4. **做搜索行为**：评论完 -> 长按自己这条评论 -> 点「搜索」-> 搜自己的账号 -> 进主页把自己的作品点赞、评论、收藏，重点看完（完播）
5. **重复3~5次触发小蓝条**：再回到同行评论区，上方「大家都在搜」的蓝色词条就会变成你的账号名——一点就进你的账号

### 2.4 「感觉」话术模板（各行业示范，可直接复制改编）

核心结构：感觉 + 同行的产品 + 没有 + 你的账号名 + 更好。
表面是替用户"货比三家"，实际是把自己的账号名种进精准人群的眼前。

- 感觉你们家的水果没有人家XX水果家的好吃。
- 感觉你们家的幼儿园没有人家XX幼儿园的服务好，老师更专业。
- 感觉你们家的英语没有人家XX教得更专业。
- 感觉你们家的家电没有人家XX家的品类多。
- 感觉你家的保险没有XX做保险的服务好，性价比更高。
- 感觉你家的精酿啤酒没有XX家的好喝。

### 2.5 关键注意点（漏一个动作就白做）

- **必须用小号评论**：没有小号可以用新手机号注册一个，评论无需实名认证
- **评论被删不影响效果**：小蓝条是平台生成的，谁都删不掉
- **找「一周内」的新爆款**：同行刚发一两天、数据正猛的作品，评论区流量最活跃，借流效果最好
- **重复3~5次才触发**：评论 -> 长按搜索 -> 进自己账号做数据，这套动作要重复几遍，小蓝条才会变成你的名字

### 2.6 方法本质（讲给学员听时用）

很多人做账号，习惯把希望寄托在运气上，等平台某一天给自己爆一个大流量。借东风恰恰相反——不等运气，主动借力。
同行经过长期养号、投流和内容打磨，已经把一批精准客户聚集在自己的评论区里。这批人对你的产品有真实需求、正处于活跃状态、正在消费相关内容——是最有价值的一群目标用户。
你不需要从头再把这群人聚集一遍。同行已经聚好了，你直接去借。一条评论、一个账号名、一个小蓝条，就能把同行几百万播放的势能，承接到自己的账号上。
起号的关键不在于从零开始，而在于懂得借势。

### 2.7 教练布置话术（可直接复制发给学员）

```

第一步，抖音搜你的行业关键词；
```

## 三、微付费投流法（花几块钱撬动上万流量）

### 3.1 投流的本质：放大器，不是魔法棒

投流不是「花钱买流量」，是「花钱买精准的人」。
视频发出去，平台先推300-500个人看，数据好继续推，数据不好停——这叫自然流量，但自然流量有天花板：你拍得再好，算法不给你推到对的人面前，也白拍。投流就是跳过算法慢慢试的过程，直接花钱让平台把视频推到你想找的那群人面前。

铁律：投流不能救烂内容。内容好，放大爆；内容差，放大自己的错误。
节奏：先测后放大——100元测方向 -> 数据好加投 -> ROI>1再追加。
正确姿势：先跑通自然流量，再用投流放大。哪天有一条视频自然播放破了1万、评论区互动也热闹——这时候投100块推一把，看能不能冲到10万。这叫「放大爆款」，不叫「拿钱买命」。

### 3.2 投流前置判定（if/else，不满足就别让学员花钱）

```
IF 还没有一条自然播放破万的视频 -> 不投，先回 Phase 2 磨内容
IF 要的是客户咨询 -> 投放目标选「主页访问」或「获取客户」，不选涨粉
   （前提：主页简介和作品能让人看完想咨询，先过08号简介要素+22号主页搭建）
IF 新号前3条作品 -> 走3.4打标签法，先把账号标签打上
IF 第4条作品起 -> 走3.5隐藏法，几块钱撬流量
IF 多平台 -> 只投主做的那个平台，测通了再考虑跨平台
IF 敏感行业 -> 先查16号速查表，确认能过审再投
```

### 3.3 四大平台工具速查

**抖音**

| 工具 | 适合 | 目标 | 预算/说明 |
|------|------|------|----------|
| DOU+（抖加） | 新号测方向/涨粉/加热视频 | 涨粉/点赞评论/主页点击 | 100-300元测试，自动出价，配比70%自然+30%DOU+ |
| 巨量千川 | 带货/直播间引流/商品转化 | 直播间成交/商品转化 | 定向地域+兴趣标签，ROI参考>2.5（美业），抖店后台开户 |
| 抖音AD（巨量广告/巨量引擎） | 品牌曝光/线索收集 | 品牌投放 | 门槛高预算大，新手不碰，先用DOU+和千川跑通再说 |
| 巨量本地推 | 实体店专属 | 团购/留资/到店 | 按地理位置推送，日预算100元起测 |

本地推 vs DOU+（实体店必须分清）：
DOU+推的是喜欢看你这类内容的人（可能全国各地的都有），本地推推的是住在你店附近的人。
开店的优先用本地推，别用DOU+拿全国的流量——外地人不可能来你店里。
用法：抖音搜「巨量本地推」-> 认领你的门店 -> 设置投放范围（3-5公里）-> 选投放目标（团购/留资/到店）-> 日预算100元起测。
适合：餐饮、美业、口腔、教培、家政、装修等一切有实体门店的行业（联动15号）。

**小红书**

| 工具 | 适合 | 目标 | 预算/说明 |
|------|------|------|----------|
| 薯条 | 个人号/品牌号加热笔记 | 笔记曝光/互动/涨粉 | 75薯条币起（约75元），笔记发布后右上角「…」-> 薯条推广，配比70%自然+30%薯条 |
| 聚光平台 | 企业号/品牌/商家 | 种草/客资收集/商品推广 | 需企业号认证，日预算300元起 |

**视频号**

| 工具 | 适合 | 目标 | 预算/说明 |
|------|------|------|----------|
| 微信豆加热 | 视频号创作者加热内容 | 视频播放/直播观众 | 1元=10豆，视频/直播「…」-> 加热，操作简单类似DOU+ |
| ADQ（腾讯广告） | 品牌/商家/专业投放 | 精准投放/线索收集 | 需开通腾讯广告账户，定向精准专业度高 |

一句话选平台：做抖音用DOU+测、千川转；做小红书用薯条测、聚光转；做视频号用微信豆测、ADQ转。不管哪个平台，都是先测后放大。

### 3.4 微付费打标签法·第一步：前3条作品打标签

每发一条新作品做一遍，3条做完平台就知道你是干什么的、要什么人了。

1. **选刚发的，立刻投**：旧视频已经跑不动了。发了立刻投——种树苗种下去就固定，长歪了拉不回来
2. **选「内容加热·点赞评论」**：不选粉丝经营（来的是老头老太太），不选获取客户（没数据没信任）
3. **选「保证播放·自定义·达人相似」**：不选最大点赞；性别/年龄/地域全不选
4. **找10个同行填达人相似**：全国选2万-20万粉，同城选2万-10万粉；用飞瓜/蝉妈妈/考古家查
5. **投放时长选12小时**：2h/6h太短糊弄你，18h/24h太长灌水，12h刚好够平台跑完定向

### 3.5 微付费打标签法·第二步：第4条起用隐藏法

流程：投100元 -> 跑1小时 -> 隐藏 -> 放出来 -> 实际只花3-5块。
系统通知消耗1-5块，剩下95块退回你的账户。下次再投，补3-5块就够了——不是一次性砸大钱，是每次花几块钱，持续撬。

注意：每条作品消耗金额不同（1-5块），因为内容不同。花3块就补3块，花5块就补5块——别多充，只补消耗掉的。

### 3.6 每条评论都要回（免费二次加热）

你回一条 -> 评论数变2条 -> 用户回来看 -> 视频还在放 -> 播放量跟着涨。回评论 = 免费二次加热。

### 3.7 投流翻车实录（6条避坑，学员踩坑时直接对照）

| 翻车现场 | 原因 | 改法 |
|---------|------|------|
| 投了好几百，一个咨询都没有 | 投的是「涨粉」或「点赞」，不是「主页访问」或「获取客户」；涨粉来的都是看热闹的，不是想买东西的 | 要咨询就选「主页访问」或「获取客户」；先把主页简介搭好（22号+08号），让人看完想咨询 |
| 投了100块，半小时用完，什么都没得到 | 投放时长选太短，平台来不及找精准用户，只能灌水充数 | 时长选12小时，让平台有足够时间找到对的人 |
| 投流来的全是老头老太太 | 选了「智能推荐」或「粉丝经营」，平台为了完成任务推给最容易停留的人 | 用「自定义人群」->「达人相似」-> 填10个同行账号，把人群主动权拿回来 |
| 达人相似选了头部大号，洗不动 | 几百万粉的大号粉丝粘性极强，看到你也不会关注你——你不是那个大V | 找2万-20万粉的中腰部账号，粉丝活跃、粘性没那么强、更容易转化 |
| 本地推全是外地人打电话问能不能发货 | 投放范围没设好，选了全市甚至全省 | 范围设3-5公里，开店的客户就在你周边，别贪大，圈越小越精准 |
| 投了5条视频4条亏了，心态崩了不投了 | 把投流当成赌博，期望每条都爆；实际投流是测试，10条里有1-2条好的就不错 | 投流的目的是用100块测出好方向：坏的停了，好的放大。亏小钱找方向，赚大钱靠放大 |

### 3.8 视频号挂车投流避坑（一线实战，仅挂车场景用）

视频号短视频挂车投放 ≠ 直播间投放。很多培训用直播间的逻辑教短视频投流，完全是两码事——直播间是实时数据+人货场搭着跑的，短视频是素材驱动。

1. **新号出价怎么设**：新号权重低，挂车投成交计划出价会略高，一般是佣金的1.2倍左右，个别品需出到客单价的0.7倍。启动后ROI不会很正——只要有消耗就行。消耗太快 -> 停止计划 -> 重建 -> 出价往下压10个豆 -> 找到消耗速度和ROI的平衡点
2. **ROI计划别上来就建**：ROI计划需要更精准的人群，必须等成交计划先跑出一定单量、有了人群数据积累，再建才有意义。顺序：先成交 -> 积累数据 -> 再ROI
3. **多素材必须同一链接**：不同链接=不同产品=佣金率不同=人群定向不同，混在一个计划里数据乱七八糟。只把同一个产品链接下的多个素材放一个计划
4. **短视频挂车不需要圈人群**：短视频内容本身就是定向——前三秒已经决定了谁留下、谁划走。圈了人群反而窄 -> 不消耗 -> 即使消耗了ROI也不正

总结：先跑成交计划积累数据 -> 再建ROI计划 -> 同链接多素材 -> 不圈人群。

## 四、边界与联动

### 4.1 与「不看后台数据」原则的边界（不冲突）

- 评价视频内容好坏：仍然用眼睛看（09号视频评价要素），不看后台数据
- 投流的消耗/ROI：是学员自己广告账户里的操作依据，用来决定「停还是加投」，不是用来诊断视频质量的
- 一句话：数据管钱花不花，眼睛管视频好不好

### 4.2 联动文件

- 15_实体店专项策略要素：实体店投流一律本地推优先（3-5公里），别拿全国流量
- 16_打量逻辑与敏感行业策略：敏感行业投流前先查速查表，不过审的行业别浪费钱
- 08_简介要素 + 22_主页搭建：投「主页访问/获取客户」之前，主页四件套必须先搭好，否则流量进来接不住
- 14_变现路径：投流目标跟着变现路径走（要咨询投获取客户，要卖货投商品转化）

### 4.3 核心金句

1. 万物均不为我们所有，万物皆可为我们所用——流量也能借
2. 同行的粉丝、同行的客户，就是你的精准客户——跟同行借
3. 评论删得掉，小蓝条删不掉——那是平台的
4. 不等运气等爆款，主动出击借爆款
5. 投流是放大镜，不是魔法棒——好内容放大10倍，烂内容放大自己的错误
6. 不是投得越多越好，是投得越准越好
7. 亏小钱找方向，赚大钱靠放大
