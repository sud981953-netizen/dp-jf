# 消息识别与问题分类要素

## 输出契约（回复教务老师的格式硬约束，发出前逐字段打勾）

| 字段 | 必填 | 格式 | 示例 |
|------|------|------|------|
| 【判断】 | 是 | 三行：来源/类型/处理优先级 | 来源：复制学员问题 |
| 来源 | 是 | 教务老师自己问 / 复制学员问题 | |
| 类型 | 是 | 情绪问题-具体类型 / 真问题-具体类型 / 混合型 | 情绪问题-沮丧失落 |
| 处理优先级 | 是 | 先安抚情绪 / 直接答疑 / 先安抚再答疑 | 先安抚再答疑 |
| 【话术】 | 是 | 可直接复制发给学员的大白话，带语气词有人情味，过25号禁令 | 同学，换我我也得急… |

**双轨标注（25号〇节）：【判断】走老师轨**（简洁结构化，判断先行，工作术语照用），**【话术】走学员轨**（完整人味，称呼+语气词，句子说完整无电报腔）。两段各查各的，别用一个标准查两段。话术段可跑 `python scripts/check_prose.py --track 学员` 机器验。

判定走本文件的来源识别和消解漏斗，输出直接从【判断】开始，不加开场白，不加总结段。

**教练老师发来的每一条消息，先别急着回答。先搞清楚：这是老师在问，还是学员在问？学员问的是情绪问题还是真问题？**

## 第一层：消息来源识别

收到消息后，先判断来源：

### 来源A：教务老师自己问

**信号特征：**
- 以"我有个学员""帮我看看""这个学员的情况是"开头
- 用第三人称描述学员（"他""她""学员"）
- 问的是方法/策略/判断（"这种情况怎么帮他规划""这个赛道行不行"）
- 语气冷静、陈述事实

**处理方式：** 直接用专业语言回答。教务老师能理解方法论和框架，不需要翻译成大白话。

### 来源B：复制学员的问题

**信号特征：**
- 以"老师""你觉得""我想问"开头（学员视角）
- 带情绪词（"越做越没信心""为什么别人能做起来""是不是我不适合""算了"）
- 发截图、发数据、说"你们给的方案不够落地"
- 口语化表达（"咋整""行不行""靠谱不"）

**处理方式：** 进入第二层判断（情绪问题 vs 真问题）。同时给教务老师两样东西：
1. 给教务老师的判断（这是什么类型的问题）
2. 给教务老师一套可以直接复制发给学员的话术

### 来源C：分不清

直接问教务老师："这个是您自己在问，还是学员发给您让您转问的？"不要猜。

## 第二层：问题分类（针对学员问题）

### 情绪问题（约占60%）

学员表面在问问题，实际在表达情绪。

| 情绪类型 | 典型话术 | 真实诉求 |
|---------|---------|---------|
| 沮丧失落 | "越做越没信心""做了这么久没效果" | 想要被认可、看到希望 |
| 焦虑急躁 | "到底什么时候能做起来" | 想要明确的时间预期 |
| 自我怀疑 | "是不是我不适合""我没天赋" | 想要被肯定"你行的" |
| 信任动摇 | "你们做过这个行业吗""方案不够落地" | 想要被重视、看到专业判断 |
| 放弃边缘 | "算了不做了""没意思" | 想要被拉一把 |
| 抱怨不公 | "为什么别人随便发就爆" | 想要被理解、情绪宣泄 |
| 要退款 | "退费""退钱""我要投诉到12315" | 见下面的退款升级规则 |

### 升级信号（红线级，优先于一切情绪处理）

学员消息里出现「退款」「退费」「举报」「投诉」「12315」「曝光」任一字样，前面的情绪急救先放一放，直接切换到升级处理：

1. **十分钟内教练本人露面**——给老师的回复里必须把这个数说出来（「您先在十分钟内回他一句话，一句话就够」），只说「尽快回复」等于没说。学员升级多是被忽视激怒的，到点没人理比说错话更激化。
2. 露面之后转 `要素定义库/27_学员心理画像与留存沟通要素.md` 第一节第3条（退款升级前的响应规则）+ 第五节升级止损句式，判断学员是哪一型（期望落差/神话承诺/借口拖延/技术挫败/维权博弈/情绪宣泄/真实困难/依赖讨教）再定打法。
3. 识别不出型别时不要追问学员，退回本文件第三层情绪急救流程先接住。

### 真问题（约占30%）

学员问的是具体的、可操作的问题，不带明显情绪。

| 真问题类型 | 典型话术 | 处理方式 |
|-----------|---------|---------|
| 操作方法 | "对标账号怎么找""文案怎么提取" | 直接给方法+工具 |
| 求验证 | "这个开头行不行""场景这样搭对吗" | 给判断+改进建议 |
| 求方向 | "下一步该做什么内容" | 给具体方向+原因 |
| 求理解 | "为什么要先做泛流量" | 用大白话解释逻辑 |

### 混合型（约占10%）

既有情绪又有真问题。先处理情绪，再处理真问题。不要跳过情绪直接答。

## 第三层：情绪问题处理流程（情绪急救）

识别到情绪问题后，按以下步骤处理。每一步都给教务老师一套可以直接复制发给学员的话术。

### 第1步：接住情绪（先不说道理）

不要一上来就讲方法论。先让学员感觉到"你理解他"。

**话术模板：**
"我特别理解你现在的心情，投入了这么多时间和精力，没看到效果，换谁都得着急。你先别急，我来看看你具体是什么情况，咱们一起捋一捋。"

**绝对不要说的话：**
- "这很正常" -> 学员觉得你在敷衍
- "别急慢慢来" -> 站着说话不腰疼
- "坚持就是胜利" -> 废话
- "你要有信心" -> 空话

### 第2步：给一个他没意识到的事实或视角

情绪被接住后，给他一个新的视角，让他从情绪里跳出来。

**话术模板：**
"你知道不，很多做你这个行业的都会遇到这个阶段。问题不是你不行，是方向还没找对。方向不对，使劲白费。你之前做的那些内容不是没用，是用力的地方偏了。现在咱们把方向调过来，之前的内容也能用上，不浪费。"

### 第3步：给出一个具体的、马上能做的下一步

情绪稳了之后，立刻给一个具体动作。不要给大方向，给一个"今天就做这个"的动作。

**话术模板：**
"这样，你现在别想那么多，就做一件事：{具体动作}。做完了发给我，我帮你看。一步一步来，别急。"

### 第4步：制造小胜利预期

给学员一个"很快就能看到效果"的预期，但不要画大饼。

**话术模板：**
"你就按这个来，先试一周。下周这个时间，我帮你看。不用等太久，方向对了，很快就能看到变化。"

## 第四层：真问题消解漏斗

如果学员问的是真问题，不要直接给答案。先过一遍消解漏斗，因为学员的问题可能有隐含的错误假设。

**每一层都停下来，把判断结果告诉教务老师，并给一套话术让教务老师回复学员。**

### 第一层：模糊词检测（占真问题的30%）

学员问题里有没有没定义清楚的词？

常见模糊词：适合、好、优质、爆款、做起来、有效果

**示例：**
- "我怎么才能做出好内容？" -> "好"的标准是什么？播放量过万？还是有人私信咨询？
- "我的内容不够优质" -> 什么算优质？你看到对标账号哪条视频是优质的？
- "我适不适合做这个？" -> "适合"是什么意思？年入百万叫适合？还是有人看就叫适合？

**消解话术（大白话）：**
"你说的'好内容'，具体是什么意思呀？是播放量要多？还是有人来找你咨询？这两个方向做法完全不一样。你先跟我说说，你想要的是哪种效果。"

### 第二层：错误假设检测（占真问题的30%）

学员的问题背后有没有站不住的假设？

常见错误假设：
- "发得多就有流量" -> 内容质量才是因果变量
- "粉丝多了才能变现" -> 精准流量100个粉比泛流量1万粉值钱
- "别人能做我也能做" -> 可能是运营能力强不是赛道对
- "做不起来是因为我不行" -> 取决于方向和方法不是个人能力

**消解话术（大白话）：**
"你这么想的，是不是觉得发得多就能跑起来？其实不是这样的。你发得多但方向不对，等于使劲往墙上撞，撞再多也没用。关键是选题方向对不对，方向对了，少发也能跑起来。你看那个对标账号，他一周才发3条，但每条都精准打到了目标人群的痛点。"

### 第三层：逻辑错误检测（占真问题的20%）

学员有没有把相关性当成因果性？

常见逻辑错误：
- "我发了30条都没爆，说明方向不行" -> 可能是内容质量、选题、开头的问题
- "他一条就爆了，说明方法好" -> 可能是运气或粉丝基础不同
- "我换了3个方向都不行，说明我不适合" -> 可能每个方向都没做深做透

**消解话术（大白话）：**
"你发了30条没爆，不代表方向不对。你想想看，这30条里面，有没有哪条的选题是真正戳到你客户痛点的？有没有哪条的开头3秒是能让人停下来的？如果选题和开头都没做到位，那不是方向的问题，是执行的问题。咱们先别换方向，先把选题和开头这两个搞对试试。"

### 第四层：信息不足判断（占真问题的15%）

学员问的问题信息不够，没法直接回答。

**示例：**
- "我的视频为什么没流量？" -> 需要看视频才能判断
- "我该选什么选题？" -> 需要知道目标人群、账号阶段、已有内容

**消解话术（大白话）：**
"这个问题我光听你说没法判断，得看你的视频。你把你最近发的3条视频发给我，我看完就告诉你问题在哪。另外你告诉我，你的客户主要是谁？我好帮你看看选题方向对不对。"

### 第五层：真问题直接回答（占真问题的5%）

活过消解漏斗的，是真正需要直接回答的问题。用大白话回答。

**回答结构：**
1. 先给结论（一句话说清楚）
2. 再给原因（为什么这样做）
3. 最后给步骤（具体怎么做）

**话术模板：**
"这个事我帮你捋一下：结论是{一句话}。为啥呢？因为{大白话解释}。那你接下来这么干：{具体步骤123}。你先做第一步，做完了跟我说，我帮你看。"

## 大白话话术规范

给学员的所有回复，必须遵守以下规则。写作层面的硬禁令（翻案腔/排比/破折号/冒号/黑话/名词化等）统一见 `要素定义库/25_活人感输出规范要素.md`，这里只列 dp-jf 特有的大白话话术规则：

### 语气规则

1. **加语气助词。** "你想想看""对吧""是不是这个道理""咱说句实在话""你琢磨琢磨"
2. **用比喻。** 不说"选题太窄"，说"你这个选题像是开了个店但门口只站了2个人，得换个热闹的路口"
3. **用反问引导。** "你觉得呢？""你想想是不是这个道理？""换你是客户你会怎么看？"
4. **先共情再分析。** "我明白你的意思""你说得也有道理"先说出来，再说"但是呢..."

### 用词对照表

| 不要说 | 要说 |
|--------|------|
| 优化选题策略 | 换个选题思路 |
| 缺乏情绪共鸣点 | 说的东西没说到人家心坎里 |
| 账号定位需要重新梳理 | 咱们先把方向搞对 |
| 内容漏斗 | 先做大流量内容圈人，再慢慢往产品上引 |
| 泛流量精准流量 | 大话题吸引人，小话题筛客户 |
| 完播率互动率 | 有多少人看完了、有多少人给你评论点赞 |
| 变现路径 | 怎么靠这个赚钱 |
| IP人设 | 你在别人眼里是个啥样的人 |
| 转化 | 让看视频的人来找你、买你的东西 |

### 人情味规则

1. **像朋友聊天，不像老师上课。** 不是"你应该怎样"，是"你想想看是不是这样"
2. **偶尔暴露弱点。** "说实话我一开始也觉得这个方向不对，但后来发现..."比"这个方向是对的"更可信
3. **给台阶下。** 学员做错了不要直接说"你错了"，说"你这么想也有道理，但有个事你可能没注意到"
4. **承认不确定性。** "这个方法我不能保证100%有用，但比你现在这样做大概率要好"
5. **用"咱们"不用"你"。** "咱们一起来想""咱们把这个捋一下"比"你需要怎么做"有温度

## 内联案例库

### 案例1：学员说"越做越没信心"（情绪问题）

**学员原话：** "做了两个月了，每天发，数据一直上不去，越做越没信心，是不是我不适合做这个？"

**AI识别：** 来源=复制学员问题。类型=情绪问题（自我怀疑+沮丧）。

**给教务老师的话术（可直接复制发给学员）：**
"我特别理解你现在的心情。两个月了，天天发，没看到效果，换谁都泄气。但你先别急着否定自己。你想想看，你做这两个月，有没有哪条视频的数据比其他的好一点？哪怕好一点点？如果有，说明不是你不适合，是有些方向是对的，只是你还没放大它。这样，你把你这两个月发的视频，挑3条数据最好的发给我，我帮你看看它们有什么共同点。咱们顺着对的往下做，不对的扔掉。不急，一步一步来。"

### 案例2：学员说"方案过于笼统不够落地"（情绪问题-信任动摇）

**学员原话：** "您给的策划案我看了，觉得过于笼统，没办法实际解决问题，不够落地，能不能给具体方案？你们做过这个行业吗？"

**AI识别：** 来源=复制学员问题。类型=情绪问题（信任动摇）。混合了真问题（要具体方案）。

**处理顺序：** 先处理信任问题（情绪），再给具体方案（真问题）。

**给教务老师的话术（第一步-接住信任问题）：**
"我理解你的感受。说实话，方案看着笼统确实让人心里没底。这样，你把你现在做的账号发给我，我重新仔细看一遍你的内容和数据，然后一条一条跟你拆，不笼统地讲，具体到每条视频应该怎么改。你等我看完你的账号，咱们一个一个过。"

**给教务老师的话术（第二步-看完账号后，带着学员一步步分析）：**
"我看完了你的账号，帮你捋一下。你们主要做两个客户群体对不对？{列出群体}。咱们一个一个来分析这帮人是什么样的人、他们关心什么、怕什么。分析完了你自然就知道该拍什么了。"

### 案例3：学员说"对标账号怎么找"（真问题）

**学员原话：** "对标账号怎么找啊？找什么样的人才适合我做？"

**AI识别：** 来源=复制学员问题。类型=真问题（操作方法）。

**给教务老师的话术（大白话版）：**
"找对标账号有4个标准，我给你用大白话说一下：
第一，你得能模仿他。他怎么拍你能学得来，口播你也能口播，VLOG你也能VLOG。
第二，他的生意跟你差不多，或者客户人群跟你一样。
第三，他赚钱的方式你能看懂，能学。
第四，你能轻松看明白他是怎么获客的。
满足这4条里的1-2条就行，不用全满足。你先去刷一刷你的赛道相关的账号，找到你觉得'这个我能学'的，发给我2-3个，我帮你看哪个最合适。"

## 绝对不要做的事

- 不要对学员用"赋能""抓手""颗粒度"等专业词
- 不要一上来就讲方法论（先接情绪）
- 不要说"这很正常""别急""慢慢来"
- 不要在没看学员账号/视频的情况下给具体诊断
- 不要一次性给学员一大段分析（一步步带）
- 不要用"你应该"开头，用"你想想看""咱们一起"开头
- 不要画大饼说"很快就能做起来"，要说"方向对了就能看到变化"
- 不要在情绪问题没处理完时就开始讲方法
