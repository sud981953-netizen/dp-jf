# 实体店专项策略要素

**实体店老板做短视频，最大的错误是学网红表演。你不是要当网红，你是要获客。**

---

## 核心方法论（非谈判项）

### 原则1：展示体验，不展示产品

客户不想看你介绍产品有多好。客户想看的是"在你店里消费是什么感觉"。

**对比：**
- 展示产品："我们家的火锅底料是XX配方，用的是XX食材" -> 没人看
- 展示体验：拍顾客进店、点菜、上菜、吃的第一人称视角 -> 代入感强，完播率高

> 来源：011_同城商家为什么做不起来、012_全新引流模式实体店必看

### 原则2：第一人称视角拍摄

不需要对着镜头说话，不需要表演。拿着手机以第一人称视角记录工作过程。

**好处：**
- 代入感强：用户感觉自己在体验你的服务
- 不需要表演能力：真实记录就行
- 自然融入产品信息：不显得像广告
- 适合高端服务：越高端的服务用这种方式越好用

### 原则3：标准化脚本（定量+变量）

实体店做内容最忌讳靠灵感。必须标准化，才能持续输出、稳定获客。

**标准化脚本结构：**
- 定量（固定不变）：视频结构、镜头数、时长范围、BGM类型
- 变量（每天变化）：菜品/服务项目/顾客类型/场景细节

**示例（火锅店）：**
- 定量：5个固定镜头（进店环境 -> 点菜过程 -> 上菜展示 -> 顾客品尝 -> 结账环境）
- 变量：每天换不同的菜品组合、不同的顾客互动、不同的细节

### 原则4：去演员化，去脚本化

不要学网红表演，不要背台词。做最真实的自己，拍最真实的场景。

现在抖音的趋势就是去演员化、去脚本化。精心设计的表演反而会被算法和用户识别为"不真实"。

### 原则5：云体验

让成千上万个人通过你的短视频，身临其境地体验一次你的产品或服务。

**核心逻辑：** 卖产品不如卖服务，卖服务不如卖体验。

## 实体店内容形式库

### 形式1：沉浸式体验（核心形式）

第一人称视角拍摄完整的消费体验流程。

**适用：** 餐饮、美业、宠物店、健身房、汽车美容等体验型服务

**脚本模板：**
```
镜头1：进门/环境展示（5-10秒）
  -> 拍店门招牌、店内环境、氛围
镜头2：服务/点单过程（10-15秒）
  -> 第一人称视角记录点单/咨询/选品过程
镜头3：核心服务展示（15-20秒）
  -> 拍服务过程中的关键环节（上菜/做美甲/洗车等）
镜头4：体验结果展示（10-15秒）
  -> 拍成品/效果/顾客反应
镜头5：收尾/环境细节（5-10秒）
  -> 拍细节/优惠信息/引导
```

### 形式2：老板视角口播

老板面对镜头讲行业知识/避坑指南/经营心得。

**适用：** 所有实体店

**注意：** 口播不是介绍产品，是讲对用户有用的内容。比如五金店老板讲"装修怎么选材料不踩坑"，不是讲"我家五金店东西便宜"。

### 形式3：顾客故事/案例

拍真实的顾客故事或案例（需顾客同意）。

**适用：** 口腔诊所、美业、健身、月子中心等有服务周期的店

### 形式4：同城热点/本地生活

拍本地热点事件、本地生活指南，吸引同城流量。

**适用：** 所有实体店

**示例：** 火锅店拍"XX路新开了一条美食街"、"本地人最爱的5家火锅店"

## 实体店选题方向库

### 泛流量选题（L1-L2层，圈人唤醒）
- "这家店人均才XX，本地人天天排队"（性价比）
- "在XX开了X年，我发现一个规律"（经验分享）
- "XX路最好吃的X家店"（本地推荐）
- "实体店老板的一天是什么样的"（老板日常）
- "为什么这条街的店倒闭了一半"（行业观察）

### 精准选题（L3层，建信任）
- "吃火锅怎么点菜最划算"（实用干货）
- "装修选材料怎么不踩坑"（避坑指南）
- "第一次去XX店要注意什么"（新手指南）
- "XX行业的水有多深"（行业内幕）

### 转化选题（L4层，促到店）
- "团购双人套餐只要XX，点击左下角"（直接转化）
- "位置在XX路，说看视频来的送XX"（到店引导）
- "今天名额只剩X个"（稀缺营造）

## 实体店主页搭建

- 昵称：店名+品类（如"老王火锅-XX路店"）
- 头像：老板真人头像或门店招牌
- 头图：门店环境图
- 简介：地址+营业时间+特色+引导到店
- 置顶视频：最好的一条沉浸式体验视频

---

## 实体店常见误区（教练要提前纠正）

| 误区 | 正确做法 |
|------|---------|
| 对着镜头介绍产品 | 拍第一人称视角的消费体验 |
| 学网红表演 | 做最真实的自己 |
| 每天想不同创意 | 用标准化脚本，定量+变量 |
| 只拍产品不拍人 | 拍顾客体验、拍老板日常 |
| 不开团购 | 团购是到店转化的核心工具 |
| 发的内容全是广告 | 7成内容给价值，3成做转化 |
| 位置信息不重要 | 同城流量靠位置标签，必须带定位 |
