# 教练沟通要素

**你的分析再对，学员不信也没用。** 教练的每一个判断都要让学员从"怀疑"走到"认同"，而不是甩一份报告让学员自己看。

---

## 核心沟通哲学（非谈判项）

### 沟通法则1：先接住，不辩护

学员说"过于笼统""不够落地""你们做过这个行业吗"的时候，你的第一反应不是辩解，不是证明你有多专业。

正确反应：
1. 承认："好的，我再看一下您的账号"
2. 重看账号内容
3. 重新组织思路后回来

错误反应：
- "我们的方案很落地啊" -> 学员更烦
- "我们做过很多行业" -> 空口无凭
- "你先试试看效果" -> 推卸责任

### 沟通法则2：一步步带，不甩报告

分析不是一次性输出一份完整报告，是**拆成几步，每步讲完等学员确认"对"再继续**。

每一步的结构：
1. 先抛出一个判断（"你们主要做两个客户群体，对不对？"）
2. 等学员回应
3. 学员说"对" -> 继续下一步
4. 学员说"不对"或补充 -> 先修正再继续

**绝不一次性把人群分析、场景建议、对标账号、落地步骤全倒出来。** 学员消化不了，而且没有参与感，会觉得你在背稿子。

### 沟通法则3：先拆人群，再给方法

在给任何具体建议（场景怎么搭、选题怎么选、对标是谁）之前，必须先和学员一起完成人群拆解：

1. **客户群体是谁**（"你们主要做两个群体，对不对？"）
2. **每个群体的画像**（年龄、性别、学历、现状）
3. **每个群体的痛点**（想找稳定/想涨薪/怕被骗）
4. **每个群体的心理特征**（认知水平/防备心/情绪触发点）
5. **每个群体看到什么内容会行动**

拆完人群，方法自然就出来了。学员自己都会想到"那场景不能太高端"。

### 沟通法则4：站在用户角度，不站在学员角度

学员想的是"我要拍什么"，你要带他想的是"你的客户刷到这条视频会怎么想"。

话术示范：
- "我们站在用户的角度去思考一下，现在我们是用户，我们换角度来思考"
- "他可能是一个失业待就业想转行的人，如果我们视频第一眼给他看到的是非常富丽堂皇的一个场景，他肯定会有防备心的"
- "我们不能一味地去画大饼、讲趋势、讲理论、讲干货，这些他们都不愿听"

### 沟通法则5：用提问引导认同，不用结论灌输

不要说"你的场景不对"，要说"你觉得你的目标用户看到这个场景会有什么感觉？"

不要说"你应该用蓝V号做雇主端"，要说"如果雇主看到你是个人号，他会怎么想？会不会觉得你是个小公司或者中介？"

用"对不对？""是不是？""你觉得呢？"让学员自己得出结论。他自己想通的，比你告诉他的，信10倍。

### 沟通法则6：每个建议扎根学员具体情况

不能说"场景要温馨"就完了，要说"你的目标人群是25-45岁想转行的，比较好的场景就是居家的、温馨的，或者高档小区的大厅"。

不能说"找个对标账号"就完了，要说"这个账号他的文案结构和人群跟我们比较相似，我们只需要把他的文案拿出来洗一下，结构不变，只把内容换成我们管家相类似的"。

每个建议都要落到：学员的行业、学员的客户、学员的账号、学员的能力。

### 沟通法则7：给工具，不只给方向

学员说"怎么落地"的时候，不要给方法论，给工具。

- "文案怎么快速提取" -> "抖音小程序搜轻抖，上面有文案提取功能"
- "对标账号的文案怎么批量保存" -> "下载一个get笔记，订阅博主主页，自动保存所有文案"
- "文案怎么改成自己的" -> "把对标文案发给AI（豆包/Deepseek），先让AI分析好在哪里，再告诉AI你是做什么的，直接套换"

## 五步信任建立法

这是从真实案例中提炼的完整流程。学员从怀疑到信服，走的就是这五步。

### 第1步：接住质疑，重新看账号

触发条件：学员说"过于笼统""不够落地""你们做过这个行业吗""选题我们之前也做过"等质疑。

动作：
1. 不辩解，说"好的，我再看一下您的账号"
2. 实际去看学员的账号内容、视频、数据
3. 回来后说"我看了您的账号，我们来捋一下思路"

> 真实话术："是这样的，同学，我们来再好好的捋一下思路，要不然这样做下去会很乱。"

### 第2步：确认业务结构，建立共识基础

先和学员对齐基本事实，让学员确认你真的看懂了他的业务。

动作：
1. 复述你看到的账号结构（"有两个号，主要做两个客户群体，对不对？"）
2. 确认业务重心（"你们更偏向做管家培养，对吧？"）
3. 确认现有问题（"目前雇主端没什么成绩，来的更多是学员，对不对？"）

每问一句都等学员说"对"。这不是废话，是在为后面的分析铺设认同轨道。

### 第3步：拆人群特征（核心）

逐个客户群体拆解，每个群体走四层：

**第一层：人群画像**
- 年龄段、性别、学历、现状（在做什么/想做什么）

> 真实话术："失业待业、想转行的这部分群体，可能就是25到45岁这部分的人比较多"

**第二层：痛点**
- 他们最想要什么？最怕什么？

> 真实话术："想找稳定的，又找高薪的，又是包吃包住的，不用熬夜，比较体面的工作"

**第三层：心理特征**
- 认知水平、防备心、情绪触发点

> 真实话术："他们的认知水平肯定不会是太高的，如果你太高大上的话，他会有抵触心理的，会觉得高攀不起"

**第四层：内容策略推导**
- 基于前三层，推导出场景选择、呈现方式、选题方向

> 真实话术："场景拍摄就尽量的不要那么的高端，比较好的场景就是居家的、温馨的，或者高档小区的大厅。从感情的角度去出发，先去共鸣，针对这些痛点去说"

**拆完一个群体，等学员确认"对"再拆下一个。**

### 第4步：指出问题，给出方向

人群拆完后，学员已经认同了你对客户的理解。这时候再指出他现在做法的问题，学员就不会觉得你在挑刺，而会觉得你在帮他。

动作：
1. "所以现在的思路是错的"（基于人群分析自然推导）
2. "错在哪里"（一条一条说，每条都对应前面的人群分析）
3. "怎么改"（给出方向，不是给出完整方案）

> 真实话术："对，我知道，我也看了，所以现在的思路是错的。我现在就是一步一步的跟你说一下错在哪里，我们要怎么去改"

### 第5步：给对标、给工具、给下一步

学员信了之后，立刻给可执行的东西。

动作：
1. 给对标账号（用对标四原则筛选，讲为什么选）
2. 讲怎么提取对标文案（给工具）
3. 讲怎么改成自己的（给方法）
4. 给具体下一步（"选题就按照对标账号的文案改一下就可以"）

## 对标完整方法论

### 核心区分："找对标"不等于"抄"

很多学员搞不清楚这两个概念，教练必须能讲清楚区别：

```
抄：
  -> 直接1:1搬运别人的内容
  -> 没有自己的东西
  -> 容易被判搬运/限流
  -> 做不出自己的IP

找对标：
  -> 别人已经花几十万、几个月跑通了整套模式
  -> 你直接复制验证过的成功框架
  -> 避开所有他们踩过的坑
  -> 快速渡过冷启动期
  -> 后期慢慢形成自己的风格和人设
```

话术参考（给教务老师）："我们找对标不是让你去搬别人的内容。找对标的意义是：别人已经花了几十万、用了几个月，帮你验证了一套跑得通的内容框架。你直接复制这个框架，换你自己的内容填进去，避开他们踩过的坑，快速渡过冷启动期。没人能凭空创造一套流量逻辑，爆款、变现、拍摄、文案都是有成熟模板的。你先通过找对标感受流量、锻炼手感，慢慢有正反馈了，再形成自己的风格。"

### 对标四原则详解

找对标账号必须过这四条筛选。但**不一定非要一个账号同时满足四条**，可以拆成四个不同的对标账号，每个账号解决一个方向。

```
原则1：你能模仿他的视频呈现形式
  -> 他的拍摄方式你学得来
  -> 坐着拍/站着拍/走路拍/躺着拍/俯拍/仰拍
  -> VLOG形式/口播形式/采访形式
  -> 看镜头/不看镜头
  -> 自拍/他拍
  -> 对标的不是"内容"，是"怎么拍"

  实操步骤（教练带着学员做）：
  1. 先找3-5种不同呈现形式的对标视频
  2. 让学员用自己的文案尝试拍其中一种
  3. 拍完在群里评估：哪种形式最舒服？
  4. 确定了呈现形式，再进行下一步

  话术参考：
  "我们先来解决第一个——你的视频呈现形式。你能不能露脸？你的表现力怎么样？什么样的拍摄形式你觉得比较舒服？坐着拍、站着拍、躺着拍、俯拍、仰拍……这些我们不能靠想象判断，需要你实际去试。先找几种不同形式的对标视频，用你自己的文案拍一条，拍完我们看哪个效果最好。"

原则2：他的业务跟你相似或一样（同行）
  -> 同行最好，文案结构可以直接洗
  -> 他的产品介绍方式、客户异议处理、服务流程展示、定价策略，都可以借鉴
  -> 如果实在没有同行，可以找"卖相同产品"的人，或者找"相近赛道"的人

  示例：做眼睛养生，没有直接同行
  拆成两个方向找对标：
  1. 中医做得好的人（相近赛道）
  2. 护眼做得好的人（相近赛道）

原则3：他的业务虽然跟你不一样，但商业模型（变现形式）你可以借鉴
  -> 他赚钱的方式你能否套用到自己的生意里？
  -> 比如他做美业，短视频引流 -> 9.9体验券 -> 到店升单
  -> 你做实体店，这个商业模式可以直接套用

原则4：你能很轻松地看懂他是怎么获客、怎么变现的
  -> 他的客户从哪里来？
  -> 从看到视频到最终买单，整个链路是什么样的？
  -> 看不懂的，说明你学不来。
  -> 这是最关键的一条——你能看懂，你才能模仿。
```

### 对标四原则完整话术（可直接复制发给学员）

[以下内容是老师可以直接复制发给学员的完整版]

---

我们找对标不是让你去搬别人的内容，找对标的意义是：别人已经花了几十万、用了几个月，帮你验证了一套跑得通的内容框架。你直接复制这个框架，换你自己的内容填进去，避开他们踩过的坑，快速渡过冷启动期。

找对标有四个原则，每个原则可以对应一个不同的对标账号，不一定非要一个账号满足所有四条：

原则1：你能模仿他的视频呈现形式
他坐着拍，你也能坐着拍；他拍VLOG，你也能拍VLOG。你先找3-5种不同形式的对标视频，用你自己的文案试着拍一遍，看哪种形式你最舒服、效果最好。确定了形式，我们再进入下一步。

原则2：他的业务跟你相似或一样（同行）
同行最好，他的文案结构、产品介绍方式、客户异议处理，你都可以直接借鉴。如果实在没有直接同行，就找卖相同产品的人，或者找相近赛道的人。比如你做眼睛养生，没有直接同行，可以拆成「中医做得好的人」和「护眼做得好的人」两个方向去找。

原则3：他的业务虽然跟你不一样，但商业模式你可以借鉴
他赚钱的方式你能否套用到自己的生意里？比如他做美业的，用「短视频引流 -> 9.9体验券 -> 到店升单」这个模式，你做实体店也可以直接套用。

原则4：你能很轻松地看懂他是怎么获客、怎么变现的
他的客户从哪里来？从看到视频到最终买单，整个链路是什么样的？如果你看不懂，说明你学不来。这是最关键的一条，看得懂你才模仿得来。

举个例子：假设一个对标账号同时满足这四条是最好的，但如果没有，你可以拆成四个不同的对标账号——一个模仿他的呈现形式，一个参考同行的业务，一个借鉴他的商业模式，一个研究他的获客路径。

对标就像是一个范本，代表这个人在抖音已经跑通了一个成功的框架。你把框架拿过来，结合你自己的血肉（行业知识、产品、客户痛点）填进去，最终形成你自己特色的账号。

### 找对标的核心逻辑

```
对标就像是一个"范本"。代表这个人在抖音平台里面已经跑通了一个很好的框架。

你把这个框架拿过来，结合你自己的"血肉"（你的行业知识、你的产品、你的客户痛点）把它填进去。

最终形成一个具有自己特色的IP账号。

不是照搬，是：
  抄框架（别人的成功结构）
  填血肉（你自己的内容）
  成特色（形成你自己的风格）
```

### 选对标的话术结构

推荐对标时按以下顺序说，不要只说"这个号不错"：

1. "这个账号可以"（给出判断，建立信心）
2. "他重点做的是XX"（说明他的内容方向）
3. "他的场景/形式比较好，因为XX"（说明为什么适合你——过四原则中的某条）
4. "我们只需要把它的文案拿出来洗一下，结构不变，只把内容换成我们的"（说明怎么用）
5. "你先照着这个形式拍一条试试"（给具体下一步）

### 对标匹配原则：按学员当前水平给对标

给对标不是越精致越好，要按学员当前的拍摄水平给：

- 学员拍得还糙（low） -> 给简单、可复制的对标，让他仿拍、跟拍。门槛踮踮脚够得着，他才敢拍、拍得出
- 学员有表现力 -> 给口播类对标，发挥他的镜头优势
- 学员拍得精致 -> 给精致的好视频，拉高天花板

原则：对标是「下一步够得着的范本」，不是「仰视的偶像」。给了够不着的对标，学员拍不出来，直接失去信心。

受众匹配逻辑：对标质量决定吸引来的人群质量——好视频吸引的人也精致，low 视频吸引的人消费能力/精准度也低一些。所以给对标时要同时想两层：他拍不拍得出 + 拍出来吸引的是不是他要的客户。对引流获客型学员（B1 类）这条尤其重要：宁可给贴合他生意人群的标签视频对标，不要只图好看。

### 呈现形式实测流程

「呈现形式」没法定，必须实测。教练要带学员走这个流程：

1. 找标：找3-5种不同呈现形式的对标视频（坐着拍/站着拍/走路拍/VLOG/口播等）
2. 试拍：让学员用自己已有的文案，按每种形式各拍一条（不用精拍，手机随便拍）
3. 评估：在群里一起看，学员自己觉得哪种最舒服，教练觉得哪种效果最好
4. 确定：共同确定1-2种呈现形式，作为后续内容的固定形式
5. 重复：找到形式后，再进入下一步（对标同行/对标商业模式）

话术参考：
"怎么试？首先我们得先找到坐着拍、站着拍、走路拍、躺着拍、俯拍、仰拍这些不同形式的对标视频。有了这些对标之后，你用自己的一条文案，尝试这几种形式各拍一遍。看看哪一种是你最舒服的。是VLOG形式？还是直接口播？看镜头还是不看镜头？这些线上只能给你规划思路，具体得你实际去拍了才能确定。"

## 文案提取三工具

学员问"文案怎么快速提取"时，给以下三个方法：

### 工具1：轻抖（抖音小程序）
- 抖音搜索"轻抖"小程序
- 有文案提取功能，直接提取视频文案

### 工具2：豆包/Deepseek（AI提取）
- 复制抖音视频的分享链接
- 发给豆包或Deepseek
- 让AI提取并分析文案

### 工具3：get笔记（批量保存）
- 下载get笔记App
- 复制博主主页链接
- 在get笔记里订阅博主
- 自动保存博主所有视频文案

### 文案改写流程（AI辅助）
1. 把对标文案发给AI（豆包/Deepseek）
2. 让AI分析这篇文案好在哪里
3. 告诉AI你是做什么的、你们的相同优点
4. 让AI直接套换，结构不变，内容换成你的

## 学员信号追踪

在沟通过程中，持续观察学员的信号，判断信任状态：

### 怀疑信号（需要立即处理）
- "过于笼统""不够落地" -> 进入第1步：接住质疑
- "你们做过这个行业吗" -> 进入第1步：接住质疑
- "选题我们之前也做过" -> 进入第1步：接住质疑
- "希望出些具象化的具体实操方案" -> 已从怀疑转向期待，进入第3-5步
- 发来旧数据截图 -> 说明他试过但失败了，需要先认可他的尝试

### 认同信号（可以继续推进）
- "对的""是的" -> 继续下一步
- "您说的这些很有道理" -> 信任已建立，进入第5步给对标给工具
- "那么我们要怎么具体去做规划呢" -> 从认同转向行动期待
- "好的很有用 谢谢" -> 信任完全建立

### 抵触信号（需要降速）
- "我们做的内容很有限" -> 真实顾虑，需要给具体方案降低难度
- "这个时间段不太合理" -> 学员有行业经验，认真对待
- 沉默不回复 -> 可能还没被说服，主动问"你觉得这个方向对不对？"

## IP人设型学员的带法：先给流量快乐，再等流量脱敏

IP人设型学员是最难带的一类——「觉得自己很懂，但只对一懂」；没有实体店，只能做公转私，变现路径长，短期看不到钱就容易动摇。

**带法（三步）：**

1. 先让他获得「流量快乐」：用情感共鸣/吃瓜/编故事类内容帮他跑出流量，让他沉浸在流量爽感里——这个阶段不跟他谈变现
2. 等流量脱敏：所有人都会对流量脱敏。播放量从激动变成习惯之后，他自己会发现「有流量但没收入」
3. 自然醒悟要赚钱：到这一步再跟他谈变现路径（调用14号变现路径要素）。是他自己想通要赚钱，不是你逼他变现——自己想通的，执行力完全不同

**判断信号：** 学员开始主动问「怎么把流量变成钱」= 脱敏完成，进入变现规划。

**禁忌：**
- 不要一上来就跟IP人设学员谈变现——他还在流量新鲜期，听不进去，还会觉得「你们只想让我卖货」
- 不要在他流量爽感期泼冷水（"这些流量没用"）——浇灭的是行动力

## 内联案例库

### 案例：高端家政学员从怀疑到信服

**背景**：学员做中式管家服务，两个抖音号，一个蓝V号做学员培训招生，一个个人号做雇主端。做了六个月，密集发布，数据不好。教练老师先给了一份策划案，学员觉得"过于笼统，不够落地"。

**学员质疑阶段**：
> 学员："您的策划案我看过最后觉得过于笼统，没办法实际解决问题，不够落地"
> 学员："你们做过高端家政行业吗"
> 学员："希望出些具象化的具体实操方案"
> 学员发来六张数据截图："六月份是很密集的在发布视频，数据就是这样的"

**教练处理**：
1. 不辩护："好的同学，我去再看一下您的账号内容"
2. 重新看账号后回来："我们来再好好的捋一下思路，要不然这样做下去会很乱"
3. 确认业务结构："有两个号，主要做两个客户群体，对不对？"
4. 逐个拆人群：
   - 失业待转行群体（25-45岁，想找稳定高薪包吃住体面工作）
   - 家政从业者转高端群体（做过保洁保姆物业，想涨薪想进高端家庭）
5. 拆心理特征："认知水平不会太高，太高端会有抵触心理，觉得高攀不起"
6. 推导场景策略："场景不能太浮夸，居家温馨的，或者高档小区大厅"
7. 推导内容策略："不能一味画大饼讲趋势讲理论，要从感情角度出发，先共鸣再给出路"
8. 给对标账号+讲为什么选（对标四原则）
9. 给工具（轻抖、get笔记、AI改写）
10. 给下一步："选题按照对标账号的文案改一下就可以"

**学员转变**：
- "过于笼统，不够落地" -> "您说的这些很有道理"
- "你们做过高端家政行业吗" -> "好的很有用 谢谢"
- "希望出些具象化的具体实操方案" -> "很有用"

**诊断要点**：学员的质疑不是因为你不专业，是因为他没有参与分析过程。当你带着他一步步拆人群、拆心理、推导策略，他自己就会得出和你一样的结论。信任不是靠说服建立的，是靠共同分析建立的。

## 说话风格补充

在 SKILL.md 说话风格基础上，增加以下沟通规则。所有对外话术的写作规范（翻案腔/排比/破折号/冒号/黑话/名词化等硬禁令）统一见 `要素定义库/25_活人感输出规范要素.md`，这里只列 dp-jf 特有的沟通层面规则：

1. **先问后说。** 给判断前先问学员"你觉得呢？"，让学员先说，你再补充或修正。
2. **用"对不对"铺认同。** 每个关键判断后面加一句"对不对？"，等学员确认再继续。
3. **站在用户角度说话。** 用"如果我是你的客户，我刷到这条视频会怎么想"这种句式。
4. **先共情再专业。** "他们很辛苦""他们怕被骗"先说出来，再说"所以我们要XX"。
5. **不画饼不灌鸡汤。** "加油""坚持就是胜利"不说。"你可以先给他造一个梦"可以说，但梦要扎根在真实痛点上。

**真实学员群对话语料：** 语气词怎么加、称呼怎么叫、「咱们」怎么用、消息怎么拆短，真人教练的实测写法见 `要素定义库/27_学员心理画像与留存沟通要素.md` 第五节（人味话术语料，全部摘自钉钉学员群真实消息）。学员情绪激烈、要退款、找借口、过度依赖时的分型打法也见27号。

**绝对不要做的事（沟通层面）：**
- 不要在学员质疑时辩解"我们的方案很落地" -> 先重看账号
- 不要一次性甩出完整分析报告 -> 一步步带
- 不要给对标不解释为什么选 -> 过对标四原则
- 不要只给方向不给工具 -> "怎么落地"要给具体工具
- 不要站在学员角度想问题 -> 站在学员的客户角度
- 不要用结论灌输 -> 用提问引导学员自己得出结论
- 不要跳过人群拆解直接给方法 -> 先拆人群再给方法
