# 内容创作底层逻辑要素

**内容创作的底层逻辑决定了你的内容质量。理解了这些逻辑，学员才能真正学会怎么做短视频。**

---

## 一、选题 vs 观点

这两个概念要区分清楚，它们决定的是不同的东西：

- **选题**：决定有多少人看你的视频（受众广度）。选题越宽泛，看的人越多。
- **观点**：决定视频能走多远（内容深度+传播力）。观点越独特、论证越清晰，转发和评论越多。

### 选题扩展的方法

把细分选题一层层往上推，受众会越来越广：

```
举例1（管家行业）：
管家月薪多少 → 受众仅限从业者（窄）
管家与保姆谁前景更好 → 受众扩大到两个群体
当今最有前途的工作 → 受众更广

举例2（护肤）：
敏感肌怎么护肤 → 受众只有敏感肌人群
30岁以后怎么护肤不显老 → 受众扩大到30+女性
为什么你的皮肤越护越差 → 受众更广
```

### 观点的深度

选题定了之后，观点要跟其他博主不同、更深入、更有道理，才能让用户产生情绪波动，进而点赞转发。

观点的三个层次：
1. **跟别人一样**：没人看，因为没有新信息
2. **比别人深入一点**：用户觉得"有点道理"，会看完
3. **比别人深入很多，让用户恍然大悟**：用户会点赞、转发、评论"说得太对了"

## 二、情绪是核心

这两年抖音的底层逻辑只有情绪——文案必须让用户心里有波动。

波动的三种来源：

### 来源1：观点独特

跟其他博主不同、更有道理、能让人恍然大悟。

**示例：**
- 大部分博主说"做自媒体要勤奋" -> 你说"做自媒体勤奋是最没用的，方向错了越努力越错" -> 用户恍然大悟
- 大部分博主说"护肤要防晒" -> 你说"防晒是护肤最没用的一步，真正该做的是这个" -> 用户想点进来看

### 来源2：共鸣

需要有真实经历才能写出来，没有经历写不出共鸣感强的文案。

**示例：**
- "我在这家公司干了8年，辞退的时候只用了8分钟" -> 打工人共鸣
- "结婚5年，最怕听到的就是'我们谈谈'" -> 已婚人群共鸣
- "30岁了，还没有存款，没有对象，没有方向" -> 年轻人共鸣

共鸣类内容的特点：越真实越好，越具体越好，不要写得像作文。

**共鸣的八个方向（写文案时至少命中一个）**：共鸣不是玄学，是替用户做八件事之一。写完一条文案问自己命中了哪条，一条都不沾就是没共鸣，改。

1. 替用户想做的事找理由（他犹豫要不要干，你给了他支持）
2. 替用户没做成的事找借口（他失败了自责，你告诉他不怪他）
3. 替用户难以释怀的事找情绪出口（他憋着，你给了一个说法）
4. 替用户的委屈和无奈站台（没人看见他，你看见了）
5. 说了用户想说但不会表达的话（他只会说「就是那种感觉」，你说清楚了）
6. 说用户的不容易，让他的不更容易被看见（说给他的家人朋友听）
7. 说用户自豪但不好意思自己说的优点（替他骄傲了一次）
8. 说到用户的痛处，精准触发（他知道你知道他疼在哪）

八条的共同底层：**用户的情绪被你接住了**。共鸣不是你抒发，是你替他抒发。

### 来源3：情绪驱动（最底层、效果最直接）

满足特定人群的虚荣心和欲望。

**示例：**
- "30岁以后的女人一定要有这三样东西" -> 满足女性的虚荣心
- "真正有钱的人都不炫富" -> 满足有钱人或者想成为有钱人的人的虚荣心
- "你离成功只差一个认知升级" -> 满足想成功的人的欲望

**重要提醒：** 情绪驱动的效果最直接，但内容质量最低。不能长期只用这种方式，要和其他方式混着来。

## 三、口播视频的四个关键

所有口播视频都由四部分决定：

### 关键1：画面

画面决定用户在你还没说出核心观点之前能停多久。

**画面的三个要求：**
1. 必须确定是自拍还是他拍（不能混着来）
2. 画面要清晰，不能让人看着没欲望
3. 除非内容万里挑一，否则画面low=没人看

**画面不好会怎样：**
- 画面模糊 -> 用户直接划走，内容再好也没用
- 光线暗 -> 产品看不清，用户没有购买欲望
- 背景杂乱 -> 不专业，用户不信任
- 表情僵硬 -> 用户看着不舒服，不想继续看

### 关键2：内容

内容决定完播率、互动率、流量能走多远。

**内容的三个要求：**
1. 考验文案的逻辑思维能力
2. 需要逻辑性和案例支撑
3. 可以借助AI，但需要交付老师先理解内容，才能给AI正确的指令

**重要提醒：**
- 画面和内容都要好，缺一个都不行
- 画面不好，内容再好用户也看不到
- 内容不好，画面再好用户也看不完
- 如果只能选一个，优先解决画面问题（因为画面是门槛）；画面过关后，例子接地气（关键3）和内容质量（关键4）决定流量上限

### 关键3：例子要接地气（能不能共鸣看例子）

观点再对，例子不接地气，用户还是觉得「跟我没关系」。好例子五个标准（写文案、改文案时逐条过）：

1. **所有人都遇过的日常场景**：❌「ROI从1.5跌到0.9」（只有创业者懂）✅「我在这家公司干了8年，辞退的时候只用了8分钟」（所有打工人懂）
2. **脑子里能立刻生成画面**：❌「我最近压力很大」✅「回家的路上脚步虚浮，轻一步重一步」
3. **有情感冲击**：❌「这个方法挺好的」✅「我愣了三秒，发现我自己也不知道答案」
4. **对比强烈**：把模糊表达和具体表达放一起，差距一眼看得见
5. **从验证过的素材里找**：自己亲历的、学员真实发生的，比编的强十倍。编的例子只有你自己懂，真实的例子自带细节

判断一条例子行不行，就问一句：**目标用户看到这句，脑子里会不会闪过「这说的就是我」？** 不会，换。

### 关键4：内容质量的算法标尺（不后悔时长）

算法已经从「完播率」升级到「不后悔时长」：用户看完觉得没白看，才算有效供给；看完无感甚至点「不感兴趣」，哪怕看完了，流量照样锁死。

**写文案时脑子里始终问一个问题：用户看完这条视频，会主动打评论还是直接划走？**

- 长评论（用户主动打字）= 深度思考的证明，权重最高
- 转发（用户用信用背书）= 价值证明，权重高
- 点赞 = 低成本互动，权重在降

这把尺子直接检验内容力：广告味文案没人评论（「又一个卖货的」划走），好文案有话想说（评论、转发、截图）。写完不放心，就假想用户看完那一刻的表情。

## 四、跨界选题

两个不同行业结合=跨界选题，可以同时吸引两个群体的流量。

### 什么是跨界选题

把你的行业和另一个行业结合，创造一个新的话题。

**示例：**
- 管家+修汽车 -> 同时吸引管家群体和修汽车群体
- 护肤+职场 -> 同时吸引护肤人群和职场人群
- 健身+育儿 -> 同时吸引健身人群和育儿人群
- 美食+旅行 -> 同时吸引美食人群和旅行人群

### 跨界选题的规则

1. **两个行业都要讲到**：不能只讲一个，要让两个群体都有收获
2. **落脚点要明确**：想推哪个行业就在那个行业上收口
3. **两个群体都要有共鸣**：不能只让一个群体有感觉

### 跨界选题的来源

1. **跟学员大量聊天中发现的**：学员会告诉你他们的其他需求
2. **自己的奇思妙想**：看到其他行业的内容，想"如果和我的行业结合会怎样"
3. **AI辅助发现**：AI很智能，人脑有局限性。把你的行业和目标人群告诉AI，让AI帮你列出10个可以跨界结合的行业和话题。AI能想到很多人类想不到的跨界组合。但最终要不要用、怎么用，由交付老师判断

**关键理解：跨界选题这个能力，不是只有人能想到，AI也应该具备这个思想。** 人脑有局限性，AI可以帮人发现跨界的可能性。交付老师要善于利用AI的跨界思维能力。

## 五、选题往上推的方法

如果讲细分领域没人信、没流量，就往上一层推。每往上一层受众更广，但需要不同的内容策略。

### 推导逻辑

```
举例1：膏药
膏药（细分，没人信）→ 养生（有流量但卖不出去）→ 中医（无脑信奉的人群，容易成交）

举例2：管家
管家（细分，没流量）→ 家政（有流量）→ 服务行业（更广）→ 职场教育（最广）

举例3：敏感肌护肤
敏感肌（细分）→ 护肤（有流量）→ 美容（更广）→ 女性自我管理（最广）
```

### 核心思路

1. **先在上层建立专业形象和信任**：用上层的话题圈人，让用户觉得你懂行
2. **再把流量引回自己的细分产品上**：用户信任你之后，你推什么他都会信

### 注意事项

- 上层话题的内容必须和你的细分产品有关联
- 不能上层讲的内容和下层卖的产品完全不搭
- 过渡要自然，不能生硬

## 六、低端 vs 高端两种打法

根据学员的变现目标选择打法，不能混着来。

### 低端打法：无限切情绪

**适合人群：** 没有独立思考能力、容易被情绪驱动的人（主要是老年人、下沉用户）

**流量大，但变现价值最低。**

**适合的内容：**
- 心灵鸡汤
- 情感鸡汤
- 接好运
- 家庭关系
- 教育子女
- 必须是浅显易懂的大白话

**操作方法：**
- 想要什么粉丝就发什么内容
- 想要男性粉丝 -> 发"男人赚钱天经地义"
- 想要女性粉丝 -> 发"男人就该养家"
- 想要老年粉丝 -> 发祝福、鸡汤、家庭伦理
- 想要宝妈粉丝 -> 发"为了孩子我愿意付出一切"

### 高端打法：凸显专业性

**适合人群：** 有消费能力、有判断力的人

**流量小，但变现价值高。**

**要求：**
- 必须有干货
- 必须有独特观点
- 必须能解决具体问题
- 适合专家型IP
- 需要把人包装成别人想成为的样子
- 讲来时路、讲专业见解

### 关键区别

| 维度 | 低端打法 | 高端打法 |
|------|---------|---------|
| 驱动力 | 情绪驱动 | 专业驱动 |
| 流量 | 大 | 小 |
| 变现价值 | 低 | 高 |
| 内容质量 | 低，但易懂 | 高，需要专业 |
| 目标人群 | 下沉市场 | 有消费力的人 |
| 变现方式 | 广告、打赏 | 服务、课程、咨询 |

**选择标准：** 根据学员的变现目标来选择。如果学员卖的是低价大众产品，走低端打法。如果学员卖的是高价专业服务，走高端打法。不能混着来。

## 七、不同平台的适配

同样的内容在不同平台效果差异很大：

| 平台 | 特点 | 适合什么内容 | 流量来源 |
|------|------|------------|---------|
| 抖音 | 偏年轻化、娱乐化 | 新奇、有趣、情绪化内容 | 推荐算法 |
| 快手 | 中老年群体多 | 真实、接地气、生活化内容 | 社交+推荐 |
| 视频号 | 适合中老年群体 | 有深度、有共鸣的内容 | 社群裂变 |
| 小红书 | 几乎每条内容都奔着变现 | 种草、攻略、好物推荐 | 搜索+推荐 |

### 平台选择建议

- 如果学员用户群体偏中老年 -> 推荐做快手和视频号，不要死磕抖音
- 如果学员卖的是女性消费品 -> 推荐做小红书
- 如果学员想做IP、做知识付费 -> 抖音为主
- 如果学员做本地生活 -> 抖音+快手双平台

**同样的内容在不同平台效果不同：** 同样一条内容，抖音可能播放量低，但快手可能播放量高。建议学员多平台分发，测试哪个平台效果最好。

## 八、文案脚本发送规范

这是给教务老师的操作规范。

### 不要发的东西

- 不要发AI生成的画面描述（一看就是机器产出的，学员会排斥，怀疑专业性）
- 不要发开场指导（如"深呼吸，面带微笑，看着镜头"）
- 不要发拍摄表情指导
- 不要发脚本里的细节描述（画面描述、动作指导等）

### 要发的东西

- 只发正文内容（开头+正文+结尾）
- 发之前自己先看一遍，感觉不好的文案千万不要发
- 包括策划里的脚本细节都要删掉，只留正文

### 为什么

1. **学员会怀疑专业性**：AI生成的画面描述一看就是机器写的，学员会觉得"老师是不是在用AI糊弄我"
2. **学员会排斥**：学员想要的是能直接用的文案，不是一堆指导
3. **学员会不知道怎么用**：太多细节反而让学员不知道怎么拍

## 九、给教练的话术参考

**解释选题vs观点：**

"选题决定有多少人看，观点决定能走多远。选题越宽泛看的人越多，但观点越独特、越有深度，用户才会点赞转发。所以你要先选一个宽泛的选题，再给出一个独特的观点。"

**解释情绪是核心：**

"这两年抖音的底层逻辑只有情绪。你的文案必须让用户心里有波动，不管是恍然大悟、还是共鸣、还是满足虚荣心，必须有一个情绪点。没有情绪点的文案，用户看完就划走了。"

**解释选题往上推：**

"如果你讲细分领域没人信、没流量，就往上一层推。比如你卖膏药，膏药没人信，你就讲养生；养生有流量，你再讲中医；中医有大量无脑信奉的人群，收割容易。先在上层建立信任，再把流量引回你的膏药。"

**解释低端vs高端打法：**

"低端打法靠情绪驱动，适合下沉市场，流量大但变现价值低。高端打法靠专业驱动，适合有消费力的人，流量小但变现价值高。根据你的变现目标选择，不能混着来。你卖的是高价专业服务，就走高端打法；你卖的是低价大众产品，就走低端打法。"

**解释跨界选题：**

"两个不同行业结合就是跨界选题，可以同时吸引两个群体的流量。比如你做管家的，可以结合修汽车的话题，同时吸引管家群体和修汽车群体。但落脚点要明确，想推哪个行业就在那个行业上收口。"

## 十、不要做的事

- 不要把选题和观点混为一谈
- 不要发没有情绪点的文案
- 不要画面low但内容好（画面是门槛，过不了门槛内容再好也没用）
- 不要混着来低端和高端打法（根据变现目标选一个）
- 不要在上层讲的内容和下层卖的产品完全不搭
- 不要发AI生成的画面描述和拍摄指导给学员
- 不要死磕抖音（学员用户群体偏中老年就做快手和视频号）
- 不要让学员只在一个平台发（多平台分发测试效果）
