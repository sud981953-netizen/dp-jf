# 主页搭建要素

> 本文件管主页四件套：昵称、头像、背景图、置顶视频。简介文字不在本文件，调用 08_简介要素.md。
> 调用时机：1. Phase 1 账号规划的主页搭建阶段；2. 学员主页诊断（"我主页要不要改"）。

**主页不是装饰，是转化页。用户刷到视频点进主页，只给你3秒——3秒内他要回答三个问题：你是干什么的？跟我有什么关系？凭什么信你？四件套就是为这三个问题服务的，而且必须说同一件事。**

---

## 一、四件套分工总览

| 元素 | 回答的问题 | 核心要求 |
|------|-----------|---------|
| 昵称 | 你是干什么的 | 一眼看懂+能被搜到 |
| 头像 | 你是谁 | 清晰、有辨识度 |
| 背景图 | 凭什么信你（补充） | 简介写不下的背书放这里 |
| 简介 | 全部三个 | 调用 08_简介要素.md |
| 置顶视频 | 兑现承诺 | 简介说"看置顶"，置顶必须接得住 |

**一致性铁律**：昵称、头像、背景图、简介、置顶视频必须指向同一件事。简介写"专做减脂饮食"，置顶是搞笑日常——用户立刻觉得货不对板，走人。

---

## 二、昵称

### 公式
`职业/身份 + 标签（+ 城市）`

- 同城账号必带城市：徐州石锅鸡老王、郑州二手车老炮
- 全国账号带领域：财税老周、美业测评阿May
- 人设向账号可用记忆点型：抠门老板张总

### 好昵称三标准
1. **看得懂**：陌生人一眼知道你是干什么的
2. **记得住**：好念、顺口，不用生僻字
3. **搜得到**：含行业关键词（用户搜"郑州二手车"能搜到你）

### 避雷
- 生僻字/火星文/一长串英文（用户记不住也搜不到）
- 纯表情符号
- 与内容无关的文艺名（"风一样的男子"——谁知道你卖什么）
- 频繁改名（昵称=品牌，改一次老粉丢一次）

---

## 三、头像

```
IF 学员出镜 -> 真人正脸照（清晰、光线好、表情亲和、背景干净）
ELIF 不出镜 -> 高辨识度形象（卡通IP/品牌LOGO/产品形象）
```

- 实体店也可用门店门头照（同城识别度高）
- 避雷：风景照、模糊自拍、戴墨镜口罩的正脸、网图（侵权且廉价）

---

## 四、背景图（第二简介）

简介字数有限，写不下的背书放背景图。可选内容（选1-2样，不贪多）：
- 一句话价值主张（"用抖音帮实体店搞同城流量"）
- 可验证背书（资质证书墙/门店实拍/产品陈列/服务数据）
- 行动引导（"关注我，教你XX"）

**排版注意**：文字放中上部，避开头像和简介的遮挡区；手机端预览确认无遮挡。

**同城账号**：背景图直接放门店实拍图，让附近的人一眼认出"原来就是街角那家店"。

---

## 五、置顶视频（简介的兑现）

### 三置顶结构

| 置顶 | 内容 | 作用 |
|------|------|------|
| 置顶1 | 人设/背书视频（我是谁、我的经历/资质） | 建立信任 |
| 置顶2 | 爆款/干货视频（最能代表内容质量的一条） | 证明实力 |
| 置顶3 | 转化/产品视频（产品可视化/服务介绍） | 承接变现 |

### 硬规则
- 简介里说"看置顶视频"，置顶就必须接得住——置顶内容和简介承诺对不上=欺骗用户
- 置顶不是永远不动：跑出更好的爆款就换置顶2；阶段变了（开始转化了）就换置顶3
- 冷启动期没有爆款：置顶2先放"内容方向预告"（这个账号会持续讲什么）

## 六、主页一致性总检（搭建完必过）

```
IF 昵称看不出干什么的 -> 按公式重起
IF 头像模糊/是风景照 -> 换
IF 背景图和简介说的事对不上 -> 改背景图
IF 简介承诺的方向，置顶视频里找不到 -> 换置顶或改简介
IF 四件套指向超过一件事（又讲财税又讲育儿） -> 砍到一件事
```

---

## 七、改版时机（什么时候该动主页）

```
IF 账号阶段变化（冷启动->成长->成熟） -> 简介加结果数字、置顶升级、背景图加背书
IF 变现方式变化（开始带货/开直播） -> 行动指令升级、置顶3换成转化视频
IF 内容方向调整（换赛道/换支柱） -> 全套重新对齐
ELSE -> 不动。主页不频繁改，每次改动都是对用户认知的重新建立
```

---

## 特别警告

- 学员想起个"有格调的文艺昵称" -> 「昵称不是给你自己欣赏的，是给陌生用户3秒看懂你干什么的。格调不能当搜索词用。」
- 学员头像想用孩子照片/风景照 -> 「用户关注的是"能帮我解决问题的人"，不是你的生活的照片。头像要么是你的脸，要么是你的品牌。」
- 学员背景图放二维码/微信号 -> 「背景图放联系方式和简介放微信一个性质，会被判导流降权。引导用'私信关键词'。」
- 学员问"主页装修得很漂亮为什么没人关注" -> 「主页不是装修是转化页。漂亮不解决问题，3秒讲清'干什么/跟我什么关系/凭什么信你'才解决问题。」
- 实体店主页补充 -> 调用 15_实体店专项策略要素.md 的「实体店主页搭建」节（同城定位/团购挂载/门店页配置）

## 内联案例

**案例：财税账号主页四件套**
- 昵称：财税老周（职业+标签，搜"财税"能搜到）
- 头像：本人正脸职业照（出镜IP）
- 背景图：「13年服务200+中小企业主」+ 办公室实拍
- 简介：注册会计师 | 13年服务200+中小企业 / 专给老板讲听得懂的财税：少踩坑、不花冤枉钱 / 开公司不懂财税的，看置顶「老板财税第一课」
- 置顶1：老周13年财税路（人设故事）；置顶2：老板最容易踩的5个财税坑（爆款干货）；置顶3：公司注册后第一件事该做什么（转化）

一致性检查：昵称"财税"√ 简介"财税"√ 背景图"财税服务"√ 置顶全部财税主题√ ——四件套说的是同一件事。

**反面案例**
- 昵称：追梦人（看不出干什么）/ 头像：海边背影（不知道是谁）/ 背景图：鸡汤文字（无背书）/ 简介：分享生活，记录美好（无指向）/ 置顶：三条杂内容
- 诊断：四件套各说各话，用户3秒内一个关键问题都答不上来，直接划走。
