# 学员文件维护要素

**核心原则：学员文件夹是教练的工作知识库。过期、膨胀、矛盾的学员资料会误导教练判断——就像过期文档会误导AI一样。**

遵循四条编辑原则：
- 减优于加：更新信息时替换旧条目，不在底部追加
- 合并优于追加：同主题的对话存档周复盘时合并
- 删除优于保留：废弃方案、无决策闲聊，删
- 绝对时间：永远写 2026-07-25，不写「昨天」「最近」

---

## 一、学员档案维护规则（学员档案.md）

学员档案是教练每次接触学员时的**第一入口**，必须「所见即最新」。

| 规则 | 做法 |
|------|------|
| 更新方式 | **替换旧条目**，不在底部追加新段落 |
| 尺寸上限 | **≤100 行**。超了说明在写历史过程，详细过程迁到对话存档 |
| 时间写法 | 绝对日期（2026-07-25），不写「上周」「前几天」 |
| 内容定位 | 只放**当前状态**：当前阶段/当前周次/最新评价结论/当前待办 |
| 历史信息 | 不放档案里。历史过程去 00_对话存档/ 查 |

### 「当前进度」字段更新示范

错误（追加式，越写越长）：
`
第1周：完成账号规划
第2周：拍了3条视频，表现力不够
第3周：调整了选题方向，开始用反差型
（半年后档案 300 行，教练找不到现在第几周）
`

正确（替换式，永远是最新）：
`
## 当前进度
- 规划状态：执行中
- 当前周次：第12周（2026-07-25更新）
- 已完成作业：38条
- 最新评价：表现力已稳定，重点攻选题独特性（2026-07-24）
`

## 二、对话存档管理规则（00_对话存档/）

每次对话后自动存档的机制不变，但要遵守以下规则：

| 规则 | 做法 |
|------|------|
| 命名 | 日期_主题.md（20260725_视频评价讨论.md） |
| 单次尺寸 | ≤200 行。超了说明一次聊太多，下次拆开或精简存档 |
| 周复盘合并 | 同主题的多次对话（如连续3天讨论同一个选题）→ 周复盘时合并成一份 |
| 可删除的 | 单次无决策闲聊、已被后续对话推翻的旧讨论 |
| 必须保留的 | 账号方向决策、学员情绪转折、方案确认记录——这些是「证据」 |

### 删除判断标准

问一句：**一个月后教练回头看这条存档，会影响他的判断吗？**
- 会 → 保留
- 不会（只是流程性对话）→ 周复盘时可删

## 三、账号策划方案版本管理（01_账号策划/）

| 规则 | 做法 |
|------|------|
| 版本更新 | 方案调整时**替换旧版本文件**，标注版本号和日期（账号策划_v2_20260725.md） |
| 旧版本 | 删除。不保留「以后可能有用」的废弃方案——它们只会让教练拿错 |
| 重大方向调整 | 在学员档案的「当前进度」里记一笔（绝对日期+一句话），方案本身不保留历史 |

---

## 四、作业与排期清理（03_作业与排期/）

| 规则 | 做法 |
|------|------|
| 已完成作业 | 周复盘时合并到本周总结（周复盘记录里），单个作业卡可删 |
| 逾期未做作业 | 重新排期（改日期）或删除。**不堆积**——堆积的旧作业让教练和学员都焦虑 |
| 当前作业 | 永远只有「今天/明天」的作业在最显眼位置 |

---

## 五、视频评价记录（04_视频评价/）

| 规则 | 做法 |
|------|------|
| 保留策略 | **全部保留**。评价记录是学员成长的追踪线，有长期价值 |
| 周复盘提炼 | 每周从评价中提炼共性问题，写进学员档案（如「连续3条视频开头都太平」） |
| 重复问题 | 同一个问题出现3次以上 → 升级写进学员档案「待办事项」，作为专项攻克点 |

---

## 六、尺寸体检标准

每次存档和每次周复盘时检查：

| 文件 | 上限 | 超了怎么办 |
|------|------|-----------|
| 学员档案.md | 100 行 | 替换旧条目，历史迁对话存档 |
| 单次对话存档 | 200 行 | 拆分或精简（只记决策和结论） |
| 账号策划方案 | 300 行 | 只留当前版本，删旧版 |
| 周复盘记录 | 200 行 | 合并同类问题，删流水账 |
| 单个学员文件夹总文件数 | 60 个 | 触发一次彻底清理 |

---

## 七、跨文件同步检查（最重要，最容易翻车）

学员状态变化时，**所有相关文件必须同步更新**。改了一个不改其他，教练就会被矛盾信息误导。

| 变化 | 必须同步更新的文件 |
|------|------------------|
| 阶段变化（冷启动→成长期） | 学员档案 + 作业配比（三类内容配比表） + 内容漏斗规划 |
| 方向调整（换选题方向/换呈现形式） | 学员档案 + 账号策划方案 + 待办事项 |
| 行业/赛道重新分类 | 学员档案 + 账号策划方案 |
| 变现路径调整 | 学员档案 + 账号策划方案 + 内容漏斗转化层 |
| 学员情绪重大波动 | 学员档案（最新状态） + 对话存档（保留证据） |

**检查口诀：改状态，先想「还有哪些文件记着这个状态」。**

---

## 八、周复盘时的文件维护步骤（Phase 3 调用）

每周复盘时，在做内容复盘之外，加做以下文件维护（10分钟内完成）：

`
1. 更新学员档案：替换「当前进度」「最新评价」「待办事项」为最新状态
2. 合并本周对话存档：同主题的合并，流水账删除
3. 清理作业区：已完成作业合并到周总结，逾期作业重新排期或删除
4. 检查方案版本：当前方案是否还是学员实际执行的方向？不是就更新或标注
5. 提炼共性问题：本周视频评价里重复出现的问题 → 写进学员档案
6. 跨文件同步检查：阶段/方向/变现有没有变化？相关文件都改了吗？
7. 尺寸体检：档案≤100行？存档≤200行/个？文件总数≤60？
`

---

## 九、不要做的事

- 不要在学员档案底部不断追加段落（要替换旧条目）
- 不要保留「以后可能有用」的废弃方案（教练会拿错）
- 不要用相对时间写存档（「昨天那条视频」一周后没法追溯）
- 不要堆积逾期未做的作业（重新排期或删除，不堆着）
- 不要只改学员档案不改方案（跨文件不同步是最大隐患）
- 不要删除视频评价记录（这是学员成长的追踪线，有长期价值）
