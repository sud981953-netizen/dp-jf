# 行业分类与赛道策略要素

**不同行业的做号逻辑完全不同。用同一套方法套所有行业，一定会出错。**

---

## 六大类型分类

所有学员都能归入以下六类之一。先分类，再定策略。

### A类：同城实体店

典型学员：火锅店、五金店、粮油店、美甲店、宠物店、服装店、理发店、健身房、烘焙店、口腔诊所、汽车美容等。

目标客户：本地3-10公里范围内的居民/消费者。

核心策略：**场景化营销**
- 不对着镜头推销，拍第一人称视角的真实工作场景
- 展示体验，不展示产品（客户看的是"在你店里是什么感觉"）
- 营造代入感，让客户身临其境体验一次你的服务
- 标准化脚本：定量（固定结构）+变量（每天换题材），不靠灵感

内容形式：VLOG/第一人称视角/场景记录为主，口播为辅
变现路径：团购券到店消费 / 私信咨询到店
账号阶段配比：流量2:价值4:转化4
常见误区：对着镜头硬推产品、学网红表演、只拍产品不拍体验、不标准化

### B类：职业IP/专业服务

典型学员：律师、会计师、税务师、香港公司注册、心理咨询、国学老师、风水师、健身教练、营养师、形象顾问等。

目标客户：有特定专业需求的人群（全国或同城）。

核心策略：**专业信任+人群漏斗**
- 用内容漏斗先做泛流量共鸣（调用 11_内容漏斗与流量分层要素.md）
- 精准内容展示专业度，建立"这个人懂行"的信任
- 人设核心：从业时间+性格+职业（如"干了15年的老练会计"）

内容形式：口播为主（讲专业观点/案例分析/避坑指南），图文为辅
变现路径：私信咨询 -> 线上/线下服务 / 知识付费
账号阶段配比：全国IP配比（冷启动7:2:1 -> 成熟3:3:4）
常见误区：只讲专业不讲人变工具人、讲太专业用户听不懂、不做泛流量只做精准、人设虚假

### C类：知识付费/教育

典型学员：做课程的、做培训的、做陪跑的、做社群的、做训练营的。

目标客户：想学习某项技能或解决某个问题的人。

核心策略：**内容即产品**
- 内容就是产品的预演，用户看内容时已经在体验产品
- 先做大流量共鸣内容圈人，再用精准内容建立"这个人能帮我"的信任
- 引流品（低价/免费资料）筛选付费用户，利润品做核心变现

内容形式：口播为主（讲方法论/案例/认知），直播为辅
变现路径：免费资料引流 -> 低价课体验 -> 高价课/陪跑变现
常见误区：直接卖课、只讲干货不讲故事、免费资料质量差、不分层做内容

### D类：带货/电商

典型学员：服装带货、美妆带货、食品带货、日用品带货、书单号、好物推荐等。

目标客户：有购物需求的消费者（按品类细分）。

核心策略：**选品+人设+场景**
- 选品是核心：产品力决定转化率
- 人设决定信任：你是"懂行的买手"还是"源头工厂老板"
- 场景决定代入感：穿搭要实拍上身、食品要试吃展示
- 书单号特殊：靠文案+金句+情绪共鸣，不需要出镜

内容形式：产品展示/试穿试吃/场景化使用/口播推荐
变现路径：橱窗/小黄车/直播带货
常见误区：只发产品不发人、选品没差异化、不做内容只发广告、忽视售后口碑

### E类：泛娱乐/内容创作者

典型学员：搞笑博主、剧情号、生活VLOG、美食探店、旅行博主、情感电台、萌宠账号等。

目标客户：不是"客户"是"粉丝"，靠内容本身吸引人。

核心策略：**内容质量+人设+情绪**
- 内容质量是唯一竞争力：创意、制作、情绪缺一不可
- 人设是记忆点：让人记住"你是谁"
- 情绪是传播力：让人笑、让人哭、让人感动
- 更新频率和稳定性：泛娱乐靠量取胜

内容形式：VLOG/剧情/混剪/口播，按内容类型选
变现路径：广告接单/直播打赏/品牌合作/带货
常见误区：模仿没有自己风格、追热点没自己角度、做太杂没垂直度、只看播放量不看粉丝增长

### F类：B2B服务/企业服务

典型学员：代运营公司、设计公司、软件开发、广告公司、批发商、制造商、SaaS销售等。

目标客户：企业老板/采购决策者。

核心策略：**案例+专业+行业洞察**
- 案例展示是核心：用真实案例证明能力
- 行业洞察建立权威：输出对行业的深度理解
- 客户证言增强信任：让客户替你说话
- 决策周期长，内容要做长期培育

内容形式：口播（行业分析/案例拆解）+ 图文（数据/对比）
变现路径：私信咨询 -> 线上会议 -> 线下拜访 -> 签约
常见误区：对C端话术讲B端业务、只讲公司不讲行业、案例太虚没细节、急于转化

## 行业路由判定（if/else）

```
IF 有线下门店 AND 主要服务本地客户 -> A类同城实体店
ELIF 提供专业服务 AND 靠专业知识变现 -> B类职业IP
ELIF 卖课程/培训/陪跑/社群 AND 靠知识变现 -> C类知识付费
ELIF 卖实物商品 AND 通过橱窗/直播变现 -> D类带货
ELIF 靠内容本身吸引粉丝 AND 通过广告/打赏变现 -> E类泛娱乐
ELIF 服务企业客户 AND 决策周期长 -> F类B2B
ELSE -> 追问"你的客户是谁？你怎么赚钱？靠什么变现？"
```

## 行业四象限模型

信息差和价格不同，内容策略不同：

| 象限 | 特点 | 策略 |
|------|------|------|
| 价格低信息差低 | 日用品/零食 | 靠场景和价格，冲动消费 |
| 价格低信息差高 | 书单号/好物推荐 | 靠内容教育，先让人懂再买 |
| 价格高信息差低 | 高端商品/服务 | 靠体验和口碑，先让人体验再买 |
| 价格高信息差高 | 律师/注册/咨询 | 靠信任建立，先让人信再买 |

## 五层用户漏斗模型（适用于所有类型）

每个学员的客户都分5层，每层内容不同：

| 层级 | 用户状态 | 内容方向 | 目的 |
|------|---------|---------|------|
| L1所有人 | 吃瓜群众 | 行业内幕/认知反差/极端案例 | 破圈+吸引新用户 |
| L2沉睡客户 | 有需求但不知道 | 危机预警/现状自查/症状对号 | 唤醒意识 |
| L3意向客户 | 在找方案怕踩坑 | 避坑指南/硬核干货/步骤教程 | 建立专家信任 |
| L4准客户 | 纠结选择困难 | 真实案例/对比测评/售后保障 | 临门一脚促转化 |
| L5已付费 | 已购买的用户 | 隐藏用法/保养/专属福利 | 留存+复购+裂变 |

做账号规划时，前4周的内容节奏就是沿着漏斗从L1往L4走：第1周做L1-L2的内容圈人唤醒，第2-3周做L3的内容建信任，第4周做L4的内容促转化。

## 内联案例库

### 案例1：火锅店（A类同城实体店）

学员背景：同城火锅店老板，有蓝V，之前发产品介绍视频没流量。

策略：
- 拍第一人称视角：顾客进店 -> 点菜 -> 上菜 -> 吃的场景 -> 结账
- 展示体验不展示产品：不介绍锅底多好，拍顾客吃的时候满足的表情
- 标准化脚本：定量=固定5个镜头（进店/点单/上菜/品尝/环境），变量=每天换菜品/换顾客/换场景
- 泛流量选题："这家火锅店人均才50，本地人天天排队"（L1层圈人）
- 精准选题："吃火锅怎么点菜最划算"（L3层建信任）
- 转化选题："点击左下角团购券，双人套餐只要88"（L4层促转化）

### 案例2：香港公司注册（B类职业IP）

学员背景：做香港公司注册服务，有蓝V，之前直接讲注册流程没流量。

策略：
- 内容漏斗：先做"做跨境电商为什么要注册香港公司"（泛流量圈人）
- 再做"注册香港公司避坑指南"（精准建信任）
- 最后"客户案例：帮XX公司3天完成注册"（转化收口）
- 人设：专注香港公司注册X年的专业顾问
- 五层漏斗：L1"为什么越来越多人注册香港公司"、L2"不注册香港公司你可能亏的税"、L3"注册流程避坑"、L4"我们的服务案例"

### 案例3：书单号（D类带货-特殊）

学员背景：做书单号，不出镜，靠文案+金句做内容。

策略：
- 选品：选择有话题性的书（心理学/自我成长/情感类）
- 内容形式：金句卡片+情绪文案+书籍推荐
- 选题方向：围绕目标人群的痛点做内容（如"为什么你总是很累"对应心理学书籍）
- 变现：橱窗挂书链接
- 关键：更新频率要高，内容质量要稳定，靠量取胜
