# 每日动态任务生成要素

## 输出契约（全班任务清单的格式硬约束，发出前逐字段打勾）

| 字段 | 必填 | 格式 | 示例 |
|------|------|------|------|
| 清单标题+统计行 | 是 | 日期 + 学员总数 + 🔴🟡🟢 分色人数 | 学员8人 \| 🔴风险1人 \| 🟡正常5人 \| 🟢观察2人 |
| 一、今天要对接谁 | 是 | 按优先级排序，🔴带建议动作和话术 | 张三，连续2天未交作业 → 1V1电话 |
| 二、每个人发什么 | 是 | 作业卡 + 知识卡片文件名 + 成品话术 | D6_选题方法论_知识卡片.png |
| 三、动态调整说明 | 是 | 每条含学员/原计划/调整原因/新任务，无调整写明 | 今日无计划外调整 |
| 天数表述 | 是 | 话术正文只写「第x天」，D前缀仅限卡片文件名 | 第6天的选题卡片，文件D6_选题方法论_知识卡片.png |

话术必须是成品，老师复制就能发。完整三段式结构以本文件第三节模板为准。

**双轨标注（25号〇节）：** 清单骨架（标题统计/对接排序/调整说明）走**老师轨**（简洁结构化，🔴🟡🟢分组+粗体关键词，一屏扫完）；「成品话术」字段走**学员轨**（完整人味，称呼+语气词，句子说完整，嵌套在清单里要用引号或字段框出来，框内学员轨框外老师轨）。话术字段可单独跑 `python scripts/check_prose.py --track 学员` 机器验。

---

**核心目标：** 标准 SOP 是固定时钟，但 B 端学员以获客为主、天天有突发问题，直接按 SOP 跑必然脱节。本要素让智能体每天根据老师随手同步的真实情况，动态生成当天的任务清单——老师负责执行，智能体负责判断。

**设计原则：** B 端客户要的是私人定制的感觉，但老师不可能给每个人做私人定制——智能体把"私人定制的判断"干了，老师只负责"执行动作"。

---

## 一、输入：老师随手同步（无格式要求）

老师每天以**语音转文字或随手打字**的方式同步昨天的情况，**不要求任何固定格式**——模板化会损害学员体验，老师怎么顺口怎么说。

### 解析规则（AI 的职责，不是老师的）

从非结构化文本中按学员名归集，提取四类信号：

| 信号 | 例子 | 提取要点 |
|------|------|----------|
| 作业状态 | "张三昨天作业交了""李四两天没交了" | 交了/没交/质量如何/连续天数 |
| 数据表现 | "王五那条爆了 5 万播放""赵六还是两百播放" | 播放量/涨粉/私信线索量 |
| 问题咨询 | "孙七问投流要不要加钱" | 学员主动问的问题（调 12 号做问题分类） |
| 情绪状态 | "周八昨天说想退费""吴九很焦虑" | 情绪信号优先标记（调 12 号情绪急救） |

### 解析纪律

1. **人名对不上时主动问**：同步里出现档案中没有的名字/昵称，列出来请老师确认，不要猜着归档
2. **没同步到的学员 ≠ 没事**：同步没提到的学员，用档案推断状态（昨天布置的作业到期没？连续几天没动静？），列入输出清单的「待确认」区
3. **语音里的口误要容错**：同音字、错字按上下文归到最可能的学员，归错了老师会在追问时纠正，纠正后立即改档案

## 二、判断引擎（三步，顺序不能乱）

对每个学员依次过三关：

### 第一关：风险信号（最高优先级，一票插队）

命中任一，当天任务优先是"处理风险"，不是"推进 SOP"：

- 连续 2 天没交作业 → 当天 1V1 电话（调指南话术：先聊状态，不说"你怎么不交作业"）
- 主动表达不满/焦虑/想退费 → 情绪急救（调 12 号第三层），当天不布置新任务
- 群里沉默超 3 天 → 主动联系，防埋雷（调 19 号消息回复三步法）
- 数据持续低迷（发 7 天播放全不过 500）→ 数据诊断（调第12天卡片，文件 D12_数据诊断与调整_知识卡片.png）+ 调整内容方向

### 第二关：分层路线（决定任务形态）

查学员档案的分层字段，任务形态完全不同：

| 分层 | 当天任务形态 | 详见 |
|------|--------------|------|
| B1 基础薄弱引流型 | 按水平给对标 → 仿拍标签视频；伪直播/录播只作辅助 | templates/SOP里程碑地图.md「B1 替代节奏」+ 10 号对标匹配原则 |
| B2 有基础获客变现型 | 压缩时钟，轻量陪跑：每天拍获客/变现向视频，智能体出文案 | 里程碑地图「B2 时钟」 |
| B3 高净值私人定制型 | 完整时钟 + 双号作业（数字人号 2 条 + 实拍号 1 条），每天 1V1 触点 | 里程碑地图「B3 时钟」 |

### 第三关：里程碑时钟（决定任务内容）

对照 templates/SOP里程碑地图.md：

- 找到学员「当前里程碑」（以完成标准为准，不以入营天数为准）
- 正常 → 布置下一里程碑任务 + 对应知识卡片
- 滞后 → 回到未完成的里程碑，降级任务量（例：文案写不出 → 改成先洗一条对标文案）
- 超前/数据爆了 → 加速到下一里程碑 + 考虑借东风放大（调 23 号）

## 三、输出：全班一次性任务清单（三段式）

每天早上老师打开智能体说"今天要做什么"，**一次性输出全班清单**，不用老师一个个问：

```
## 📋 今日任务 - {日期}
学员 N 人 | 🔴 风险处理 X 人 | 🟡 正常推进 Y 人 | 🟢 观察/待确认 Z 人

### 一、今天要对接谁（按优先级排序）
🔴 风险处理（插队优先）：
  1. {姓名} — {风险原因} → 建议动作：{1V1电话/情绪安抚/...}，话术：「可直接复制的话术」
🟡 正常推进：
  2. {姓名} — 当前里程碑 {第几天_主题} → 今天布置：{具体任务}
🟢 观察/待确认（昨天没同步到的）：
  3. {姓名} — {档案推断的状态} → 建议：{确认作业/轻触达话术}

### 二、每个人发什么
  {姓名}：作业卡 {任务} + 知识卡片 {第几天的主题，文件 D{天数}_主题.png} + 群发话术「...」
  （话术和作业卡 = 可直接复制转发给学员的成品，老师不用二次加工）

### 三、动态调整说明
  - {姓名}：原计划 {第几天}，因为 {原因}，调整为 {新任务}
  - （没有调整就写"今日无计划外调整"）
```

**输出纪律：**
1. 话术必须是成品，老师复制就能发——这是"体验感"的来源
2. 每条任务必须能指出依据：风险信号 / 分层路线 / 里程碑，说不出依据的任务不许布置
3. 全班清单控制在老师一屏能看完的密度；单个学员的细节（完整话术、作业卡全文）在老师追问时再展开
4. 天数只写「第x天」。D 前缀是知识卡片文件名的命名规则（老师找文件用），发给学员的话术正文、任务描述、里程碑名称里禁止出现 D6/D12 这类编号——学员看不懂

## 四、单学员追问模式

全班清单输出后，老师针对某个学员追问（"李四具体情况怎么样""李四今天发什么"）：

1. 展开该学员的完整判断链：风险 → 分层 → 里程碑 → 昨天同步的信号
2. 给出完整成品：完整话术 + 作业卡 + 要发的知识卡片文件名
3. 老师临时补充新情况（"李四刚说他今天没时间"）→ 立即重判，给出调整后的任务
4. 追问结束后**写回档案**（见第六节），不要只留在对话里

---

## 五、知识卡片调用规则

知识卡片库（知识卡片库/）是本要素的弹药库，三种用法：

1. **每日任务配卡**：布置哪个里程碑的任务，就配对应卡片（对应关系见 templates/SOP里程碑地图.md）。发学员优先用 PNG截图/（微信里直接能看），HTML知识卡片/ 用于老师自己查看细节
2. **答疑引用**：学员问的知识点，先查卡片内容组织回答（第6天到第28天的卡片覆盖选题/标题/开头/文案/对标/口播/数据/VLOG/矩阵/包装/热点/投流/复盘/素材库/变现/转化/橱窗/直播/长期运营/自媒体认知）——卡片里有的，不许自己编
3. **B1 学员选发**：B1 只发与当前仿拍任务相关的单张卡片，不按天全发

## 六、写回档案（每天闭环）

任务清单输出 + 老师执行反馈后，写回每个学员文件夹：

1. 学员档案.md：更新当前里程碑、分层（如发生调整）、风险信号状态、未解决问题清单
2. 03_作业与排期/：写入今日作业卡
3. 00_对话存档/：追加今日同步原文 + 关键判断（老师随手发的原文也要存，这是明天判断的上下文）
4. 写回规则遵循 20_学员文件维护要素（档案替换式更新，不追加堆积）

---

## 七、边界情况

- **新学员第一天**：无档案 → 先走建档流程（SKILL.md Phase 路由），不进任务清单
- **学员超过 30 人**：清单按 🔴🟡🟢 分区输出，🟢 区只列名字一句话，细节等追问
- **老师某天没同步任何情况**：纯按档案扫描出清单（退化为 19 号巡检模式），并在清单顶部标注"昨日无同步，以下基于档案推断"
- **学员已毕业/结营**：不进清单，在第28天结营后转入月度跟进节奏
- **C 类学员**：已推合作商 C 端承接，不进本清单（档案标注"已转 C 端"后归档）

---

## 八、与其他要素的分工

| 要素 | 管什么 |
|------|--------|
| 19_每日巡检 | 扫描学员文件夹、识别状态、优先级分类（消息回复节奏） |
| **24_每日动态任务生成** | **结合老师同步出今天的动态任务（任务节奏）** |
| 12_消息识别 | 同步文本里单个问题的分类与消解 |
| 10_教练沟通 | 具体话术的沟通法则、对标匹配原则 |
| 20_学员文件维护 | 档案写回的格式与维护规则 |

每天的完整节奏：**19 号扫描排雷 → 本文件出任务清单 → 老师执行 → 20 号规则写回档案**。
