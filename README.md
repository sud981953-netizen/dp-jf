# dp-jf 账号教练技能包

给短视频交付教练用的 Agent Skill。教练老师带很多学员，行业各异（美业、餐饮、财税、二手车、知识付费、疗愈等），这个技能帮你把学员的抖音账号从 0 做起来。

适用于豆包、Claude Code、Codex 等支持 Agent Skills（`SKILL.md`）的智能体。

## 它做什么

重心在日常教练循环：**教知识点 → 布置作业 → 评价视频 → 调整方向**。

| 阶段 | 能力 |
|------|------|
| 前置门槛 | 学员信息采集、存件目录管理、接手新学员 |
| 账号规划 | 摸底 → 分叉口判断 → 行业分类 → 定位 → 变现路径 → 主页搭建，输出账号策划方案 |
| 日常教练 | 每日一个知识点 + 一条作业，作业卡流水线生成，学员视频逐条评价 |
| 周复盘 | 每周回看方向与配比，调整下一周排期 |
| 晨间巡检 | 每日检查待办与学员动态，生成当天任务 |
| 文案仿写 | 内置 552 条实战爆款语料库，写文案前先检索锚点，照着真爆款的结构写 |

它不做后台数据分析，不做完播率诊断——那些看后台就行。它管的是**方向、作业、评价**。

## 核心机制

- **答案来源唯一**：28 个要素定义文件覆盖的问题必须先读文件再答，回答标注「依据：XX 号文件 第 X 节」。禁止拿网上通用建议（养号、互粉、破播放）凑数
- **文案锚点硬门槛**：文案/开头/金句类产出必须标注「仿写锚点：语料 #id（借它的 XX 句式）」，没有锚点的文案不许发。借网感句式结构，不借题材
- **文风机器校验**：长文本产出先落盘，跑 `scripts/check_prose.py` 校验禁词，报告清零才发
- **启动自检**：技能触发先查文件完整性，缺文件就大声失败并停工，禁止静默降级
- **状态落文件**：存件地址、最后巡检日期写进 `config/设置.md`，跨会话不靠对话记忆

## 安装方式

### 豆包

1. 打开豆包客户端，进入办公模式
2. 选择「技能 → 创建技能」
3. 输入本仓库的 GitHub 链接，豆包会自动进入 Agent 模式执行安装，中途点击授权确认即可

### Claude Code / Codex 等开发类 Agent

```bash
git clone https://github.com/sud981953-netizen/dp-jf.git
cp -r dp-jf ~/.claude/skills/dp-jf
```

或者把 `dp-jf` 整个文件夹复制到对应 Agent 的技能目录。**注意 `SKILL.md` 必须在技能文件夹根部，`name: dp-jf` 只能出现一份**，否则会被识别成两个同名技能。

### 触发方式

装好后对 AI 说 `/dp-jf`、`/账号教练`、「帮我规划学员账号」、「帮我布置作业」、「帮我评价视频」。

## 更新技能

### 我怎么知道装的是不是最新版

两个办法，都不用懂技术：

1. **看版本号**：本地技能目录里 `version.md` 顶部的「当前版本」和「发布日期」，和仓库页 https://github.com/sud981953-netizen/dp-jf 上的 `version.md` 比一下。一样就是最新
2. **让 AI 帮你查**：直接说「检查一下 dp-jf 有没有新版」，AI 会比对仓库并告诉你结果

更硬的证据是**内容指纹**：仓库 `文件清单.json` 里的 `fingerprint` 字段，和你本地按清单重算的指纹一致，说明逐字节相同——不是「大概齐是最新」，而是确认为最新。更新回执里会报这个数。

### 怎么更新

**直接对 AI 说「更新 dp-jf」**（或「升级账号教练」「/dp-jf-update」），AI 会读仓库里的 `更新说明.md` 照着执行：

- 先核对版本，已经是最新就告诉你「无需更新」，不做任何改动
- 需要更新时按安装方式自动选路径：
  - 你的技能目录是用 `git clone` 装的 → 用 git 拉取，自动删掉旧版残留，只留最新
  - 是手动复制 / 上传目录装的 → 按仓库 `文件清单.json` 逐文件比对，删旧留新
- 更新完输出一份**更新回执**：版本从几变到几、新增/更新/删除各几个文件、校验结果、以及本次更新内容摘要

### 更新会保留什么

这两样**永远不会被覆盖或删除**：

- `config/设置.md` — 你的存件地址，更新后不用重新提供
- 学员数据 — 存在你指定的存件地址下，技能更新完全不碰

### 更新完怎么确认

看回执里的四项校验：版本号一致 ✅、内容指纹一致 ✅、关键文件齐全 ✅、启动自检通过 ✅。四项全过才算更新成功。如果哪项没过，回执会如实列出出错的文件，不会假装成功。

## 使用前提醒

- 首次使用会让你指定一个**存件地址**，学员文件夹都建在那里，设置写进 `config/设置.md`（本机私有，不随仓库分发）
- `templates/` 是输出格式的唯一事实源，`要素定义库/` 是方法论内容的唯一事实源，两处说法打架时按这个顺序裁定
- 升级技能时保留 `config/设置.md` 和存件地址下的学员文件夹，不要覆盖

## 说明

- 本技能基于创亿商学交付方法论，内容持续更新
- 知识卡片库 PNG 版体积较大（约 24MB），如需轻量分发包可跑 `scripts/打包分发包.ps1`，会自动排除截图、缓存与本机私有设置
