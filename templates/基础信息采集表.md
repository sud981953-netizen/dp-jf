## 采集后自动判定
- **B/C 类分流**：看第5条 + 报课目的反确认（C 类 = 以做自媒体为目的，含无业及想做自媒体项目的）→ C 类推合作商 C 端；B 类进入下方三层判定
- **B 端三层判定（B1/B2/B3）**：仅对 B 类学员，看第9条（经验）+ 第10条（目标）+ 第19条（投入时间）：
  - **B1 基础薄弱引流型**：基础薄弱、只想给生意引流获客、做不了 IP → 标签视频仿拍路线（伪直播/录播仅辅助）
  - **B2 有基础获客变现型**：有一点基础、要稳定获客变现 → 轻量陪跑 SOP + 智能体出文案
  - **B3 高净值私人定制型**：把业务/账号当事业做、每天能稳定投入 2-3 小时 → 全套 30 天 SOP 手把手
  - 分不清 → 先按 B2 走 1-2 天，观察后再调（详见 templates/SOP里程碑地图.md）
- **同城/全国**：看第6条（线下店铺）+ 反确认
- **账号阶段**：看第8条（粉丝量）→ 冷启动/成长/成熟
- **出镜能力**：看第17条 → 决定价值型呈现形式 + 72变筛选
- **身份倾向**：看第5条 → 印证同城/全国判定
