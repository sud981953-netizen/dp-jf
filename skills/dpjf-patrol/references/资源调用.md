# dpjf-patrol 资源调用契约

| 条件 | 资料 | 应用 |
|---|---|---|
| 多学员巡检 | `19_每日巡检要素` | 扫描、优先级和输出，旧固定阈值只作候选 |
| 老师随手同步 | `24_每日动态任务生成要素` | 按人归集、风险和里程碑；同音名不猜 |
| 学员路径与证据 | `dpjf-student`＋`20_学员文件维护要素` | 身份、目录、档案和跨文件状态 |
| 需要任务展开 | 对应业务子技能和该学员证据包 | 只展开一人，不生成全班长任务 |
| 学员话术 | `25_活人感输出规范要素` | 完整自然，老师学员分轨 |

输出必须写覆盖范围和记录时间；无法取得完整资料时，不能称“全员实时状态”。
