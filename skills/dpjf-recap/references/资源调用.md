# dpjf-recap 资源调用契约

| 条件 | 资料 | 应用 |
|---|---|---|
| 所有复盘 | `templates/周复盘表.md`、`方法补充/复盘与增长.md` | 时间线、内容目的、单变量和回填 |
| 看作品共性问题 | `09_视频评价要素` | 提炼重复问题，不全量重评 |
| 看内容与咨询匹配 | `11`、`14`、`方法补充/内容目的与选题.md` | 流量构成和业务承接 |
| 原任务调整 | `24_每日动态任务生成要素`、`templates/SOP里程碑地图.md` | 实际完成状态和资源降级 |
| 档案与历史 | `dpjf-student`＋`20_学员文件维护要素` | 证据范围、历史事实和写入授权 |
| 需要周计划 | `templates/周排期表.md`、`月规划表.md` | 只按明确要求，保留调整空间 |

复盘结论必须能指回具体记录；数据不足时写“无法断定”，不拿单个波动证明方法。
