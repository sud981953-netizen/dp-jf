# dpjf-update 资源调用契约

| 条件 | 资料 | 应用 |
|---|---|---|
| 本地版本 | 包根 `version.json` | 唯一当前版本记录 |
| 更新协议 | `维护/更新说明.md` | 来源、备份、保留和验证 |
| 旧清单 | `维护/历史资料/` | 只作追溯，不证明当前发布 |
| 行为迭代 | 当前 `evals/` 和写入前快照 | 前后对比和回归 |
| 安装验证 | `skills/dpjf/scripts/list-skills.py` 与真实加载路径 | 确认生效副本 |

远端来源未确认时停止联网更新，不猜版本或覆盖本地候选。
