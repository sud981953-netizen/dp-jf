# 技能更新：详细判断方法

## 1. 确定当前实际来源

解析当前技能的真实包根路径，读取版本元数据和用户已配置的来源。Git 安装可只读 remote、status 和 HEAD；非 Git 安装查包内来源信息。来源不存在或指向旧 dp-jf 时如实说明，不能把旧仓库的版本当 dpjf 新版本。只问本地版本则到此结束，不访问网络。

## 2. 检查更新

用户要求比较远端时，使用实际明确可信的来源读取版本和文件清单；记录访问结果和来源。不同版本只是候选差异，版本相同不能证明文件一致；联网失败不称最新版。检查模式不写入或安装。

## 3. 检查本地状态

明确哪些是用户改动、未跟踪文件、配置、学员数据、共享资源和安装链接。不可执行 git reset --hard、git clean 或以清单没有列出为由删未知文件。用户改动不能被自动覆盖；来源身份不清或内容冲突时保留并报告。

## 4. 准备候选与备份

仅在用户明确要求更新时，从明确来源在独立临时目录准备候选。验证每个相对路径不越界、逐项 SHA-256 与来源清单一致；逐文件计算实际哈希，不只对清单本身做哈希。创建可恢复备份并校验；无法保护本地修改时停止冲突部分。

## 5. 应用与验收

安全应用无冲突变更，必要时因版本依赖整体暂停，保留学员资料和用户配置。核验主路由、全部登记子技能、共享资源、脚本和当前实际安装链接。部分失败列清楚，不宣布成功；回退使用已验证的备份。来源版本较低时不自动降级。
