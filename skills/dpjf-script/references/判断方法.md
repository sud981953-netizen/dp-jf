# 脚本与文案：详细判断方法

## 1. 先做材料账

确定作者、受众、主题、使用场景、现有原文、用户希望保留的观点与限制。将可引用事实、本人自述、案例、未验证主张和缺口分开；可概括真实经历，不能捏造年限、成果、病情或客户评价。

## 2. 内容先于套公式

先写清一句核心主张和观众看完能带走的东西。检查能否用已知事实解释、演示或讲出故事；素材不足时用占位或给最小补充问题。历史04号五模块是工具而不是所有视频必须包含的固定五段。

## 3. 新稿路径

从一个具体问题、观察或场景进入；展开中每段承担一个功能（解释、步骤、证据或故事进展）；结束时收住主要意思或给自然的下一步。根据媒介和老师的要求控制长度，不给未经验证的“每30秒必须有金句”。用学员真实说法，行业术语在需要时解释。

## 4. 诊断与改写路径

只检查：按原文位置引用问题，说明目标观众可能在哪里看不懂、与目标脱节或缺证据，指出怎么改；不强行凑问题。明确改稿：先保留论点、案例、数字及用户希望保留的语气，删除重复、补必要连接或重排；新增事实先用待核标记，不能替用户编。

## 5. 完成检查

开头是否兑现，论证与事实是否一致，是否能口播，是否贴近目标客户，是否能在拍摄条件下实现。语料检索可帮助结构和节奏，必须确认相关、禁止照抄；无命中可正常创作。先给成品，再按需说明关键改动；不把形式脚本检查等同质量验证。
