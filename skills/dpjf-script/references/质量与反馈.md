# 文案质量与反馈纠偏

## 关键评估

- 每段有可说明的功能：引入问题、解释、证据、示范或收束；没有贡献的重复才考虑删。
- 核对指代：这、这样、它、那个选择分别指什么？断裂处引用原句，解释观众缺的关键前提。
- 核对素材：例子、个人经历和数据来自哪里？素材缺失时使用明确待补标记，而不是写成已发生。
- 核对口播：连续长句能否听懂，行业词是否对目标客户必要；口语化不等于一味加语气词。
- 核对用户范围：只检查不交整篇重写；已明确改稿则直接改，不反复索要许可；只改开头不重做结尾。

## 反馈处理

老师说“有AI味”，引用具体空洞表述或不自然的连接，再按用户希望改到何种程度处理。说“太像广告”，指出哪句没有提供顾客可核实信息，并询问或保留真实服务细节。用户要求保留强观点时不自动削弱；仅当关键事实或兑现有问题时明确指出。
