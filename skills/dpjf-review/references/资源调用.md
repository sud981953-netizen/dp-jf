# dpjf-review 资源调用契约

| 条件 | 资料 | 应用 |
|---|---|---|
| 所有评价 | `09_视频评价要素`、`templates/视频评价表.md` | 评价维度和输出；未知不填好坏 |
| 内容质量 | `04`、`26`、`方法补充/文案故事与呈现.md` | 主张、证据、广告味、横纵信息 |
| 开头与受众 | `03`、`方法补充/素材标题与平台.md` | 开头独立性和兑现 |
| 画面与呈现 | `05_呈现要素`、`17_产品可视化要素` | 只见材料支持的拍法和产品细节 |
| 原定72变 | `06`＋72变源文 | 核对结构和适配 |
| 反馈历史不足 | `dpjf-student` 证据包 | 最近评价、重复问题和未知项 |
| 学员话术 | `10_教练沟通要素`、`25_活人感输出规范要素` | 先有效后改进，自然完整 |

不得采用“画面不行内容再好也没用”覆盖证据边界；只有文字时内容可以先评。
