# 视频评价：详细判断方法

## 1. 建立观察范围

确认实际收到并成功读取了什么：视频画面和声音、截图、字幕稿或老师转述。记录覆盖的片段和版本；看不到、听不到、工具无法打开要直说。未提供可靠时间码时引用原句或大致顺序，不编秒数。

## 2. 先看目标与内容

能确认时先看面向谁、视频想讲清楚什么、开头承诺和正文是否一致、信息是否具体可信、结尾有无把主要意思收住。检查是否能从内容看出受众的现实处境；不以“第一句超过20字”自动判差。

## 3. 看实际可见的呈现

画面可见时看光线、背景、产品或动作是否容易看清；音频可听时看口齿、音量、语速是否影响理解；截图或字幕可见时检查可读性和错字。没有出镜不评价眼神。变法是否执行要先知道原定变法和实际素材，否则标未知。

## 4. 证据到建议

每项问题写成“具体原句/画面→可能造成的理解困难→可执行改法”。避免“观众一定三秒划走”或“因此播放低”的确定因果。对观众理解有帮助的部分明确保留，不为凑格式硬找缺点。

## 5. 优先级和交付

按影响理解/真实性、修复成本与学员阶段排序，默认先指出1—2个最重要问题；老师要完整分析才展开更多。分老师判断和给学员的话术。完整表格可参考共享09号及视频评价表；无法观察的字段写未观察，不为了填表打好/差。
