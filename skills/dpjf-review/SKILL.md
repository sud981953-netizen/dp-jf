# dpjf-review：视频评价与改进

评价的任务是帮助学员知道这条哪里有效、最需要改哪一件事、下一条具体怎样做。不是把五维表格全部填满，也不是把老师的主观好恶说成平台结果。

## 一、建立观察范围

先记录：

- 收到的是完整视频、片段、截图、字幕、文稿还是转述；
- 实际成功读取了哪些部分；
- 作品版本、时间、选题、原定变法和制作状态；
- 老师希望评价整体还是某一项；
- 是否有对应数据及其统计口径。

只有文字时不评画面、眼神、声音和剪辑；只有截图时不评动态节奏；工具打不开就直说。没有可靠时间码时引用原句或顺序，不编秒数。

## 二、先看内容目的与核心筹码

先问：

- 这条内容面向谁，主要任务是什么；
- 观众最初以为它要讲什么；
- 最核心、最值得停留的元素是什么；
- 正文是否兑现标题和开头；
- 观众看完能得到什么。

不能用后文的优点反向掩盖开头没有留人，也不能仅凭播放数据判断内容哪里有问题。

## 三、按实际材料评价

### 内容与结构

- 核心主张是否明确；
- 目标观众能否认出自己；
- 证据和细节是否具体可信；
- 信息是否重复、断裂或过密；
- 是否有横向文字与纵向画面共同传递信息；
- 是否像广告或抽象说教。

### 可见画面

只有实际看到时检查：光线、背景、动作、产品细节、字幕可读性和画面是否帮助理解。

### 可听声音

只有实际听到时检查：口齿、音量、语速和声音是否妨碍理解。

### 原定变法

知道原定变法并核对源文后，才判断核心结构是否执行和适配。未指定变法时不硬套。

## 四、证据到建议

每项问题写成：

```text
具体原句／画面／转述
→ 可能造成的理解或信任障碍
→ 最小可执行改法
```

同时指出需要保留的有效部分，不为凑格式硬找缺点。不能写“观众一定三秒划走”“所以播放低”，只能说材料支持的理解风险。

已拍不可补时区分：

- 这条通过剪辑、字幕或顺序还能改什么；
- 哪些只能下一条重拍；
- 无法核看声画时标待核。

## 五、确定优先级

按以下顺序综合判断，不机械“画面先行”：

1. 真实性和明显事实问题；
2. 目标观众是否理解与开头是否兑现；
3. 核心主张和证据是否成立；
4. 声画是否妨碍理解；
5. 修复成本与学员当前阶段。

默认先给 1～2 个最重要问题，完整分析只在老师要求时展开。学员连续出现同一问题时，先解决复发问题再推进新技巧。

## 六、输出契约

```markdown
## 先说结论
{主要保留项＋最优先改进项}

## 最该先改
1. 证据：{原句／画面}
   影响：{理解或信任风险}
   改法：{具体动作}

## 已经有效、请保留
{具体部分}

## 下一条怎么做
{一个可执行方向}

## 本次未观察
{未看到的维度和材料}
```

完整评价时可读取模板，但未知字段写“未观察”，不能为了填满打“好／差”。需要发给学员时另给自然话术。

## 七、质量自检

- 是否只评价实际观察的维度？
- 是否先说最重要的保留项和改进项？
- 每条建议是否有具体证据和动作？
- 是否区分这条可改与下条再做？
- 是否没有把相关当因果或预测播放？
