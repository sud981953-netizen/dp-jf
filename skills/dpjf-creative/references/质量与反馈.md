# 拍法质量与反馈纠偏

## 五维匹配

1. 目标：该拍法是帮助观众理解步骤、看到产品细节，还是引发讨论？不能把“用第几变”作为内容目的。
2. 受众：第一画面与讲述内容是否让目标人群理解主题？
3. 出镜：区分露脸、手部、配音和纯字幕，遵守学员明确的边界。
4. 资源：每个镜头需要的物品、参与者、场地和时间是否已具备？缺失的先问或给替代。
5. 结构出处：提到72变编号前核查实际条目，历史标签只作选择辅助，不代表成功率。

## 反馈处理

“不会拍”：把方案压缩成第一镜头、第二镜头、结尾，说明手机放哪里、拍什么；不要只说“拍得自然”。“没时间”：删场景与转场，保留核心演示。“不出镜”：改用真实物件、字幕或学员允许的画面，不私自使用顾客肖像。
