# dpjf-creative 资源调用契约

| 条件 | 资料 | 应用 |
|---|---|---|
| 指定或选择72变 | `06_72变要素`＋`00_短视频内容创作72变.md` | 先索引后源文，核对编号和结构 |
| 选择呈现形式 | `05_呈现要素` | 口播、VLOG、不出镜和调性 |
| 设计产品画面 | `17_产品可视化要素` | 展示方式、行业素材和检查 |
| 需要故事或冲突 | `07_创意故事要素`、`方法补充/文案故事与呈现.md` | 稀缺、冲突、动作和画面 |
| 需要横纵信息 | `方法补充/文案故事与呈现.md` | 文字、场景、人物、道具和声音组合 |
| 学员条件不足 | `dpjf-student` 证据包 | 真实素材、时间和意愿，不猜 |
| 输出作业式拍法 | `25_活人感输出规范要素` | 完整步骤和自然话术 |

任何形式建议都要指出真实素材和完成标准；只有形式名称不算交付。
