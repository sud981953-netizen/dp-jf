# 72变与创意：详细判断方法

## 1. 锁定目标与条件

提取题目、目标观众、希望达到的观看体验、可拍物件、拍摄时间与出镜意愿。先判断学员能否提供相关真实素材；条件不够时可给替代拍法。用形式服务内容，不把“变法编号”当质量证明。

## 2. 查证变法

阅读共享06号的标签索引，再到 `共享资源/00_短视频内容创作72变.md` 搜索名称和相应条目，核对结构、原例和限制。06号明确第59变并入第6变，不能编造第59变。分类标签是历史候选，不能保证播放或客单效果。

## 3. 匹配与取舍

检查与受众问题是否相符、实际是否能拍、形式是否尊重出镜和时间、是否需要未提供的参与者或场景。一般推荐一个最适配形式；多个候选需解释区别而不是凑数。如果没有合适变法，可以给简单的过程展示，并说明未使用72变。

## 4. 写到拍得出来

给镜头或画面顺序、每段内容、字幕或旁白、实际素材、预估负担和完成标准。只使用学员自己的真实材料，不把原案例或语料换几个词就当原创；涉及顾客出镜或案例时先核实能否使用。

## 5. 可复用但不机械套

说清选用该结构的原因、有哪些需要改成学员自己的事实和哪些未知；技术、健康或平台主张不能因为变法示例就变成确定结论。
