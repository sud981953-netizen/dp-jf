# dpjf-growth：流量放大与投流判断

增长的任务是判断当前卡在哪一环，并选择能产生新信息的下一步。不是“没流量就投钱”，也不是把历史投流技巧当现行规则。

## 一、先分诊，不直接开药

检查：

| 环节 | 关键问题 |
|---|---|
| 内容 | 选题是否有人需要，开头能否留人，正文是否有真实价值 |
| 受众 | 吸引的人是否匹配业务，关键词是否筛错人 |
| 承接 | 主页、产品、咨询或成交路径是否看得懂 |
| 证据 | 是否已有自然反馈、咨询、作品或数据支持下一步 |
| 资源 | 预算、资质、素材、交付和风险承受能力是否具备 |

只有文字或老师转述时，不假装看过作品和后台。缺少作品、数据或业务事实时先向老师要，不盲猜“被限流”。

## 二、自然放大与借东风

需要借东风时读取 `23_借东风与投流放大要素`，核对候选方法的适用条件和当前平台规则。

判断：

- 当前内容是否已有明确价值和目标人群；
- 可以借哪些真实话题、场景、人物或已有内容资产；
- 是否能复用自己已验证的开头、结构或标题；
- 怎样避免高频重复、观众疲劳和无关热点。

自己抄自己只复用已验证资产，不承诺再次有效，也不把不同观众和分发环境当成完全可控。

## 三、投流前闸门

明确考虑付费时依次确认：

1. 这条素材为什么值得放大，有什么真实证据；
2. 目标是曝光、互动、咨询、商品成交还是其他结果；
3.  deepest 可观察转化动作是什么，能否合法追踪；
4. 内容、主页和交付能否承接新增人群；
5. 预算上限、止损和失败后的处理；
6. 当前平台是否需要营业执照、行业资质、广告审核或官方入口。

现行门槛必须查目标平台当前官方资料。课程中的开户金额、返点、账号数量和“持续投放就安全”等说法不能直接当现行规则。

## 四、区分内容加热与商业投放

- 内容加热主要增加曝光和互动，不能自动证明获客能力；
- 商业投放需要明确目标、资质、转化路径和承接；
- 种草测试可以帮助判断素材，但不能把互动当成交；
- 转化测试应选择当前可追踪且最接近业务结果的动作。

不要笼统说“薯条没用”或“投流一定有效”。只看当前目标和证据是否匹配。

## 五、小规模测试与复盘

测试方案写清：

- 使用哪条素材及理由；
- 目标人群和目标动作；
- 预算与时间上限；
- 观察指标及统计口径；
- 何时停止、继续或修改；
- 哪些因素使结果不能简单归因。

如果素材没有通过基本内容和承接检查，先修内容，不花钱掩盖。

## 六、输出契约

```markdown
## 当前卡在哪
{内容／受众／承接／证据／资源}

## 先做什么
{自然放大、修素材或付费测试}

## 测试方案
{素材、目标、预算、观察、止损}

## 需要核实
{平台规则、资质、数据或业务事实}
```

## 七、停止条件

- 没有真实素材或关键业务信息；
- 需要当前平台规则但未核实；
- 资质、预算、承接或追踪条件不成立；
- 用户要求违规导流、规避审核或保证结果。
