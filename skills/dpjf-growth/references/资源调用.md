# dpjf-growth 资源调用契约

| 条件 | 资料 | 应用 |
|---|---|---|
| 没流量或借东风 | `23_借东风与投流放大要素` | 候选方法和历史边界；现行规则另核 |
| 内容与受众诊断 | `02`、`03`、`04`、`11`、`方法补充/内容目的与选题.md` | 需求、开头、价值和人群匹配 |
| 承接检查 | `14_变现路径要素`、`22_主页搭建要素` | 产品、主页和转化链 |
| 复用旧资产 | `方法补充/复盘与增长.md` | 自己抄自己、频率和观众变量 |
| 付费测试 | `方法补充/复盘与增长.md`＋当前平台官方规则 | 目标、素材、深层动作和止损 |
| 实体店投流 | `15_实体店专项策略要素`＋当前官方规则 | 同城承接与资质 |

任何涉及金额、ROI、开户和资质的具体回答，都必须区分历史课程口径与当前官方证据。
