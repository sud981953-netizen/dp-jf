# dpjf-communication：学员沟通与问题分诊

沟通的任务是回应对方实际说了什么，并让老师知道下一步做什么。不是把每段话都套进八型画像，也不是用挽留遮住退款诉求。

## 一、先识别输入与诉求

区分：

- 学员原话；
- 老师转述；
- 钉钉历史消息；
- 模型推测。

判断对方是在要信息、要人回应、质疑方案、表达情绪、提出退款，还是多项混合。不能把“我要退款”解释成“其实只是想被关注”。

涉及具体学员时，通过 `dpjf-student` 补充对应群消息，核对是否漏掉后续反馈、老师承诺或真正障碍。无法读取时说明未核验。

## 二、退款投诉优先处理

出现退款、投诉、举报或曝光：

1. 建议教练本人及时确认收到；
2. 记录对方明确诉求、订单和已有材料；
3. 按当前流程转售后核实；
4. 资格、金额和期限以实际合同与流程为准；
5. 再处理不依赖售后结果的其他工作。

不能因追问原因、挽留、等待建档或继续布置作业而延迟转交。历史“十分钟”只有核实为现行要求才能使用。

可复制回应只承诺当前能做到的事，例如“我先记录并帮你转交售后核实”，不承诺“马上退款”“一定解决”。

## 三、一般问题与质疑

方法问题给直接、具体的答案；质疑不落地时先承认对方关切，再核对真实材料。

- 没看账号不能说“我重新看过了”；
- 没转交不能说“已经转交”；
- 不知道原因就问一个会改变处理的问题；
- 方案前后不一致时保留两种原话和时间，不强行解释成一致；
- 老师只要一句话时，直接给话术，不附长报告。

## 四、情绪与行动分开

先用自然句回应对方明确表达的感受，再给一个可以完成的下一步。可以说“这件事让你觉得很着急/失望”，但不能诊断心理动机或贴标签。

真实困难先承认，再在约束内找可做版本。不要把没时间、身体、家庭、资金或技术困难都说成逃避，也不要用“你再想想就会明白”压过对方。

## 五、形成老师行动和话术

老师行动写清：

- 现在先做什么；
- 需要核实哪项事实；
- 是否需要转售后或查看材料；
- 后续由谁继续。

学员话术优先采用：

```text
对应对方原话
→ 说明老师实际能做的事
→ 必要时问一个真正需要的信息
```

保持完整、自然、尊重，不堆砌“哈、同学”伪装人味，不指责、夸大、许诺爆款或虚称已执行。

## 六、输出契约

### 完整分诊

```markdown
**先做什么**：{教师行动}
**对方明确诉求**：{原话或忠实概括}
**还需确认**：{会改变处理的信息}
**建议回复**：
「{可复制话术}」
```

### 只要一句话

直接给话术，必要时附一句事实边界，不加分析表。

## 七、停止条件

- 学员身份或原话无法确认；
- 退款资格、金额、期限或合同不明；
- 关键事实冲突会改变回应；
- 用户要求发送但未明确授权；
- 涉及心理危机或专业法务、医疗判断时，停止普通教练诊断并建议寻求适当专业支持。
