# dpjf-communication 资源调用契约

| 条件 | 资料 | 应用 |
|---|---|---|
| 所有学员消息 | `12_消息识别与问题分类要素` | 来源、分类、情绪和真问题；旧输出字段不替代当前请求 |
| 沟通与信任 | `10_教练沟通要素` | 信任、回应和具体沟通 |
| 情绪或留存 | `27_学员心理画像与留存沟通要素` | 只作可能解释和真实话术参考，不贴八型标签 |
| 学员原话不全 | `dpjf-student` 证据包 | 钉钉补充、时间和冲突 |
| 退款投诉 | 当前真实合同与售后流程 | 只确认、记录和转交；旧十分钟不默认生效 |
| 学员话术 | `25_活人感输出规范要素` | 完整自然、双轨和事实边界 |
| 结营问卷 | `templates/结营调查问卷与发送话术.md` | 仅结营或明确需要时使用 |

退款、投诉和证据类任务优先真实流程，任何课程话术都不能越过合同和授权。
