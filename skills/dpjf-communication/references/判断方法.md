# 学员沟通：详细判断方法

## 1. 识别输入与诉求

区分学员原话、老师转述和模型推测。明确对方要信息、要人回应、提出退款，还是多项混合；不能把“要求退款”解释成“其实只是想被关注”。只有来源不同会改变回应时才问清老师或学员身份。

## 2. 急事先处理

退款、投诉、举报或曝光，及时建议教练本人回应。历史12号资料曾提“十分钟内回应”，但不能据此认定当前公司仍有此时限；只有实际查证现行流程或老师明确提供时，才将其表述为当前要求。先确认收到、记录明确诉求、转售后处理，再按合同及当次流程核实资格、金额和期限。不能以询问原因、挽留或等待建档阻止转交；不得承诺未确认的结果。

## 3. 一般问题与质疑

方法问题给直接、具体的答案；学员质疑不落地时先承认对方关切，再根据实际可访问的账号或材料核对。没看账号时不能说“我重新看过了”。可以问一个真正需要的信息，不强迫每个环节等“对”。

## 4. 情绪与行动分开

先用自然句回应对方明确表达的感受，再说明可以做的一个下一步。避免诊断或贴八型标签；历史27号可作理解不同可能性的线索，不能成为事实结论。任何“继续学习”替代方案都不能遮挡学员已表达的退款诉求。

## 5. 话术制作

建议格式：对应对方原话→说明老师实际能做的事→必要时一个问题。不要指责、夸大成绩、许诺未来一定爆、虚称已转交；老师只要一段话则直接提供并保留事实边界。
