# dpjf-topic：学员选题开发

选题要回答：这条内容呈现一件什么事，谁会关心，观众能得到什么，学员凭什么讲，以及今天能不能拍出来。不要把“避坑、干货、认知、共鸣”当成具体题目。

## 一、入口模式

- **A 从零开发**：有业务和素材，需要候选；
- **B 今天一条**：资源和时间有限，只要一个最可执行题目；
- **C 选题池**：需要一批能持续使用的题；
- **D 筛选已有题**：判断保留、改写或放弃；
- **E 判断是否值得拍**：只回答该题，不扩成完整规划。

用户指定数量、受众、平台和出镜条件时优先遵守，不为了凑数生成近义题。

## 二、先锁定目的与真实素材

先确定内容主要目的：认知、关注、咨询、到店、成交或信任。目的不同，选题评价标准不同。

整理五类素材：

1. 真实产品、服务、交付和场景；
2. 客户原话、常见问题和决策障碍；
3. 学员经历、案例、数据和资质；
4. 可拍物件、动作、人物和过程；
5. 当前业务目标及可承接方式。

缺少会改变题目的事实，先问教务老师。不能把课程案例中的数字和经历移植给学员。

## 三、从五级星图拆出具体题

按资料选择业务星图或个人星图：

```text
行业／个人
→ 细分领域／人生阶段
→ 产品服务／关键事件
→ 使用或决策场景／具体转折
→ 观众此刻的问题／可呈现的事
```

第五级必须是一件可理解、可呈现的事，而不是一个分类词。例如“装修避坑”不够，继续落到“签装修合同时，‘按实结算’这句话可能怎样影响最终费用”。没有真实证据时，不沿用课程中的具体金额和效果。

## 四、用需求＋解决方案形成候选

每个候选写清：

```text
谁，在什么处境下，需要什么
→ 这条内容提供什么判断、方法、体验或情绪
→ 学员用什么真实材料兑现
```

可从六类角度变换，但角度只是工具：

- 避坑或揭秘：提供以前不知道的风险或机制；
- 对比或测评：降低选择成本；
- 教程或方法：帮助完成一个动作；
- 案例或故事：用真实过程建立理解和信任；
- 观点或认知：提供解释日常现象的新框架；
- 过程或现场：让观众看到稀缺、真实或有情绪的场景。

客户已经提出的问题优先于凭空想象；老师聊天、钉钉群和服务现场优先于通用热点。

## 五、检查供需与陌生化

分别判断：

- **需求**：哪些人已经关心，关系是高频、阶段性还是偶发；
- **供给**：同类内容是否已被反复讲烂；
- **差异**：需求本身、解决方案、证据、人物或场景有什么真实不同；
- **时效**：热点是否仍有效，平台规则是否需要核实。

不能仅因“别人做过”就放弃，也不能仅因“反常识”就推荐。无法确认供给时，给搜索和验证方法，不假装查过全平台。

## 六、A／B 类选题与隐含优点

### A 类：事情本身有吸引力

有真实稀缺事件、反差、战绩或经历时，可以直接呈现。不要为了套公式把亮点藏起来，也不能拿别人独特的 A 类事件当学员可复刻模板。

### B 类：日常内容需要素材支撑

普通知识、服务和过程需要找到：

- 数据或真实结果；
- 权威或专业证据；
- 金句或可复述判断；
- 认知冲突；
- 痛点或具体处境。

如果业务已有真实客户，追问“客户为什么愿意付钱”，从付费理由中挖掘隐含优点。不能把缺点包装成虚假战绩。

## 七、筛选与排序

逐题检查：

| 检查 | 通过标准 |
|---|---|
| 目的 | 能说明主要服务哪个业务或信任目标 |
| 受众 | 能指出谁关心以及为什么 |
| 回报 | 看完得到判断、方法、情绪、故事或体验 |
| 证据 | 学员有真实事实、经历、材料或可信解释 |
| 可拍 | 在当前时间、场地、设备和出镜条件下能完成 |
| 承接 | 吸引的人与后续产品或账号方向不冲突 |

优先级通常是“业务相关且今天能拍”高于“看起来更大但缺素材”。题目过宽时收窄；题目过窄且与业务无关时不为了流量硬扩。

## 八、输出契约

### 单条推荐

```markdown
**推荐题**：{完整具体题目}
**面向谁**：{处境和关心理由}
**观众能得到**：{主要回报}
**用什么拍**：{真实素材、首个画面}
**为什么现在做**：{目的和可行性}
**还需确认**：{仅有影响事实}
```

### 选题池

每条只写“题目＋受众＋真实素材／首个画面”。另给首选及一句理由，不用大表和长分析压住老师。用户只要题目时，不加整稿、标题或封面。

## 九、质量自检

- 每题是否是一件具体可呈现的事？
- 是否说明目标观众和观看回报？
- 是否有真实素材，而不是行业通用套话？
- 是否经过目的、供需、证据和可拍性筛选？
- 是否没有虚构数字、经历和平台结果？
- 是否只交付用户要求的范围？
