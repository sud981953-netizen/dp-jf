# 选题质量与反馈纠偏

## 五个检查

1. **受众**：谁在什么处境下会遇到这个问题？不能用“所有人都关心”代替具体人群。
2. **主题**：一句话能否讲清内容要回答什么？“科普一下”“分享日常”不能直接作为最终选题。
3. **事实**：学员能举什么真实素材或演示？需要而未知的服务、数据和案例标待确认。
4. **拍摄**：第一镜头、地点、物件是否匹配已知时间与出镜条件？缺素材时给可执行的准备动作。
5. **商业相关**：选题和客户决策、服务或用户指定目标有什么关系？情绪类/泛受众内容可用，但不要把覆盖面推测当获客结果。

## 反馈处理

“太普通”：换受众具体处境、常见误解或对比角度，仍需现有事实支撑；不能凭空制造夸张结论。“只有同行看”：核实学员是否卖给同行，再按目标客户用词重写。“一天只能拍一条”：只给最可执行的一条，不生成大题库。
