# dpjf-topic 资源调用契约

| 任务条件 | 资料 | 使用方式 |
|---|---|---|
| 所有选题开发 | `02_选题要素`、`方法补充/内容目的与选题.md` | 五级星图、六角度、目的、需求和素材；不机械执行“所有题都要数字” |
| 需要差异化 | `07_创意故事要素`、`18_内容创作底层逻辑要素` | 稀缺性、冲突、共鸣和跨界；用于真实差异 |
| 内容阶段或转化目标不明 | `11_内容漏斗与流量分层要素`、`14_变现路径要素` | 内容目的和承接，不先卖货 |
| 需要对标供给 | `dpjf-benchmark` 的真实候选与作品 | 判断已有人怎样讲，不凭记忆估计全平台 |
| 学员不愿露脸 | `05_呈现要素`、`16_打量逻辑与敏感行业策略要素` | 可拍形式和约束 |
| 产品展示 | `17_产品可视化要素` | 真实展示和素材需求 |
| 学员资料不足 | `dpjf-student` 证据包 | 客户原话、历史作业和未知项 |

最终每个入选题都要能说明“资料或事实怎样影响了它”，而不是只换一个行业词。
