# dpjf-title 资源调用契约

| 任务条件 | 资料 | 使用方式 |
|---|---|---|
| 所有标题和开头 | `03_开头钩子要素`、`方法补充/素材标题与平台.md` | 素材、标题与开头分工、兑现检查；固定数字只作历史经验 |
| 主线不清或 A/B 判断 | `方法补充/内容目的与选题.md` | 目的、A/B 类、隐含优点和观众筛选 |
| 需要履历素材 | `dpjf-student` 证据包及用户真实履历 | 数据、权威、案例和待核事实 |
| 需要结构或语料参照 | `26_爆款文案密码与语料要素` 及真实检索脚本 | 只借结构和节奏，标注锚点，不照抄 |
| 平台适配 | `18_内容创作底层逻辑要素` 的平台章节 | 候选口径；现行限制以实际平台为准 |
| 已拍不可补 | 用户原话、字幕或可访问视频 | 原话定位、接回和声画边界 |
| 活人感检查 | `25_活人感输出规范要素` | 口播自然、材料真实、禁套话 |

没有素材时停止“批量写爆款标题”的动作，先说明缺素材、缺正文还是缺包装。
