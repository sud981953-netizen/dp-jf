# dpjf-plan 资源调用契约

| 任务条件 | 必读资料 | 提取和应用 |
|---|---|---|
| 所有完整规划 | `00_自媒体认知要素`、`01_账号定位要素` | 业务与内容前提、价值／人设／用户定位；用于定位，不照搬口号 |
| 新学员或换行业 | `13_行业分类与赛道策略要素` | 行业类型及差异；用于提出候选，不机械归类 |
| 选择 IP／打量或敏感行业路线 | `16_打量逻辑与敏感行业策略要素` | 表现路线、资质和边界；先核实现行合规 |
| 规划内容组合 | `11_内容漏斗与流量分层要素`、`方法补充/内容目的与选题.md` | 内容任务、受众层和转化时机 |
| 设计变现承接 | `14_变现路径要素`、`方法补充/概念学习与研究.md` | 业务机制、递进和交付；不做词义空推 |
| 实体店学员 | `15_实体店专项策略要素` | 同城场景、体验和到店承接 |
| 主页与简介 | `08_简介要素`、`22_主页搭建要素` | 简介、四件套和一致性 |
| 完整方案输出 | `templates/账号策划方案.md`、`账号策划母版.md`、`基础信息采集表.md` | 只取当前需要字段；缺事实写待确认 |
| 学员具体资料不足 | `dpjf-student` 证据包 | 老师陈述、钉钉、档案和未知项 |

交付前说明哪些资料实际改变了定位、路线或承接；不能只把文件名列在“策划依据”里。
