# 规划质量与反馈纠偏

## 逐项检查

1. **目标连贯**：内容支柱中的每条是否能说清对应哪类买家、解决什么问题，以及与咨询/到店/销售等真实承接的关系？不能只列“人设、专业、日常”。
2. **真实可证**：资历、过往客户、产品功效、价格均能在用户材料中找到，还是明确写待核？不能把“同行通常会”写成这个学员已有。
3. **资源闭环**：每周可用时间是否覆盖选题、准备、拍摄、剪辑？给分配时总和不能超过用户上限；只有一个人也不能默认有摄影师。
4. **形式匹配**：不出镜和不口播是不同约束；明确展示不露脸如何讲清关键内容。不要把不出镜的课题改成劝其露脸。
5. **调整依据**：指出下一次要观察的问题或可核对行动，不能只说“先发看看”。没有数据时不报结果预期。

## 老师反馈后的处理

- “太泛”：把每个内容支柱缩到具体受众、具体问题、真实可拍画面，删掉空口号。
- “这不是我的客户”：保留已确认产品事实，重做目标人群，不继续沿用上一轮画像。
- “学员不愿拍”：先确认是时间、出镜还是素材问题，调整具体动作，不归因为态度。
- “直接给完整报告”：信息足够时直接给；缺核心事实的字段写待核，不强行要求逐步说“对”。
