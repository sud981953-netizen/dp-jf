# dpjf-plan：学员账号与获客规划

账号规划的任务是回答：这个学员用什么内容，帮助哪类人解决什么问题，观众为什么相信他，以及怎样进入他已经具备的咨询或成交路径。不是把模板填满。

## 一、四种入口

| 入口 | 判断 | 交付范围 |
|---|---|---|
| A 新学员完整规划 | 业务和目标明确，需要账号路线 | 完整规划 |
| B 资料不足的定位草图 | 只有行业或零散信息 | 条件性方向和关键问题 |
| C 老账号诊断 | 有主页、作品、数据或老师转述 | 保留、调整、验证 |
| D 单项任务 | 只问定位、简介、主页、变现或是否换方向 | 只回答该项 |

单条选题、标题、写稿、投流和每日作业不在这里处理。需要具体学员资料时，先通过 `dpjf-student` 取得证据包，不能猜学员情况。

## 二、先做业务事实账

按以下来源整理：

- 老师当次提供；
- 钉钉学员原话和补充；
- 当前档案、账号和作品；
- 可核实的公开资料；
- 模型假设与未知。

必须区分：

| 事实组 | 关键问题 |
|---|---|
| 产品与交付 | 学员实际卖什么、怎样交付、哪些地方有真实证据 |
| 客户与交易 | 谁在什么处境下付钱、为什么现在买、在哪里成交 |
| 学员资源 | 时间、人手、场地、素材、能力、资质、出镜意愿 |
| 当前目标 | 获客、咨询、到店、成交、关注或建立信任 |
| 当前约束 | 平台、行业、预算、隐私、合规和可持续投入 |

不知道价格、客户、服务区域或资源时，不能填“适中”“都可以”。信息会改变路线时向教务老师确认。

## 三、从顾客任务倒推定位

不要先问“这个人设是什么”，先问：

1. 顾客正在完成什么现实任务；
2. 他在当前方案里遇到什么障碍；
3. 他担心付出什么代价；
4. 学员用什么真实能力、产品或过程降低这个代价；
5. 观众看完内容后为什么愿意进入下一步。

每个主要客户群写成：

```text
谁｜在什么情境｜想完成什么｜担心什么｜学员能提供什么证据
```

多个客户群都重要时，根据本轮业务目标确定首要群，说明其他群何时处理。不要按年龄、性别或行业标签猜动机。

## 四、检查业务与内容承接

用一条链检查：

```text
目标客户的问题
→ 内容提供的判断或体验
→ 学员展示的真实能力
→ 主页和置顶兑现
→ 已确认的咨询／到店／成交方式
```

发现以下断点要直接指出：

- 内容吸引的人与产品买家不一致；
- 学员讲专业，但客户只关心结果、成本或风险；
- 只模仿 A 的内容，却硬接 B 的产品；
- 有流量动作，没有可理解的产品介绍和承接；
- 产品、价格和交付只是假设，却写成完整商业方案。

## 五、确定表现路线

根据学员真实条件选择，不强迫露脸：

- 真人讲解：适合能自然表达、需要信任和专业解释的人；
- 工作过程：适合有真实门店、服务、制作或交付场景的人；
- 产品与细节：适合产品可视化、使用前后和选择决策明确的人；
- 手部、旁白、字幕：适合不愿露脸但有可拍物件和过程的人；
- 故事与人物：适合有真实经历、客户授权和持续素材的人。

“不愿露脸”是约束，不是能力评价。“愿意露脸”也不等于必须口播，场景演示可能更合适。敏感行业先查合规和资质，不照搬历史流量载体说法。

## 六、形成内容支柱

每个内容支柱必须包含：

1. 面向哪类客户处境；
2. 提供什么观看回报；
3. 用学员哪些真实材料；
4. 通向哪项业务或信任目标；
5. 一条现在能拍的示例。

常见支柱可以是客户决策、服务过程、专业判断、真实经历和产品展示。数量通常 2～4 个，不为了显得完整而凑齐干货、记录、情绪、故事、产品五类。

同时检查内容组合：每条内容不必同时涨粉和成交，但要写清它承担的主要任务。

## 七、主页与转化承接

只有涉及主页时读取 `08_简介要素` 和 `22_主页搭建要素`，检查：

- 昵称能否识别人和价值；
- 头像与背景是否服务真实定位；
- 简介说明服务谁、提供什么、为什么可信；
- 置顶内容是否兑现简介；
- 观众能否找到已确认的下一步。

没有实际主页材料时只能给方案，不能说“你现在的主页很乱”。没有确认的联系方式或交易入口时写待确认，不擅自设计违规导流。

## 八、首次验证

规划必须落到最低成本验证：

- 第一条拍什么；
- 用哪些真实素材；
- 谁来做、花多久；
- 完成什么算完成；
- 下次观察目标客户是否理解、是否出现有效咨询或有效反馈；
- 什么证据会支持继续、调整内容或重新判断方向。

不用播放量单独证明定位正确，也不把一次低反馈当成定位失败。

## 九、输出契约

### 完整规划

```markdown
## 核心定位
{用内容帮助谁解决什么问题，通向什么业务}

## 依据与未知
{关键事实、假设和需要确认的一项}

## 首要客户
{处境、任务、顾虑和真实证据}

## 表现路线
{形式、为什么适合、学员条件}

## 内容支柱
1. {方向：受众／回报／素材／示例}

## 主页与承接
{当前确认可用的路径}

## 第一条验证
{动作、时间、完成标准、观察信号}
```

资料不足时缩成“暂定定位＋理由＋一个关键问题＋首条低成本验证”，不输出完整长表。单项任务只交该项。

## 十、质量自检

- 定位是否从真实客户任务和业务证据推出？
- 是否说清观众为什么继续看、为什么相信、怎样承接？
- 每个内容方向是否有真实素材和可拍示例？
- 是否避免编造履历、客户、价格和资质？
- 是否尊重学员时间、能力、出镜和业务选择？
- 是否给出第一条验证，而不是只有长期口号？
