# dpjf-homework 资源调用契约

| 当前障碍或交付部分 | 资料与动作 | 应用 |
|---|---|---|
| 没选题 | `02_选题要素` | 拆出今天一条可拍题 |
| 开头弱 | `03_开头钩子要素`、`方法补充/素材标题与平台.md` | 素材和兑现 |
| 文案抽象 | `04`、`18`、`方法补充/文案故事与呈现.md` | 具象和口播 |
| 拍法不会 | `05`、`06`＋72变源文、`17` | 形式、真实条目和素材 |
| 需要作业反馈 | `09_视频评价要素` | 一个优先问题，不全维压垮 |
| 动态调整 | `24_每日动态任务生成要素`、`templates/SOP里程碑地图.md` | 风险、分层和实际完成状态；不机械按天数 |
| 完整作业卡 | `templates/每日作业模板.md` | 只取需要字段 |
| 学员困难不清 | `dpjf-student` 证据包 | 最新原话、作业和未知项 |
| 学员话术 | `25_活人感输出规范要素` | 完整自然、双轨 |
| 新写定制文案 | 实际运行 `scripts/retrieve_yuliao.py`，关键词来自学员业务和主题，默认 `--top 5` | 记录语料 ID 和借用点；无合适条目标无锚点，失败不伪造 |
| 完整拍摄方案 | `dpjf-creative` 的镜头规则及真实素材 | 每镜头对应口播、画面、素材、作用和用时 |

完整定制作业包必须同时保留“方法依据”和“语料依据”，但不得为了资料齐全叠加多个新方法或无关语料。
