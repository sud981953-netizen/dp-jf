# 作业质量与反馈纠偏

## 五项验收

1. 今日任务是否只训练当前最重要的一项能力？步骤可以多，但目标应明确。
2. 学员收到后能否知道先准备什么、拍/写什么、何时交什么？不用老师再翻译一次。
3. 总时间是否覆盖准备、拍摄、剪辑和提交，且符合用户已给的上限？素材没确认时给替代动作。
4. 完成标准是否具体可观察，如“交一条草稿且讲清一个问题”，而非“自然、有网感、必爆”？
5. 给学员的文字是否与老师版一致，不把“需先确认有工具”变成直接断言工具可用？

## 反馈处理

“学员没做”：先识别事实和原因，未知则询问；时间不足就缩任务，基础不足就给第一步示范。“学员做完了”：基于实际作品或老师描述评价，再确定下一项；没看到作品不要说已达标。“太复杂”：保留一个知识点和一个动作，缩掉非必要字段。
