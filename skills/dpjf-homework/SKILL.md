# dpjf-homework：每日完整定制作业包

每日作业默认不是一张任务清单，而是一套老师和学员可以直接执行的成品：为什么今天练这个、文案怎么说、为什么这样写、镜头怎么拍、多久完成、做到什么算完成。

## 一、三种交付模式

| 模式 | 触发 | 交付 |
|---|---|---|
| A 完整定制作业包 | 老师要求今天作业、每日任务、定制文案和拍法 | 默认完整交付 |
| B 原任务调整 | 未完成、抵触、时间或素材变化 | 先修正原任务，再给可执行成品 |
| C 单项教学活动 | 只要知识点、提纲、拍法、话术，或明确不要完整包 | 只交指定部分 |

用户已有完整选题、文案或拍法时复用，不重复规划。只要单项时不借“完整包”扩权。

## 二、先取得学员事实

复用：

- 学员目标、阶段、产品和目标客户；
- 昨天作业、实际完成情况和最近评价；
- 钉钉补充的学员原话、真实困难和后续反馈；
- 已有选题、规划、文案和拍法；
- 真实经历、案例、物件、场景、设备和出镜意愿；
- 可用时间及保存要求。

区分“没有完成”“没有看到记录”“老师转述”和“学员明确说出的原因”。缺少会改变文案和拍法的信息，先问教务老师，不能凭行业印象补。

## 三、只选一个当前障碍

常见障碍：没选题、缺素材、内容抽象、拍法超出条件、主要问题未改、原任务过大或需要验证方向。

选择能让学员今天完成且对目标最有帮助的一项。一次只引入一个主要新能力，其他步骤复用已有能力。

原任务未完成时：

- 仍适合：优先缩短、拆小、减少镜头或改成提交草稿；
- 部分适合：保留核心练习，替换缺素材部分；
- 已不适合：说明新事实再换；
- 原因未知：先给最小行动并核实，不随意换方向。

## 四、建立方法与语料依据

### 方法资料

按当前障碍读取 `references/资源调用.md` 指定资料。提取的规则必须进入具体句子或镜头，不能只列文件名。

### 爆款语料

完整定制作业包需要新写文案时，必须先形成 2～4 个来自学员业务和主题的关键词，再实际运行包根检索脚本：

```bash
python "<包根>/scripts/retrieve_yuliao.py" "<关键词1>" "<关键词2>" --top 5
```

需要平台或分类时再添加 `--platform`、`--sheet`。检查返回记录的主题、开头、结构和表达，不只看热度。

每次交付记录以下三种状态之一：

- **有锚点**：语料 ID、借用的是开头／结构／节奏／情绪推进／表达；
- **无合适锚点**：已实际检索但没有相关条目，本次按学员事实原创，不硬凑；
- **检索失败**：说明失败原因，不能编造语料 ID 或声称已参考。

语料只借结构、节奏和表达机制，不搬题材、身份、数字和原句。学员事实优先于语料。

## 五、写定制文案

文案必须包含：

1. 面向哪类目标客户；
2. 一个核心主张；
3. 学员真实事实和素材；
4. 可自然念出的完整口播；
5. 与拍法一致的镜头顺序；
6. 真实的语料或无锚点说明。

默认给完整成品，不只给“开头怎么写、正文怎么写”的提纲。事实不足时可以先交结构并只问一项，但不能编造具体经历、客户、数字或效果。

## 六、给学员讲清为什么这样写

老师版解释要能看出设计逻辑，学员版用大白话讲清：

- 开头为什么这样筛选目标客户；
- 哪句话用了学员自己的真实材料；
- 哪一处用了哪条方法；
- 哪一处借鉴了哪个语料 ID 的什么结构；
- 哪些内容不能照抄、不能编；
- 学员照着念和拍时要保留什么。

不是逐字讲理论，也不把“方法论、链路、锚点”等内部术语塞给学员。给学员的解释可以只说“这句话先让附近上班的人知道，这条视频是讲给他们听的”。

## 七、逐镜头拍摄方案

每个镜头必须包含：

```text
画面｜对应口播／字幕｜所需真实素材｜作用｜预计用时
```

同时写：

- 准备什么；
- 先拍什么、后拍什么；
- 哪些可以删减；
- 不露脸时怎样实现；
- 完成标准。

拍法必须兑现文案，不能文案讲一套、画面另外一套。72变只有实际核对源文后才能写编号；没有合适变法就称普通过程展示。

## 八、控制负担

估算“准备素材＋理解知识点＋拍摄／书写＋检查提交”。超过学员硬时间时，依次减少地点、人物、镜头、口播和后期，不牺牲核心练习。

20 分钟任务不能同时要求找大量素材、学多个新方法、拍多机和复杂剪辑。没有素材时先安排最小采集，不编经历。

## 九、默认完整交付格式

```markdown
## 今天只解决
{一个障碍及为什么是它}

## 定制文案
{完整口播稿}

## 为什么这样写
- 开头：{目标客户和作用}
- 真实材料：{学员事实}
- 方法依据：{实际读取及使用点}
- 语料依据：{ID及借用点／无合适锚点／检索失败}

## 拍摄方案
| 镜头 | 画面 | 口播／字幕 | 素材与作用 | 用时 |
|---|---|---|---|---|

## 完成标准
{可检查的提交结果}

## 发给学员的话
「{自然完整、可复制的话术}」
```

## 十、保存与反馈

用户要求保存时，通过 `dpjf-student` 写入该学员 `03_作业与排期/`；未要求时不写。反馈回来后比较原任务、实际完成和障碍，能继续原任务就不换题，下一轮仍交付完整成品。

## 十一、验收清单

- 是否只有当天最值得解决的一个障碍？
- 文案是否完整、具体、自然且使用学员真实事实？
- 是否实际读取方法资料并应用？
- 是否实际检索语料并记录 ID 或无匹配状态？
- 是否讲清开头、真实材料、方法和语料依据？
- 是否逐镜头对应口播、素材、作用和用时？
- 是否能在学员现有条件下完成？
- 是否只保存到对应学员目录，且未擅自发送？
