# 对标研究：详细判断方法

## 1. 先定对什么

区分客户群体、产品服务、内容主题、账号阶段、出镜形式和地区。一个候选可以只对标选题结构或画面形式，不必假装覆盖整个生意。先问“这次要学什么”，用户已说清则直接执行。

## 2. 获取与核验

用户已有账号名或链接时，实际读取可访问材料；需要新找账号时使用有权限的公开检索，记录访问日期、名称、作品链接和看到了什么。无法访问或候选资料不够时明确说明；不得把搜索片段写成亲自看过整条视频。粉丝、互动及播放口径分开；利润与成交无法从粉丝推知。

## 3. 五项筛选

- 受众：能看出服务谁吗，和学员目标客户的交集是什么？
- 内容：哪些选题和论述能从实际作品中指出？
- 形式：镜头、口播、剪辑及成本能否从材料核对？
- 转化：公开可见的联系方式、商品或预约如何承接；看不到的私域流程写未知。
- 可执行：学员有无设备、时间、场景和意愿；不露脸、不能补拍、资质及资金约束都要算进去。

按证据强弱给推荐、备选或待核实。不因为数据好就保证可复制，不以猜测收入淘汰别人；用户要一个候选就不凑三条。

## 4. 拆一条作品

记录标题、开头原句或可见画面、结构转折、证据材料、结尾承接，说明每块对观众的作用；缺时间码就引用原句或段落。转换给学员时只迁移可描述的结构与做法，另写真实素材需求，不复制整篇、身份或作品画面。
