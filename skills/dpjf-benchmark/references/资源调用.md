# dpjf-benchmark 资源调用契约

| 条件 | 资料 | 应用 |
|---|---|---|
| 所有对标 | `10_教练沟通要素` 的对标章节、`方法补充/对标与文风.md` | 筛选、匹配、动作与认知模仿 |
| 内容产品链 | `14_变现路径要素`、`01_账号定位要素` | 受众、变现和承接匹配 |
| 拆作品 | `03`、`04`、`05`、`18` 对应章节 | 标题、结构、呈现和情绪，按实际材料使用 |
| 学员条件判断 | `dpjf-student` 证据包 | 资源、资质、时间和意愿 |
| 关键词与选题库 | `02_选题要素`、`方法补充/内容目的与选题.md` | 高频词、需求和供给 |
| 风格提取 | `方法补充/对标与文风.md` | 分簇、7＋1、触发条件和反抄袭 |
| 需要新候选 | 真实公开检索返回 | 链接、日期、实际观察；无工具只给找法 |

每个推荐必须说明证据和不可模仿项；不能把“知名”当推荐依据。
