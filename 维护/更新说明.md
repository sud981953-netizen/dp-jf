# dpjf 更新说明

当前主路由 `/dpjf`，更新能力为 `/dpjf-update`，分别位于 `skills/dpjf/` 和 `skills/dpjf-update/`。

只查本地版本时读取包根 `version.json`，不联网、不改文件。当前正式发布来源为 `https://github.com/sud981953-netizen/dp-jf`，发布文件清单为 `维护/文件清单.json`。历史目录中的旧清单只用于追溯。

## 更新流程

1. 核对本机路径、可信来源和已修改文件，在独立位置准备候选并创建可恢复备份。
2. 下载并逐项校验主路由、15个子技能、共享资料、脚本和实际安装入口。
3. 保留当前最新版中的用户改动、学员资料、用户配置、原始素材和未知文件；不得通过硬重置或清理未知文件覆盖用户改动。
4. **只有最新版安装和验证全部成功后，才清理旧版。** 更新失败时保留旧版及回退备份，不执行清理。
5. 清理范围仅限 `dp-jf`、`dpjf-*`、`dojf*` 及对应旧版备份目录。不得删除其他技能、学员资料父目录、未知文件或当前最新版。
6. 先运行预览，确认待删除目录，再执行实际清理：

```bash
python scripts/cleanup_old_versions.py --current-root "<最新版技能包目录>"
python scripts/cleanup_old_versions.py --current-root "<最新版技能包目录>" --apply
```

`--apply` 会删除预览中列出的旧安装和旧备份。符号链接或 Junction 只删除链接本身，不删除链接指向的源码；真实旧目录才被删除。当前最新版路径及其父级、子级不会被清理。

本机候选可执行 `python scripts/生成文件清单.py --local` 生成 `维护/文件清单_本地候选.json`。该清单只描述本地受管理的技能文件，不代表公开发布或远端可下载。正式来源为 released 时可生成 `维护/文件清单.json` 并核对内容指纹。

## 学员资料位置

技能包不内置 `学员/` 文件夹。首次处理学员资料时，必须由用户提供专门的学员资料父目录，再由 `dpjf-student` 建立学员索引和各学员子文件夹。用户原有学员资料不得随更新删除。

应用更新后核验主路由、15个子技能、共享资料及宿主入口；部分失败须如实说明并使用可核验备份恢复。
