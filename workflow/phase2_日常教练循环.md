# Phase 2：日常教练循环（核心）

> 本文件是工作流细则。进入本 Phase 前必须已过 Phase 0 四道门槛。每天教练老师跟学员对接时，走以下4步循环。所有相对路径基于技能根目录。

---

## Step 1：教今日知识点

从知识点库中选一个，按学员当前周数匹配进度：

| 周次 | 主题 | 每日知识点（按天递进） |
|------|------|---------------------|
| 第1周 | 账号基建 | 第1天账号定位 / 第2天人设标签 / 第3天五级星图选题 / 第4天选题四条件 / 第5天标题三公式 / 第6天开头四维评分 / 第7天文案五模块 |
| 第2周 | 起号实操 | 第8天口播三类型 / 第9天 72变匹配 / 第10天对标拆解 / 第11天拍摄技巧 / 第12天 VLOG创作 / 第13天图文制作 / 第14天三号矩阵发布 |
| 第3周 | 增长优化 | 第15天包装视频 / 第16天找热点 / 第17天数据认知（看视频判断而非看后台） / 第18天爆款复盘 / 第19天素材库深化 / 第20天对标进阶 / 第21天内容迭代 |
| 第4周 | 变现转化 | 第22天转化型内容 / 第23天线索转化型视频 / 第24天开通橱窗团购 / 第25天直播间搭建 / 第26天直播话术 / 第27天直播复盘 / 第28天下月规划 |

每天的知识点不是讲理论，是讲完就能用的操作方法。参考知识卡片目录和实操执行手册。
周次知识点表是执行主线。实操执行手册、知识卡片、陪跑SOP 的每日主题与周次表不完全对应时，以周次表为准，把对应主题嵌入当周作业即可。
学员创作没思路、内容同质化时，调用 要素定义库/07_创意故事要素.md（稀缺性6法/冲突设计/故事六板块），帮学员找到差异化拍法。

## Step 2：布置今日作业

**按 templates/每日作业模板.md 的结构逐字段生成，不得增删字段、不得改小节顺序。** 字段速览（完整版以模板为准）：

```
作业卡（模板完整结构，缺一项就回去补）：
- 基本信息：学员 / 日期 / 第__周 第__天
- 今日知识点：名称 + 一句话核心
- 今日作业（五个必填板块）：
  - 选题：选题 + 四条件自检（四个checkbox，与人设强相关/目标用户关心/有真实经历或独特见解/有具体数字或反常识结论）
  - 72变变法：变法 + 变法框架 + 模板（按行业替换）+ 范例（行业A/行业B两个，严禁照搬）
  - 文案要点：五模块结构 / 论证层4以上 / 开头第一句<=20字 / 结尾金句或行动引导
  - 呈现形式：口播/VLOG/图文/混剪 + 时长 + 场景
  - 拍摄要求：BGM / 字幕 / 话题标签 / 发布时间 / 发布平台
- 完成标准（5条）：选题过四条件 / 开头第一句<=20字 / 文案五模块完整 / 按变法框架拍 / 发布后截图发教练
```

| 步骤 | 读哪个文件 | 只取什么 | 填进作业卡哪个字段 |
|---|---|---|---|
| 0 | templates/每日作业模板.md | 完整字段结构 | 整张卡的骨架（不得增删字段） |
| 1 | 要素定义库/02_选题要素.md | 五级星图取选题 + 四条件自检标准 | 「选题」板块 |
| 2 | 要素定义库/06_72变要素.md | 按学员标签匹配变法 + 框架 + 模板 | 「72变变法」板块 |
| 3 | 要素定义库/03_开头钩子要素.md | 开头四维评分 + 6种开头模板 | 「文案要点」的开头要求 |
| 4 | 要素定义库/04_文案要素.md | 五模块结构 + 论证五层 | 「文案要点」的结构与论证目标 |
| 5 | 要素定义库/26_爆款文案密码与语料要素.md | 五层密码要点 | 「文案要点」的密码框架 |
| 6 | `python scripts/retrieve_yuliao.py "{主题词}" --sheet {分类} --top 5 --json` | 同分类同主题爆款**全文**3-5条 | 「文案要点」的仿写锚点（见下方语料锚定规则） |
| 7 | 要素定义库/05_呈现要素.md | 形式选择（口播/VLOG/图文/混剪） | 「呈现形式」板块 |
| 8 | 要素定义库/27_学员心理画像与留存沟通要素.md 第五节 | 人味话术模板 + 八型画像调整 | 发给学员的话术（另走学员轨） |

**流水线执行要求：**
- 每步「读完即填」：从对应文件里只取上表列明的那一块，填进对应字段，不把整份文件内容抄进作业卡
- 学员已有档案的，开工前先读学员档案（人群/行业/进度/出镜意愿/拖延倾向），按档案筛选题和变法，不按通用默认值填
- 卡片写完 -> 过下面的「作业自检」-> 落盘到学员文件夹 -> 跑 `python scripts/check_prose.py --contract 作业卡 文件.md` 清零 -> 再发给老师
- 学员拖延/抵触时，话术按27号八型画像调整，不换作业本身

### 语料锚定规则（第6步展开；写任何学员轨文案/开头/金句前必过）

**为什么硬性要求：** AI味重的根源是模型只拿规则写文案，没拿真爆款当参照。锚定制度强制每次写文案前先调出真爆款全文，照着真爆款的句式和节奏写。

**执行动作：**
```
1. 确定分类映射：
   泛流量共鸣内容 -> --sheet 情感
   搞钱干货/干货清单 -> --sheet 搞钱
   AI工具/自媒体运营 -> --sheet AI
   人设故事/来时路 -> --sheet 人设
   转化收口内容 -> --sheet 营销
2. 跑检索（主题词用学员行业的词，不用抽象词）：
   python scripts/retrieve_yuliao.py "{主题词}" --sheet {分类} --top 5 --json
3. 从返回结果里挑 3-5 条：
   优先 选题/标题 直接命中的；同主题多平台重复的只取一条；长度和目标作业接近的优先
4. 拆锚点：每条拆出 开头句式 / 推进结构 / 口语特征（语气词/称呼/短句节奏）
5. 照锚点写学员行业的文案（见下方红线）
6. 作业卡「文案要点」板块末尾必须标注：
   仿写锚点：语料#220（借开头「一旦开窍，钱会追着你跑」的断言语气）+ 语料#246（借「十个微习惯」清单推进）
```

**降级路径：** 主题词检索无命中 -> 去掉 --sheet 全库检索 -> 仍无命中 -> `--sheet {分类} --top 3 --random` 随机取同分类高分条目，只借句式不借题材。语料库文件缺失 -> 按 SKILL.md 启动自检报失败，不许跳过锚定直接写。

**仿写红线（非谈判项）：**
- 借网感、句式、推进结构、口语特征；**不借题材**——语料偏情感/搞钱/AI，学员是美业/餐饮/财税的，题材必须回到学员自己的行业和人群
- **禁止照抄原文发给学员**，必须是换过行业换过细节的仿写
- 没有锚点ID的文案不许出——就像没有文件依据的方法论答案不许出一样
- 语料里的错别字和口语瑕疵不仿（如「底曾」「转会李梦」），锚的是节奏不是错字

### 完整样例（照这个形状产出，字段密度以此为准；发给学员的话术部分另按25号/27号写人味，不照抄本样例的书面语气）

```
# 每日作业卡 - 20260920 张三

## 基本信息
- 学员：张三
- 日期：20260920
- 第2周 第10天

## 今日知识点
对标拆解：把对标账号的爆款文案拆开看结构，框架留下、内容换成自己的

## 今日作业

### 选题
- 选题：为什么你家的美容院年卡卖不动，隔壁却排队的三个原因
- 四条件自检：
  - [x] 和人设强相关（美容院老板日常经营）
  - [x] 目标用户关心（想做年卡的客户和同行老板都关心）
  - [x] 有真实经历或独特见解（张三家年卡从滞销到排队的真实经历）
  - [x] 有具体数字或反常识结论（三个原因+排队反差）

### 72变变法
- 变法：第6变 吐槽起号法【吐槽行业奇葩现象引发共鸣】
- 变法框架：找行业普遍现象 → 站在用户视角吐槽 → 有理有据 → 结尾引导互动
- 模板（按行业替换）：「做[行业]的都知道，[普遍奇葩现象]。客户觉得[用户视角的吐槽]，其实[真实原因]。」
- 范例（严禁照搬）：
  - 行业A（餐饮）：点一份黄焖鸡米饭，里面鸡肉只有3块
  - 行业B（职场）：迟到一分钟扣50块，加班两小时没加班费

### 文案要点
- 结构：五模块（开头/定义/拆解/案例/收束）
- 论证目标：层4以上（有案例支撑的因果论证）
- 开头要求：第一句<=20字
- 结尾要求：金句或行动引导

### 呈现形式
- 形式：口播
- 时长：45-60秒
- 场景：店里，靠窗自然光

### 拍摄要求
- BGM：轻快不带人声
- 字幕：全程字幕，行业词核对后再发
- 话题标签：#美容院经营 #实体店获客
- 发布时间：今天18:00-20:00
- 发布平台：抖音

## 完成标准
1. 选题过四条件
2. 开头第一句<=20字
3. 文案五模块完整
4. 按变法框架拍
5. 发布后截图发教练
```

### 作业自检（if/else）

```
IF 选题四条件任一不满足 -> 丢弃，换选题
IF 开头四维<3项8分 OR 第一句>20字 -> 重做开头
IF 文案论证<层4 -> 重写补论证
IF 学员不出镜 AND 选题需出镜 -> 换形式或换选题
IF 作业类型是产品展示 -> 必须加入产品可视化元素（调用 要素定义库/17_产品可视化要素.md），不是介绍产品，是展示效果
IF 流量型选题未命中四大跑量基因（反差/利益/悬念/情绪）-> 不做流量型
```

### 流量放大路由（if/else，调用 要素定义库/23_借东风与投流放大要素.md）

```
IF 学员冷启动停滞/发了几条没流量/问"怎么让更多人看到我":
    -> 借东风（零成本）：布置五步法作业，话术从23号第二章复制
IF 学员有视频自然播放破过万 AND 想放大/想投钱:
    -> 微付费投流：先过投流前置判定（23号3.2），按微付费打标签法给投放步骤
IF 学员内容还没跑通就想投钱:
    -> 拦住：投流救不了烂内容，先磨内容跑通自然流量
IF 学员是实体店 AND 想投流:
    -> 优先本地推3-5公里，别用DOU+拿全国流量（联动15号）
```

## Step 3：学员提交视频

学员拍完视频发给教练老师。教练老师把视频情况给skill。

## Step 4：视频评价（核心）

调用 要素定义库/09_视频评价要素.md，按以下维度逐项评价：

1. 场景：拍摄环境/光线/背景/道具是否匹配内容
2. 表现力：眼神/表情/语速/状态/肢体语言/口齿
3. 画面包装：剪辑/字幕/BGM/封面/节奏/画质
4. 内容质量：选题/开头/文案结构/论证层级/结尾/语言风格
5. 变法执行：是否按72变框架拍，核心结构是否保留
6. 改进建议：具体到下一步怎么改

评价时同样遵循沟通法则（调用 要素定义库/10_教练沟通要素.md）：先问学员自己觉得拍得怎么样，再给评价。评价不要一次性甩出全部问题，先说最严重的1-2个，等学员认可后再说其他的。

评价输出（写入 /{学员}/04_视频评价/视频评价_{日期}.md）：

**按 templates/视频评价表.md 的结构逐字段生成，不得增删字段、不得改小节顺序。** 发出前对照模板逐字段打勾：基本信息五项（学员/日期/选题/变法/呈现形式）、多维评价五行（场景/表现力/画面包装/内容质量/变法执行，判断只填 好/注意/差）、核心问题（最严重的1-2个）、改进建议（3条，具体到可执行）、下一条视频怎么做（一句话方向）。每个维度的「判断」怎么填，以模板「评价维度说明」一节的标准为准。

字段速览（完整版以模板为准）：

```
## 视频评价 - {日期}
### 基本信息（学员/日期/选题/变法/呈现形式）
### 多维评价（五行表：场景/表现力/画面包装/内容质量/变法执行 × 好/注意/差）
### 核心问题（最严重的1-2个）
### 改进建议（3条）
### 下一条视频怎么做（一句话方向）
```

### 完整样例（照这个形状产出，字段密度以此为准）

- 变法：第6变 吐槽起号法
- 呈现形式：口播

| 维度 | 判断 | 具体问题 |
|------|------|---------|
