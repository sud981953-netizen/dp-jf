# Phase 00：每日晨间巡检（上班第一件事）

> 本文件是工作流细则。总路由见 SKILL.md，进入本 Phase 后按本文执行，不需要回读 SKILL.md 的工作流部分。所有相对路径基于技能根目录。

每天早上第一件事：把学员交付文件夹地址发给AI，告诉它"所有学员的情况，我今天需要做什么？"
AI自动扫描所有学员文件夹，按优先级排序，告诉你今天该做什么、怎么跟学员说。

**触发条件（调用 要素定义库/19_每日巡检要素.md 触发条件定义）：**
- 老师发送的内容以盘符或绝对路径开头（如 E:\学员交付）
- 老师明确说"所有学员的情况""我今天需要做什么"
- 老师输入包含"今天"+"需要/要做/安排/工作"等关键词组合
- 老师说"巡检"/"晨检"/"上班第一件事"/"先看看"

---

## Step 0：确认存件目录 + 日期判断（状态只认 config/设置.md，不认对话记忆）

```
IF 老师提供了新的文件夹地址:
  -> 校验地址存在且可写（不存在就先创建）
  -> 写入 config/设置.md 的「存件地址」
  -> "好的，已记录地址。今天是{当前日期}，我现在扫描所有学员..."
ELIF config/设置.md 已有存件地址:
  -> 读取 config/设置.md 的「最后巡检日期」
  -> IF 最后巡检日期 == 今天（同一天内再次请求）:
       -> "今天{日期}已经巡检过了（结果见上次），需要重新扫描所有学员吗？"
  -> ELSE（新的一天，日期变了）:
       -> "好的，今天是{日期}，我重新扫描所有学员的最新情况..."
ELSE（config/设置.md 不存在或存件地址为空）:
  -> 按 workflow/phase0_前置门槛与学员管理.md 门槛1 处理（问地址 -> 写入设置文件 -> 再回来执行本Phase）
```

**日期判断说明：** 老师每天在同一条对话里说"今天需要做什么"，AI自动识别今天是哪天。
- 同一天内再次请求 -> 直接复用上次结果，不用重新扫描
- 新的一天（日期变了）-> 自动重新扫描，输出新的今日工作台
- 不用老师手动告诉AI今天是哪天，AI自动判断
- 巡检完成后必须把今天日期写入 config/设置.md 的「最后巡检日期」字段——这是判断"今天巡检过没有"的唯一依据
- 地址只需提供一次，之后每天老师只需要说"今天需要做什么"即可

## Step 1：扫描所有学员文件夹（调用 要素定义库/19_每日巡检要素.md 学员状态扫描清单）

```
1. 列出 {存件地址}/ 下所有子文件夹
2. 排除非学员文件夹（templates、要素定义库、.codex、.git 等）
3. 对每个学员文件夹执行诊断：
   - 读取 学员档案.md（阶段/行业/进度/待办）
   - 检查 03_作业与排期/ 最新作业状态
   - 检查 04_视频评价/ 是否有待评价视频
   - 检查 00_对话存档/ 最近对话记录
4. 按优先级规则分类：
   🔴 今日必做：有待评价视频/有未回复消息/冷启动停滞/情绪问题
   🟡 今日跟进：今日作业未布置/需要提醒交作业/等确认
   🟢 观察：一切正常
```

## Step 2：生成今日动态任务（调用 要素定义库/24_每日动态任务生成要素.md）

先接收老师随手同步（语音转文字/随手打字，无格式要求——模板化会损害学员体验），按 24 号解析规则提取四类信号（作业/数据/问题/情绪）；老师没同步就纯按档案扫描（退化为 19 号模式，清单顶部标注"昨日无同步，基于档案推断"）。
然后按 24 号三步判断引擎（风险信号一票插队 -> 分层路线 B1/B2/B3 -> 里程碑时钟超前/正常/滞后）逐学员判断，一次性输出全班三段式清单：

```
## 📋 今日任务 - {日期}
学员 N 人 | 🔴 风险处理 X 人 | 🟡 正常推进 Y 人 | 🟢 观察/待确认 Z 人

一、今天要对接谁（按优先级排序）
  🔴 风险处理：原因 + 建议动作 + 可直接复制的话术
  🟡 正常推进：当前里程碑 + 今天布置的任务
  🟢 观察/待确认：档案推断状态 + 建议触达

二、每个人发什么
  作业卡 + 知识卡片（知识卡片库/PNG截图/D{天数}_主题.png，对应关系见里程碑地图）+ 成品话术
  （天数表述红线：D 前缀只是卡片文件名的命名规则，老师找文件用；发给学员的一切文本里天数只写「第x天」，禁止出现 D6/D12 这类编号，学员看不懂）

三、动态调整说明
  谁、原计划、调整原因、新任务（没有就写"今日无计划外调整"）
```

里程碑基准：templates/SOP里程碑地图.md（以完成标准为准，不以入营天数为准）

**知识卡片降级处理：** PNG截图目录不存在或找不到对应卡片时，不要编造文件路径。改用 知识卡片库/HTML知识卡片/ 下的同名 HTML 卡片（老师打开后可直接截图发学员），并告知老师「PNG版未随包安装，可用HTML版代替」。

## Step 3：单学员追问模式（调用 24 号第四节）

```
输出完后，问老师：
"建议先处理🔴再处理🟡。要展开哪个学员的完整话术和作业卡？有特殊情况随时补充，我会重新判断。"
老师追问某个学员 -> 展开完整判断链 + 完整成品（话术/作业卡/知识卡片文件名）
老师补充新情况 -> 立即重判并给出调整后的任务
追问结束后按 20 号规则写回学员档案（今日作业卡入 03_作业与排期/，同步原文入 00_对话存档/）
```

## 注意事项（调用 要素定义库/19_每日巡检要素.md 边界情况处理）

- 学员文件夹为空 -> 待初始化，不归入优先级
- 学员已完成课程 -> 已毕业，不归入优先级
- 学员超过2周未互动 -> 休眠，归入🟢观察
- 同一天内再请求巡检 -> 先输出上次结果，问是否重新扫描
- 地址无效 -> 提示重新提供
