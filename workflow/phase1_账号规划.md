# Phase 1：账号规划（一次性，新学员首次启动时）

> 本文件是工作流细则。进入本 Phase 前必须已过 Phase 0 四道门槛（学员已识别、档案已建立）。所有相对路径基于技能根目录。

收到学员20条基础信息后，先在脑内跑一遍「构思起点」，再分析输出账号规划方案。

---

## 构思起点（AI脑内顺序，跑完这一层再进入下方对学员的交付五步）

总纲：先想生意，再想账号；从"客户掏钱"倒推，不从"发什么视频"正推。

```
第0步：摸底两问（各一句话摸清）
  -> 卖什么、在哪卖：产品/服务 + 成交场景（同城到店/私信咨询/橱窗下单/直播间/私域）
  -> 人手里有什么牌：能不能出镜、有没有网感、有没有时间

第1步：第一分叉口——IP人设化 vs 去人设化（打量）
  -> 四根柱子判定，详细if/else见下方 判定3
  -> 这是总开关：方案形态、作业形式、评价标准、沟通话术，全都跟着分叉走

第2步：按分叉深挖
  -> 打量路：深挖客户群体特征（一层层挖到"他刷到什么会停下来"）
     -> 找流量载体 -> 选模板 -> 元素植入（调用16号）
  -> IP路：深挖人设定位 -> 搭信任漏斗（泛流量共鸣->精准专业->转化收口）
     -> 选题文案的干货细节（调用01号/11号）

第3步：输出获客草图（一句话）
  -> 用【什么内容】在【哪个平台】拦住【哪群人】，用【什么钩子】引到【哪个成交场景】
  -> 草图定了，才进入下方交付五步
```

## 【开策划前必读清单】（硬门槛，没读完不许输出方案）

做账号策划前，必须已读取以下7个文件，一个都不能少：

```
1. 21号_方法论总览（先建全局观：学员的问题归哪个文件管）
2. 00号_自媒体认知要素（思考的底层：流量/算法/内容/变现的本质）
3. 13号_行业分类与赛道策略（把学员归进A-F类，定行业打法）
4. 01号_账号定位要素（价值定位/人设标签/用户漏斗）
5. 06号_72变要素（策划必须结合72变：内容方向 x 变法匹配，不能只给干巴巴的方向）
6. 11号_内容漏斗与流量分层（泛流量共鸣->精准->转化收口的结构）
7. 14号_变现路径（变现方式决定内容钩子和主页设计）
```

输出方案时，开头必须先列「本次策划依据」，格式：

```
本次策划依据：
- 已读取：13号（行业分类：{X类}）/ 01号 / 06号（选用变法：{...}，原因：{...}）/ 11号 / 14号 / 00号（认知锚点：{...}）
- 分叉判定：{IP人设化 / 去人设化打量}（四柱子：{一句话}）
```

没读齐7个文件、没列依据，就不许输出方案。学员信不信你专业，就藏在这份依据里。

## 沟通方式（调用 要素定义库/10_教练沟通要素.md）

Phase 1 的输出不是一次性甩给学员一份报告，而是按以下顺序逐步交付：

```
第1步：确认业务结构
  -> 复述你看到的账号情况，问"对不对？"
  -> 等学员确认后再继续

第2步：拆人群特征
  -> 逐个客户群体拆：画像/痛点/心理特征/内容策略推导
  -> 每拆完一个群体，等学员说"对"再拆下一个

第3步：指出问题，给出方向
  -> "所以现在的思路是错的，错在哪里？一条一条说"
  -> 每个问题都对应前面的人群分析

第4步：给对标、给工具
  -> 推荐对标账号（过对标四原则，说明为什么选）
  -> 对标四原则完整话术，直接复制 要素定义库/10_教练沟通要素.md -> 对标四原则完整话术（可直接复制发给学员）
  -> 给文案提取工具（轻抖/get笔记/AI改写）

第5步：输出完整方案文件
  -> 学员信了之后，再把方案文件产出给学员
```

## 对标四原则（推荐对标时必须过，可拆成四个不同对标）

注意：不一定非要一个账号同时满足四条。可以拆成四个对标账号，每个账号解决一个方向。
具体定义和话术参考，调用 要素定义库/10_教练沟通要素.md -> 对标完整方法论。

## 路由判定（if/else）

### 行业分类路由（调用 要素定义库/13_行业分类与赛道策略要素.md）

- A类同城实体店：有线下门店+服务本地客户 -> 调用 15_实体店专项策略要素.md
- B类职业IP：提供专业服务+靠知识变现
- C类知识付费：卖课程/培训/陪跑+靠知识变现
- D类带货：卖实物商品+靠橱窗/直播变现
- E类泛娱乐：靠内容吸引粉丝+靠广告/打赏变现
- F类B2B：服务企业客户+决策周期长
- 分不清 -> 追问客户画像和变现方式

### 变现路径路由（调用 要素定义库/14_变现路径要素.md）

- A类 -> 到店消费(主)+私域引流(辅)
- B类 -> 私信咨询(主)+私域引流(辅)
- C类 -> 私域引流(主)+直播间(辅)+橱窗卖课(辅)
- D类 -> 橱窗带货(主)+直播间(辅)
- E类 -> 广告合作(主)+直播间打赏(辅)
- F类 -> 私信咨询(主)+私域引流(辅)

### 原路由判定

```
---- 判定1：同城 vs 全国 ----
IF 第6条=有线下店铺 AND 追问=引流到店 -> 分支=同城
ELIF 第6条=有线下店铺 AND 追问=做全国IP -> 分支=全国
ELSE -> 分支=全国

---- 判定2：账号阶段 ----
IF 第8条粉丝<1万 -> 阶段=冷启动（配比7:2:1）
ELIF 1万<=粉丝<5万 -> 阶段=成长（配比5:3:2）
ELSE -> 阶段=成熟（配比3:3:4）

---- 判定3：IP人设化 vs 去人设化（第一分叉口，核心判定）----

四根柱子一起判，优先级：人的硬条件 > 行业敏感度 > 卖人还是卖货 > 信任缺口。冲突时按顺序让路。

柱子1 人的硬条件（一票否决）：
IF 第17条=不出镜 OR 没网感 OR 没时间 OR 明确说不想出镜:
    -> 去人设化（打量逻辑，调用 要素定义库/16_打量逻辑与敏感行业策略要素.md）
    -> 哪怕行业再适合IP也不硬走：硬条件不满足，IP路线走不动

柱子2 行业敏感度：
IF 行业敏感易违规（见16号 敏感行业速查表）:
    -> 去人设化 + 流量载体承接，不管能不能出镜
    -> 人设越重死得越快；元素表现出来，观众自然懂

柱子3 卖人还是卖货：
IF 客户掏钱是冲这个人来的（律师/疗愈/财税/咨询类：不买你这个人就不买你的服务）:
    -> IP人设化
ELIF 客户掏钱是冲货/店来的（槟榔/服装/餐饮/日化类：东西好就行，你是谁不重要）:
    -> 去人设化优先（打量+产品可视化，调用17号），IP作为长期可选项

柱子4 信任缺口：
IF 高客单/决策重/怕被骗（香港公司注册/装修/月子中心类）:
    -> IP人设化养信任，长漏斗
ELIF 低客单/冲动消费/就近消费（槟榔/餐饮/日用类）:
    -> 去人设化，曝光+元素植入就够，不用养长漏斗

中间态：
IF 愿出镜 AND 表现力弱:
    -> 先按IP试（场景化呈现，非对口播）
    -> 表现力跟不上再切打量逻辑
IF 信息不足判断:
    -> 追问：是愿意出镜还是完全不想？有没有空拍内容？客户买的是你这个人还是你的货？

分叉后的路线：
打量路 -> 从目标客户群体出发，选流量载体打流量，去人设化模板批量生产，后续跳过所有IP相关要素判定
IP路 -> 按人设方向出镜，走账号定位+人设包装+内容漏斗等IP要素

[话术参考]：学员实在不能出镜没网感没时间，就别硬走IP路线。换一种打法：从目标客户出发，看他们喜欢看什么，就用什么内容去吸引他们。不需要学员出镜，用AI批量生产就行。

---- 判定4：身份倾向 ----
IF 第5条=生意人 -> 引流现有生意，钩子=到店/咨询
ELIF 第5条=自媒体创业者 -> 内容IP变现，钩子=挂车/私信/直播

---- 判定5：赛道可行性 ----
IF 列不出50+选题 -> 打回：换赛道或细分
ELIF 讲不清底层逻辑 -> 打回：先深挖或换
ELIF 用户听不懂 -> 打回：简化或换
ELSE -> 通过

---- 判定6：人设可行性 ----
IF 一句话说不清"你是谁" -> 打回：用人设标签三思路重做
ELIF 人设是虚假的 -> 打回：铁律不弄虚假
ELSE -> 通过
```

## 规划输出（调用要素定义库）

1. 账号定位（调用 要素定义库/01_账号定位要素.md）
   - 价值定位（实用/情绪配比）
   - 人设标签组合
   - 用户漏斗（重点打哪几层）
   - 内容支柱（3-5个核心方向）

2. 内容策略
   - 内容漏斗分析（调用 要素定义库/11_内容漏斗与流量分层要素.md）：拆目标人群 -> 搭三层流量池（泛流量/精准/转化）-> 排内容节奏 -> 每层列10-20个选题方向
   - 三类内容配比（按同城/全国 x 阶段判定，速查表见 SKILL.md）
   - 72变匹配（调用 要素定义库/06_72变要素.md，按学员标签筛Top-N变法）
   - 漏斗承接节奏（调用 要素定义库/11_内容漏斗与流量分层要素.md：第1-2周泛流量为主 -> 第3周精准内容加重 -> 第4周转化收口）

3. 主页搭建
   - 昵称/头像/背景图/置顶视频规划（调用 要素定义库/22_主页搭建要素.md）
   - 简介（调用 要素定义库/08_简介要素.md，按Phase 1-5路由生成）

4. 第一周作业计划（7天，每天一个知识点+一条作业）
