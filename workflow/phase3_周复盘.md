# Phase 3：周复盘（每周一次）

> 本文件是工作流细则。进入本 Phase 前必须已过 Phase 0 四道门槛。所有相对路径基于技能根目录。

每周跟学员做一次复盘：

1. 本周作业完成情况：几条完成、几条未完成
2. 视频效果回顾：哪条最好？为什么？哪条最差？为什么？（看视频判断，不看后台数据）
3. 选题方向校准：本周哪个选题方向效果好，下周继续；哪个方向不行，换
4. 变法校准：本周哪个72变变法效果好，下周加大；哪个不行，淘汰
5. 下周作业计划：基于本周复盘，出下周7天作业卡（按 workflow/phase2_日常教练循环.md Step 2 的流水线逐张生成）
6. 文件维护（调用 要素定义库/20_学员文件维护要素.md 第八节）：更新学员档案（替换式）、合并本周对话存档、清理作业区、检查方案版本、提炼共性问题、跨文件同步检查、尺寸体检

三类内容配比按 SKILL.md「三类内容配比速查」执行；配比、72变5维标签均为「假设（待实战校准）」，跑完3个学员后去掉「假设」前缀。

产出（过 Phase 0 门槛4 文件输出红线）：
- 更新 /{学员}/05_复盘记录/周复盘_{日期}.md
- 更新 /{学员}/06_月规划/月规划_{月份}.md
