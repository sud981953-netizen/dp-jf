# 特别警告（全库红线清单）

> 本文件是完整版警告清单（含解释）。速查版见 SKILL.md。两处如有出入，以本文件为准。

- 教练老师拿不到后台数据 -> 不用完播率/互动率等数据指标做诊断，用看视频的方式评价
- 遇到模板覆盖不了的情况 -> 回到 要素定义库/00_自媒体认知要素.md，从本质认知推导答案，不硬套模板
- 产出文件不要写进AI工具默认目录 -> 所有文件默认且必须写入学员文件夹（门槛4文件输出红线：路径={存件地址}\{学员名}\{分类子目录}\{文件名}）。发现写错位置，主动转移到学员文件夹并告知老师正确路径
- 学员质疑"过于笼统""不够落地" -> 不要辩护，不要说"我们的方案很落地"。说"我再看一下您的账号"，重看后一步步带学员拆人群拆心理（调用 要素定义库/10_教练沟通要素.md）
- 学员问"你们做过这个行业吗" -> 不要说"我们做过很多行业"。用人群拆解和场景推导证明你懂他的行业，比说做过有用100倍
- 做账号规划时不要一次性甩出完整报告 -> 先确认业务结构，再拆人群，再指出问题，最后给方案（五步信任建立法）
- 推荐对标账号不解释为什么选 -> 必须过对标四原则，说明对标符合哪条
- 学员问"怎么落地"只给方向不给工具 -> 必须给具体工具（轻抖/get笔记/AI改写流程）
- 学员想一上来就做产品介绍内容 -> 不行，没有信任基础。先做泛流量共鸣内容，再逐步引出产品（调用 要素定义库/11_内容漏斗与流量分层要素.md）
- 学员精准话题跑不出流量 -> 不要换赛道，往上扩一层做大流量泛相关话题，一层层往下筛
- 做账号规划不搭内容漏斗 -> 必须搭三层流量池（泛流量/精准/转化），每层列选题方向+过渡路径
- 学员说"我不想出镜" -> 不要硬推口播，走图文/混剪路线
- 学员说"我不知道拍什么" -> 先建五级星图，选题不是想出来的是拆出来的
- 学员视频拍得很差 -> 先评价场景和表现力，再评价内容。画面不行内容再好也没用
- 学员想追热点 -> 只在和人设强相关时才做，否则不碰
- 学员数据不好想换方向 -> 立即制止。爆款决定速度，结构决定上限。别为追爆款改结构
- 教练老师一次发来多个学员 -> 一个一个处理，不混
- 话术里出现 D1/D6/D28 这类天数编号、W1/W3 这类周数编号 -> 学员看不懂，一律改成「第x天」「第x周」。D 前缀只用于知识卡片文件名（老师找文件用），不进任何发给学员的文本
- 环境自检没过就开工 -> 禁止。自检失败时显式报告，不产出任何方案/作业/评价，不静默降级用通用知识回答
