# Phase 0：前置门槛 + 学员管理

> 本文件是工作流细则。skill 被调用后、进入任何业务 Phase 前，先过本文件的四道门槛；门槛4是每次写文件前都要过的红线。所有相对路径基于技能根目录。

---

## 门槛1：存件文件夹地址（首次使用必须提供，状态存 config/设置.md）

```
IF config/设置.md 不存在 OR「存件地址」为空:
    -> "请先提供一个文件夹地址，作为所有学员资料的存件目录。"
    -> "这个目录下面会为每个学员自动创建独立文件夹，存放该学员的所有文档和对话记录。"
    -> 阻塞等待，直到用户提供地址
    -> 校验：地址存在（不存在就创建）且可写
    -> 立即写入 config/设置.md（在技能根目录下创建 config/ 文件夹，文件格式见 SKILL.md「运行设置」）
    -> 之后任何对话不再重复问；换新对话也不问（设置在文件里，不在记忆里）
ELSE:
    -> 读取 config/设置.md 的存件地址，进入门槛2

IF 老师主动说"换存件地址/存件地址改成...":
    -> 更新 config/设置.md 的「存件地址」
    -> 告知老师：旧地址下的学员文件夹不会自动迁移，需要迁移就说一声我来搬
```

**禁止把存件地址只存在"对话记忆"里。跨会话唯一可信来源是 config/设置.md 文件。** 新对话开场如果设置文件里有地址，直接用，一个字都不要再问。

## 门槛2：学员识别（每次对话必须先识别是哪个学员）

```
收到消息后，先判断这条消息是关于哪个学员的：

IF 消息中包含学员姓名/昵称/编号:
    -> 在存件目录下查找该学员的文件夹
    IF 找到 -> 这是已有学员，加载该学员的历史记录（学员档案.md + 最近对话存档）
    IF 没找到 -> 这是新学员，自动创建文件夹

IF 消息中没有明确学员信息:
    -> 问教务老师："这条消息是关于哪个学员的？请提供学员姓名或编号。"
    -> 阻塞等待
```

新学员文件夹创建：

```
-> 在存件目录下创建 /学员姓名或编号/ 文件夹
-> 在该文件夹下创建子目录：
    /学员/00_对话存档/   每次对话内容存档
    /学员/01_账号策划/    账号策划方案等
    /学员/02_选题与文案/  选题池、文案
    /学员/03_作业与排期/  每日作业卡、周排期
    /学员/04_视频评价/    视频评价记录
    /学员/05_复盘记录/    周复盘记录
    /学员/06_月规划/      月度规划
-> 创建 /学员/学员档案.md（记录学员基础信息，模板见本文件末尾）
```

## 门槛3：基础信息采集表（仅新学员首次）

```
IF 是新学员（刚创建文件夹）:
    -> 输出 templates/基础信息采集表.md
    -> "请填写完整这张基础信息采集表，填完才能进行账号规划。"
    -> 填完后存入 /学员/学员档案.md
    -> 阻塞等待
ELSE:
    -> 已有学员，加载 /学员/学员档案.md 中的历史信息
    -> 进入对应Phase（根据当前对话内容判断是做规划/布置作业/评价视频）
```

## 门槛4：文件输出红线（每次写文件前必过，无例外）

所有文件产出（方案/作业卡/评价/复盘/选题池/话术文档/任何文档），默认且必须写入学员文件夹。
AI工具的默认目录（当前工作目录/桌面/下载/工具自带输出目录）永远不是目的地。

```
写文件前，先按以下顺序自检：

1. 学员识别了吗？
   IF 当前对话还没确定是哪个学员 -> 回门槛2先识别，识别前不产出任何文件

2. 路径拼对了吗？
   完整路径 = {存件地址}\{学员名}\{分类子目录}\{文件名}
   自检：路径是不是以存件地址开头？
   IF 不是 -> 重拼路径，禁止直接写入AI默认目录

3. 分类子目录对了吗？
   账号策划方案 -> 01_账号策划/
   选题、文案     -> 02_选题与文案/
   作业卡、周排期 -> 03_作业与排期/
   视频评价       -> 04_视频评价/
   周复盘         -> 05_复盘记录/
   月规划         -> 06_月规划/
   对话内容       -> 00_对话存档/

4. 文件名带绝对日期了吗？
   用 20260728_主题.md，不用"今天/最新/最终版"

5. 写入后回执：
   告诉老师一句"已存到：{学员名}/0X_分类/文件名"，
   老师凭这句话就能去文件夹里找到文件
```

**特殊情况：**

```
IF 老师说"先别存，给我看看就行":
    -> 可以先把内容贴在对话里
    -> 但对话结束走存档机制时，仍要写入学员文件夹，不能只留在对话里

IF 发现之前的文件写错了位置（写到了默认目录）:
    -> 主动把文件转移到正确的学员文件夹
    -> 告诉老师新路径，提醒他以后以学员文件夹为准
```

## 对话存档机制（全自动，无需老师发指令）

存档位置永远是学员文件夹（先过门槛4文件输出红线），不是AI工具的默认目录。

每次对话结束，AI自动执行以下存档操作，不需要老师发任何指令。老师说完最后一句话，AI在回复的同时自动存档：

1. 将本次对话的完整内容（含AI判断+话术+建议）存入：
   /学员/00_对话存档/日期_简要主题.md
   例如：/张三/00_对话存档/20260714_账号规划讨论.md

2. 如果对话中产出了方案/作业/评价等文档，存入对应子目录：
   账号策划方案 -> /学员/01_账号策划/
   选题文案     -> /学员/02_选题与文案/
   每日作业卡   -> /学员/03_作业与排期/
   视频评价     -> /学员/04_视频评价/
   周复盘       -> /学员/05_复盘记录/
   月规划       -> /学员/06_月规划/

3. 更新 /学员/学员档案.md，补充本次对话的关键信息
   （当前阶段、最新作业进度、最新评价结论、待办事项等）

目的：AI不能有遗忘。每次对话前先加载该学员的历史存档，确保延续之前的进度，不重复问已经问过的问题。

## 存档规范（调用 要素定义库/20_学员文件维护要素.md）

- 存档文件用绝对日期命名（20260725_主题.md），不写「今天/昨天」
- 单个对话存档 ≤200行；学员档案 ≤100行，超了做替换式精简
- 学员档案更新用替换式：替换旧条目，不在末尾堆叠
- 阶段/方向/变现变化时跨文件同步更新（详见20号文件第七节）

## 学员档案.md 模板

```
# 学员档案 - 姓名

## 基本信息
- 学员编号：编号
- 行业类型：A/B/C/D/E/F类
- 变现路径：到店/私信/橱窗/直播/私域/广告
- 账号阶段：冷启动/成长/成熟
- 出镜意愿：出镜/不出镜/有条件出镜

## 当前进度
- 规划状态：未规划/已规划/执行中
- 当前周次：第N周
- 已完成作业：N条
- 最新评价：一句话概括最近一次视频评价结论

## 待办事项
- 待办1
- 待办2

## 对话历史索引
- 日期 主题 -> /00_对话存档/文件名.md
```
